# document.md 格式细则(Prism)

你在 Prism 里编辑 cwd 里的 **`document.md`**(受限 Markdown,正文)和 **`references.bib`**(参考文献,见「引用文献」),系统会确定性地把它们转成目标期刊模板的 LaTeX 再编译。**不要写 LaTeX 源码(`.tex`/`.cls`)、不要自己编译**;`references.bib` 之外别新建其它 `.bib`。保持最小 diff(Edit 定点替换,不重写整篇)。

## 元信息(frontmatter)
- 开头 `---` 与 `---` 之间:`title:` / `abstract:` / `keywords:`,各占一行(keywords 逗号分隔)。
- 改就改值;**不要删整行** —— 删掉 `abstract:` 行会把真源里的摘要清空。不改的字段原样留着。

## 数学
- 行内:`$...$`。独立公式:单独一行,上一行 `$$`、中间公式、下一行 `$$`。
- **一律用 `$...$`,绝不用 Unicode 上标/符号**:`$O(n^2)$` 不是 O(n²);`$1\times10^{-4}$` 不是 1×10⁻⁴;`$\alpha,\beta$` 不是 α、β;`$\le,\ge,\times,\pm$` 不是 ≤ ≥ × ±。
- 公式里正常写 LaTeX 数学命令(`\frac`、`\sum`、`\alpha`、`\mathbf` 等)—— 数学模式内部的 LaTeX 是正常的,受限的只是正文结构。
- 需要编号/交叉引用的公式:目前 document.md 不支持给公式打编号锚,正文引用公式请就近描述(如"上式")而不是"式(3)"。

## 表格(GFM)
```
| 方法 | 准确率 | F1 |
| --- | --- | --- |
| Baseline | 88.5 | 0.87 |
| 本文 | 93.1 | 0.92 |
```
- 表头行 + `| --- | --- |` 分隔行 + 逐行数据。单元格用**纯文本**:单元格内的公式/引用/加粗可能无法完整保留,复杂内容放正文别塞进单元格。
- **题注 + 交叉引用锚**:在**表格正下方紧挨一行**写 `表: 题注文字 {#tbl:键}`(题注可省、锚 `{#tbl:键}` 可省)。系统据此出带编号的表题注,正文用 `[@tbl:键]` 即可引用(见「交叉引用」)。例:
  ```
  | 方法 | 准确率 |
  | --- | --- |
  | 本文 | 93.1 |
  表: 各方法在测试集上的准确率 {#tbl:main}
  ```

## 引用文献
- 会话工作区里除了 `document.md`,还有一份 **`references.bib`**(参考文献,BibTeX)。**引用条目就写在这里** —— 你可以用 Read/Edit/Write 改它;轮末系统会把它解析进参考文献表并编号渲染。
- **文献来源 = minicod**:要引证某个说法时,用 **minicod MCP**(`mcp__minicod__*`)检索真实论文,拿到**真实元数据**(标题/作者/年份/期刊/DOI),把它写成一条 BibTeX **追加进 `references.bib`**,正文里用 `[@键]` 引用(键 = 你在 `@article{键,...}` 里起的键)。
- **绝不编造**:只引 **minicod 真检索到**的论文;BibTeX 里的作者/年份/DOI 必须是 minicod 返回的真实值 —— **不许凭记忆编文献、编 DOI、编年份**。查不到就别硬引,把话写扎实、用文字交代来源即可。
- BibTeX 条目(键用「首作者姓氏+年份」如 `smith2020`;同姓同年就加字母 `smith2020a`):

  ```
  @article{smith2020,
    title   = {论文标题},
    author  = {Smith, John and Doe, Jane},
    year    = {2020},
    journal = {期刊名},
    doi     = {10.xxxx/xxxxx},
  }
  ```
- 正文引用:`[@smith2020]`(相邻多篇会自动并成一条 `[1,2]`)。润色改写时**保留所有已有 `[@键]` 的位置**,别漏或挪。
- 要去掉某处引用 → 删正文的 `[@键]`;别删 `references.bib` 里别处还在用的条目。
- 区分:`[@fig:x]`/`[@tbl:x]`/`[@sec:x]`(带 fig:/tbl:/sec: 前缀)是**交叉引用**(见下),不是文献引用 —— 别把它们写进 `references.bib`。

## 图(题注)
- 图由用户经工具栏「插入图片」上传;在 document.md 里它是一行 `![图](资产id "题注"){#fig:键}`(`{#fig:键}` 锚可选)。你**只改引号里的题注**、以及(要引用它时)那个 `{#fig:键}` 锚,别动 `资产id`、别自己新造这种图行、别手写图片路径或 `\includegraphics`。
- 图/表内容层面的处理(何时配图、题注怎么写、位置怎么安排)见 [prism-figures]。

## 交叉引用(图 / 表 / 节)—— 打锚 `{#键}` + 正文 `[@键]`
- 要在正文引用某张图/表/某节 → 先给它打一个**带类型前缀的唯一锚**,再在正文用 `[@锚]` 引用。系统编译成**自动编号**("图 1""表 2""第 3 节"),内容重排也不会指错。
- 打锚:
  - 图:`![图](资产id "题注"){#fig:arch}`
  - 表:表格正下方一行 `表: 题注 {#tbl:main}`
  - 节(标题):`## 方法 {#sec:method}`
- 引用:正文写 `[@fig:arch]` / `[@tbl:main]` / `[@sec:method]`,**前面自己带上"图/表/第…节"这个词**:如"如图 `[@fig:arch]` 所示""见表 `[@tbl:main]`""详见第 `[@sec:method]` 节"。
- 只能引**已打锚**的目标;锚名拼错或没打锚会编译出 `??`。**公式暂不支持打锚**,引用公式仍就近描述("上式")。

## 标题 / 强调 / 列表
- 标题 `#` / `##` / `###`(最多三级,再深会被降级)。
- **加粗**、_斜体_;列表用 `-` 或 `1.`。

## 特殊字符
- 你写的 `$` 一定被当作数学定界符。要表达"美元/百分比"等字面量,用文字("美元""百分号")或放进不含数学的普通句子,避免裸 `$`/`%` 引发歧义。

## 收尾自查
- frontmatter 三行还在、只改了该改的字段;数学全在 `$...$`/`$$` 里、无 Unicode 符号;**每条 `[@文献键]` 在 `references.bib` 里都有对应条目、且条目来自 minicod 真检索(作者/年/DOI 真实、没编)**、已有 `[@键]` 位置没挪;要引用的图/表/节都打了 `{#fig:/tbl:/sec:键}` 锚、正文用 `[@锚]` 引用(没写死"图1/表2"),公式仍就近描述;没有手写 `\ref`/`\label`(锚和引用都走 `{#键}`/`[@键]` 语法);图行只改了引号里的题注 + 锚;表格分隔行 `| --- |` 在;标题层级 ≤ 3。不要自己编译(系统负责)。
