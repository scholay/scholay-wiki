# document.md 编辑纪律(Prism · 常驻)

你编辑会话 cwd 里的 **`document.md`**(受限 Markdown,正文)和 **`references.bib`**(参考文献,规则见 `prism-citation-grounding`)。系统会**确定性地**把它们转成目标期刊模板的 LaTeX 再编译。

**铁律**:不要写 LaTeX 源码(`.tex`/`.cls`/环境/宏包)、不要自己编译、不要新建其它 `.bib`、不要画图(见「图」)。**保持最小 diff**:用 Edit 做定点替换,别整篇重写(整篇重写会放大合并风险、抹掉未变内容的元数据)。

## 元信息(frontmatter)
- 开头 `---` 与 `---` 之间:`title:` / `abstract:` / `keywords:`,各占一行(keywords 逗号分隔)。
- 改就改**值**;**绝不删整行** —— 删掉 `abstract:` 行会把真源里的摘要清空。不改的字段原样留着。

## 数学
- 行内:`$...$`。独立公式:单独一行 `$$`、中间公式、下一行 `$$`。
- **一律用 `$...$`,绝不用 Unicode 上标/符号**:`$O(n^2)$` 不是 O(n²);`$1\times10^{-4}$` 不是 1×10⁻⁴;`$\alpha,\beta$` 不是 α、β;`$\le,\ge,\times,\pm$` 不是 ≤ ≥ × ±。
- 公式**内部**正常写 LaTeX 数学命令(`\frac`、`\sum`、`\alpha`、`\mathbf`)—— 受限的只是正文结构,数学模式内部不受限。
- **公式打锚(要被引用时)**:在闭合的 `$$` 后加 `{#eq:键}`,正文用 `[@eq:键]` 引用 → 自动编号"式(1)":
  ```
  $$
  E = mc^2
  $$ {#eq:emc}
  ```
  正文:"由式 `[@eq:emc]` 可得…"。不需要引用的公式不打锚。

## 表格(GFM)
```
| 方法 | 准确率 | F1 |
| --- | --- | --- |
| Baseline | 88.5 | 0.87 |
| 本文 | 93.1 | 0.92 |
```
- 表头行 + `| --- | --- |` 分隔行 + 逐行数据。**单元格用纯文本**:单元格内的公式/引用/加粗可能无法完整保留,复杂内容放正文别塞进单元格。
- **题注 + 交叉引用锚**:表格**正下方紧挨一行**写 `表: 题注文字 {#tbl:键}`(题注可省、锚可省)。系统据此出带编号的表题注。

## 图(机制层 —— 你不画图)
- **不写 TikZ/pgfplots,不调 matplotlib/python 生成图** —— document.md 没有画图语法,这类内容只会落进兜底块、大概率编译失败或排版错乱。
- 图由用户经工具栏「插入图片」上传;在 document.md 里它是一行 `![图](资产id "题注"){#fig:键}`。你**只改引号里的题注**、以及要引用时那个 `{#fig:键}` 锚;**别动 `资产id`、别自己造图行、别手写图片路径或 `\includegraphics`**。
- 用户要"把数据画成图":说明你不能在正文直接画矢量图,建议 ta 用外部工具后经「插入图片」上传;你可先把数据整理成表格。
- 题注**怎么写得好**(figure-first、独立可读、与论点接起来)→ 按需加载 `wl-figure-narrative`。

## 交叉引用(图 / 表 / 节)—— 打锚 `{#键}` + 正文 `[@键]`
- 引用某图/表/节 → 先给它打**带类型前缀的唯一锚**,再在正文用 `[@锚]` 引用。系统编译成**自动编号**("图 1""表 2""第 3 节"),重排不指错。
- 打锚:图 `![图](资产id "题注"){#fig:arch}`;表 正下方一行 `表: 题注 {#tbl:main}`;节 `## 方法 {#sec:method}`。
- 引用:正文 `[@fig:arch]` / `[@tbl:main]` / `[@sec:method]`,**前面自己带上"图/表/第…节"这个词**("如图 `[@fig:arch]` 所示""见表 `[@tbl:main]`")。
- 只能引**已打锚**的目标(拼错/没打锚会编出 `??`)。**别手写 `\ref`/`\label`**(锚与引用都走 `{#键}`/`[@键]`)。
- 区分:`[@fig:x]`/`[@tbl:x]`/`[@sec:x]`(带前缀)是**交叉引用**;无前缀的 `[@键]` 是**文献引用**(见 `prism-citation-grounding`)。别把交叉引用锚写进 `references.bib`。

## 代码 / 围栏
- **别写 ``` ```python``` / ```js``` 等代码围栏**:document.md 不是代码文档,非 LaTeX 语言的围栏会被当作安全的纯文本代码块处理(不参与排版),多半不是你想要的。要展示算法用 `wl-structure` 的伪代码约定或普通列表描述;确需代码清单时告诉用户其局限。

## 标题 / 强调 / 列表 / 特殊字符
- 标题 `#`/`##`/`###`(最多三级,再深会被降级);**加粗**、_斜体_;列表 `-` 或 `1.`。
- 你写的 `$` 一定被当数学定界符;要表达字面"美元/百分比"用文字("美元""百分号"),避免裸 `$`/`%`。

## 收尾自查
frontmatter 三行还在、只改了该改的值;数学全在 `$...$`/`$$`、无 Unicode 符号;表格分隔行 `| --- |` 在、单元格纯文本;要引用的图/表/节都打了 `{#fig:/tbl:/sec:键}` 锚、正文用 `[@锚]`(没写死"图1/表2"、没手写 `\ref`/`\label`);图行只改了题注 + 锚;标题层级 ≤3;做的是最小定点 diff。**不要自己编译**(系统负责)。
