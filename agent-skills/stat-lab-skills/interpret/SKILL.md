# 数据分析 · 结果解读

> 这一层是**你的主场**:B4 实证明确指出「把统计输出解释给非统计背景的人听」是 LLM 的原生强项,
> 不需要加防线,要加体验。但有几处措辞是硬约束 —— 它们会被审稿人一眼抓到。

## 只教解释,不教计算

**本技能里不出现任何数字计算。** 要引用数字就引用报告里已有的;
需要新的数字(比如换个效应量、补事后功效)→ 回去调引擎,不要自己算。

## 措辞硬约束

### 1. 非参检验:检验的是分布位置,不是均数

Mann-Whitney / Wilcoxon 的结论**不能**写成「两组均数差异显著」。
正确:「两组的分布位置存在显著差异」或「A 组的取值倾向高于 B 组」。
描述统计也要跟着换:非参报**中位数(四分位数)**,不报 `x̄±s`。

### 2. 观察性数据:不许因果措辞

没有随机分组就不能写「导致 / 造成 / 使得 / 证明了」。
正确:「与…相关联」「在…组中更高」。这一条审稿人抓得最勤。

### 3. 不显著 ≠ 没有差异

「p>0.05」的正确表述是「**未发现**统计学显著差异」,不是「两组没有差异」或「两组相同」。
这是逻辑错误(未拒绝原假设 ≠ 原假设为真),也是最常见的退稿理由之一。

配套要给的:效应量与置信区间。若 95%CI 很宽且跨 0,说明**样本量不足以判断**,
这跟「确实没有效应」是两回事,值得在讨论里写清楚。

### 4. 效应量要落到领域语境

不要只说「d=0.7 属于中等效应」。要说这在**用户的领域**里意味着什么:
临床上是否达到最小临床重要差值(MCID)?教育干预里 0.7 是很大的?
不知道就说不知道,并建议用户对照本领域文献 —— 别编一个领域基准。

## 审稿人会问什么(提前准备)

跑完分析后主动提示用户,这些是同类论文最常被问的:

1. **为什么用这个检验?前提检验做了吗?** → 报告里的 Methods 段已经把依据链写好了,直接引用。
2. **样本量是怎么定的?** → 若是回顾性数据,如实说「基于现有可获得样本」,不要编一个事后的样本量计算。
3. **做了多少次比较?校正了吗?** → 若同一批数据跑了多个检验,主动说明并做多重比较校正。
4. **异常值怎么处理的?** → 删了就要说删了几个、按什么标准。《心理科学》等中文期刊已把这条写进硬规范。
5. **数据和代码能提供吗?** → 报告附带的 `analysis.py` 就是答案(固定随机种子,可原样重跑)。

## 引擎给了这些标记时,如实转达

- **`contested`(方法学有分歧)** → 告诉用户存在另一派主张,以及我们采用哪一派、为什么。
  常见的一处:两组比较前要不要先做方差齐性检验(先测再分流 vs 无条件用 Welch),
  两派都统计学正确,我们按中文期刊惯例走「先测再分流」并把依据链一起交付。
- **「本默认依学科惯例而非文献建议」** → 说明这个默认值来自学科惯例(审稿人期待),
  但没有一次文献直接论证。用户若要更严谨的选择,可以换。
- **`degraded`(降级)** → 例如样本量过大时正态性检验做了子抽样。如实说,不要藏。

## 不要做的事

- 不要替用户下「所以你的假设成立」这种结论 —— 统计结果支持或不支持,论证是作者的事。
- 不要因为用户看起来失望就软化结论。
- 不要在解读里引入报告中没有的数字。
