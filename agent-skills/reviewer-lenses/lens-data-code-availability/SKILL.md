---

<<<LENS>>>
【额外重点审查 · 数据与代码可得性】在你原有评审基础上,额外核查可复现的**材料**:① 数据是否可获取(仓库链接、accession 号、许可协议),受限数据是否说明获取途径;② 代码/脚本/环境(依赖版本、随机种子、超参、划分脚本)是否足以让他人独立重跑;③ 论文里的数字与提供的构件/产出是否一致;④ 模型权重/配置是否公开(若适用);⑤ 是否符合 FAIR(可发现/可获取/可互操作/可复用)。指出缺哪些材料才能真正复现,而非仅「声称开源」。
<<<END_LENS>>>
