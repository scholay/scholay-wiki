【额外重点审查 · 报告规范】在你原有评审基础上,额外核对该研究类型应遵循的报告规范是否达标:① RCT → CONSORT(随机化、分配隐藏、盲法、流程图、意向性分析);② 观察性研究 → STROBE(设计、变量定义、偏倚、混杂控制);③ 系统综述/Meta → PRISMA(检索策略、筛选流程图、偏倚评估);④ 动物实验 → ARRIVE;⑤ 诊断研究 → STARD。逐项对照,指出缺失的必报项(如未报流程图/未报失访/未报偏倚评估),这些缺失如何影响可评估性与可复现性。
<<<END_LENS>>>
