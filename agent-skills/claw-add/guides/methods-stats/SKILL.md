# 研究设计 & 统计方法咨询

给**有依据的方向 + checklist**,帮用户想清楚;同时说明:**正式分析仍需本人/统计师核实**,你不替代统计咨询。

## Step 1 · 先厘清三件事(决定一切)
1. **研究问题类型**:比较(组间差异)/ 关联(相关)/ 预测(建模)/ 因果(干预)?
2. **数据/变量类型**:连续 / 序数 / 二分 / 多分类 / 计数 / 生存(时间-事件)?
3. **设计**:配对还是独立?几组?有无重复测量 / 嵌套(同一被试多次、同一班级多学生)?

## Step 2 · 检验选择(按上面三点对号,别背模板)
- **两组连续**:正态+方差齐→独立/配对 t;否则 Mann-Whitney / Wilcoxon。
- **多组连续**:ANOVA(+ 事后两两,做多重比较校正);非正态→Kruskal-Wallis。
- **分类×分类**:卡方(期望频数够);小样本→Fisher。
- **关联**:连续→Pearson(线性)/ Spearman(单调);建模→线性/逻辑/泊松回归按结局类型。
- **重复测量/嵌套**:重复测量 ANOVA 或**混合效应模型**(别把非独立数据当独立 → 伪重复 pseudoreplication)。
- **时间-事件**:Kaplan-Meier + log-rank / Cox 回归。

## Step 3 · 前提与陷阱
- 查前提:正态(残差)、方差齐、独立性、线性、无严重共线性。
- 常见坑(主动排查并提醒用户):
  - **p-hacking / 只报显著的**;**HARKing**(事后假设当预设);
  - **伪重复**(把非独立观测当独立,虚高自由度);
  - **多重比较不校正**(做了 N 个检验必然有假阳性);
  - **基线不平衡 / 混杂未控**;**幸存者偏差 / 选择偏差**;
  - **过拟合 / 无独立验证集**;**用序数数据当连续**滥用均值。

## Step 4 · 样本量 & 功效
需要:预期**效应量** + α(通常 .05) + 目标 power(通常 .8) + 检验类型 → 反推 N。提醒功效分析应在**做实验前**做;事后"观察到的功效"意义有限。claw 能用 python(statsmodels)真算,需要就加载 `data-figures` 一起做。

## Step 5 · 报告规范
- **效应量 + 置信区间**,不要只给 p 值;写清检验名、自由度、统计量。
- 按研究类型对齐报告标准:RCT→CONSORT,观察性→STROBE,系统综述→PRISMA,诊断→STARD。

## 红线
- 给**方向和依据**,不下"就用这个准没错"的定论;让用户结合数据实际与领域惯例核实。
- 不替用户捏造/美化统计结果。
- 不确定就说不确定,并建议咨询统计师 / 查对应领域报告规范。
