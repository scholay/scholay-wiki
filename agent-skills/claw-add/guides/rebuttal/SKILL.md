# 回复审稿意见(Rebuttal)

目标:写出**逐条、有理有据、不卑不亢**的回复,让编辑和审稿人看到"作者认真对待了每一条、该改的改了、该辩的辩得有据"。

## Step 1 · 先给每条意见归类
把每条 reviewer comment 归到一类,决定回应策略:
| 类型 | 策略 |
|---|---|
| 事实性错误(审稿人看错/记错) | 礼貌澄清 + 指到原文位置,别让人觉得在指责 |
| 可补的实验/分析 | 尽量做,回复里说明做了什么、结果如何 |
| 表述不清导致的误解 | 承认没写清 + 说明已改到哪 |
| 主观偏好(风格/取舍) | 能顺就顺;不认同就有据地礼貌保留 |
| 真实缺陷/局限 | **大方承认** + 说明如何缓解 / 补进 limitation |

## Step 2 · 决策:让步 vs 据理力争
- **让步(concede)**:审稿人对的、或低成本能满足的 → 改,并明说改动。放低姿态不丢人,反而加分。
- **据理力争(push back)**:审稿人误解或要求不合理时,**用证据+文献+数据**礼貌反驳,给出为什么维持原做法。**绝不**敌对、防御过度或阴阳怪气。
- **澄清(clarify)**:纯误解 → 指明原文已有/已补的位置。
拿不准就倾向于"部分让步 + 解释",几乎总比硬刚好。

## Step 3 · 逐条回复的结构
每条固定四段式:
1. **原样引用**审稿人这条意见(编号,如 R1.3),让人对得上。
2. **一句话表态**(感谢 + 你的立场:已采纳 / 已澄清 / 已补充 / 谨慎保留)。
3. **具体改动**:改了什么、**改到稿件哪里**(页/行/小节,如 "见修订稿 §4.2, p.7")。
4. 若**不改**:有据地说明理由(数据/文献/范围),而非"我们认为没必要"。

## Step 4 · 全局收尾
- 开头写一段**总述**:感谢 + 概括主要修改(让编辑快速抓到重点)。
- 结构清晰:按 reviewer 分块、条内编号;修订稿里的改动可**高亮/标色**并在信里指位置。
- 语气统一:专业、感激、自信但谦逊。

## 语气模板(可直接改写)
> We thank Reviewer X for the constructive comments. We have revised the manuscript accordingly; point-by-point responses follow (reviewer comments in *italics*, our responses below, changes marked in the revised manuscript).

## 红线
- **绝不承诺做不到的实验**,也**绝不谎称做过**没做的补充。
- 不人身攻击审稿人、不情绪化。
- 中英按用户稿件语言;英文回复注意时态与礼貌措辞。
- 你可以帮着起草每条回应的措辞,但**具体实验结果/数据必须由用户提供**,不替他编。
