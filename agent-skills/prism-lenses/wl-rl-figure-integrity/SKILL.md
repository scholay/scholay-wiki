【总准则 · 视觉落差=数据落差】读者前注意地相信"眼睛看到的比例=真实比例"。任何让视觉差异大于/小于真实差异的处理都是借读者信任撒谎——哪怕每个数字本身没写错。
【误差棒:先声明是什么再画】SD(数据多散)、SE=SD/√n(均值多准)、95%CI≈±1.96SE 是三种不同的东西,同批数据画 SD 的棒可能是 SE 的两三倍长。题注必写:棒代表什么 + n + 成对/独立。单次测量没重复就别画误差棒,写"代表性样例",别给没重复的曲线披统计外衣。坏:"error bars indicate variability";好:"error bars = ±1 SD; n = 12"。
【y 轴:截断是最常见的合法谎言】表示数量/比例/计数的柱状/折线图**默认 y 轴从 0 起**,让高度比=数值比;从 97.5% 起会把 98% 与 99.2% 画成差一倍(数字全对、视觉全错)。要截断必显著标注并说明理由。
【双轴/色阶/选择性展示】双 y 轴任意缩放能造出假相关,慎用或改画两图;禁 panel splice(拼接不同来源的凝胶/图像不标注)、禁只挑好看的样本/时间窗。
【图↔正文一致】图上的数值、n、显著性标注与正文/表格必须对得上;题注独立可读(不看正文也懂棒/轴/n)。

## 深入

图是论文里信息密度最高、也最容易在"无意识"里骗人的部分。读者看图的第一反应是前注意的视觉比较——条形谁高、斜率谁陡、颜色谁深——他们本能地相信"眼睛看到的比例=真实的比例"。所以图表诚信只有一条总准则:**视觉落差 = 数据落差**。任何让眼睛看到的差异大于(或小于)真实差异的处理,都是在借读者的信任撒谎,哪怕图里每个数字本身都没写错。写图题、给图配文、把图接进正文时,时时回到这条准则。

### 误差棒:先声明它是什么,再画它
读者看到误差棒会默认它代表"不确定性",但 SD、SE、CI 是三种不同的东西:SD 描述这批数据本身有多散;SE=SD/√n 描述均值估计有多准(n 越大 SE 越小,棒越短);95% CI≈均值±1.96·SE。同一批数据,画 SD 的棒可能是画 SE 的棒的两三倍长。不写清是哪一种,读者无从判断两组是否真有差别。落笔时确保题注里三件事齐全:棒代表什么、n 是多少、是否成对/独立。
- 坏:`Fig 2. Expression across groups. Error bars indicate variability.`("variability"什么都没说)
- 好:`Fig 2. Mean expression per group; error bars = ±1 SD; n = 12 biological replicates.`
单次测量、没有重复,就别硬画误差棒;把它写成"representative trace / 代表性样例",别让一条没有重复的曲线披上统计的外衣。

### y 轴:截断是最常见的"合法谎言"
把 y 轴从 97.5% 起,能让 98% 和 99.2% 看起来差了一倍——数字全对,视觉全错。对表示数量、比例、计数的柱状图和折线图,**默认让 y 轴从 0 起**,让条形的高度比就是数值比。
- 坏:两组准确率 98.0% vs 99.2%,y 轴 97.5→100,配文"our method substantially outperforms the baseline"。
- 好:y 轴 0→100,两条几乎齐平;配文老实说"a modest but consistent gain of 1.2 points",把"是否显著"交给检验而非视觉。
例外要诚实地标出来:确实需要放大一处微小但重要的差异、或量本身有非零的自然基线(体温、pH、以某年为基期的指数)时,可以截断,但必须在轴上画断裂符号、并在题注写明"y-axis starts at 92 %"。对数轴同理——在轴标里写 `log scale`,否则读者会把等距刻度读成等差。

### 双 y 轴:天生制造"看起来相关"
把两条量纲不同的曲线叠在左右两根轴上,谁在上谁在下、斜率像不像,全取决于你各自选的量程——这几乎必然诱导读者读出并不存在的相关或因果。首选是拆成上下两个小 panel 共享同一条 x 轴,或各画一张图用 [@fig:a]、[@fig:b] 交叉引用。实在要共轴,就在题注写清"left axis: temperature (°C); right axis: reaction rate (s⁻¹)",并克制地不去暗示两线的贴合意味着什么。

### 拼接与选择性展示:一格里只放一次真实
面板类图像(泳道、显微、示例网格)的底线是:**一个 panel = 一次实验、一处处理的完整原图**。不同来源的图像不拼进同一格,不裁掉落在趋势之外的数据点,不把最好看的那次结果单独拎出来当"结果"。要展示"代表性"样例时,在题注说明它从多少次中挑出、依据什么挑:`representative of 3 independent experiments`。散点图别偷偷剔除离群点后再拟合;要去点就在正文写明剔除准则与剔了几个。

### 色阶与图例:让颜色说真话
彩虹(jet)色阶在感知上不均匀——它在某些区段制造根本不存在的"边界",又把真实的渐变压平,还对红绿色盲不友好。热图、密度图改用感知均匀的连续色(viridis、magma 一类),题注标明色标对应的量和范围。用发散色(蓝—白—红)时,让白色对齐真正的中性值(如 0 或对照),别让零落在最扎眼的深色端而夸大反差。图例的分箱别忽宽忽窄地掩盖或放大某一档。

### 图—文—表三处对得上
同一个数字常出现三次:图内标注、图题、正文转述(往往就在 [@fig:x] 旁边),有时还进了一张 GFM 表。它们必须字字相符。最常见的诚信事故不是造假,而是改了正文里的均值却忘了同步图题,或表里 n=48、图注写 n=50。每当你动了一处数据,顺手把另外两处一起改齐。

### 让每张统计图自足
好图题是能独立读懂的一小段:它交代样本量、用了什么检验、误差棒定义、显著性记号的含义。读者不翻回正文也该明白这张图在说什么。
- 坏:`Fig 4. Results of the experiment.`
- 好:`Fig 4. Tumor volume over 21 days (mean ± SE; n = 8/group). Two-way ANOVA with Bonferroni correction; *p < .05, **p < .01 vs. control.`
把"这张图能不能被单独截出来还不骗人"当作每张图的收尾准则——能,它就是诚实的。
