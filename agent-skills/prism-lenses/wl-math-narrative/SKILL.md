# 数学叙述:把推导写成有骨架的散文

数学段落最常见的崩法不是算错,而是「草稿纸誊抄」:公式一行接一行连排,步与步之间的蕴含关系要读者自己重建;定理光秃秃地冒出来,假设散落在三页之前;符号第一次露面就直接参与推导,定义靠猜。

总原则只有一条:**数学论文是散文,公式只是句子里的名词短语,逻辑永远由文字承载。**自检办法同样只有一条:把公式当作普通词语读出声,整段话必须语法通顺——「由 [@eq:bound] 与凸性可得,右端不超过……」是句子;两行公式中间空一行,不是。

## 一、四拍骨架:setup → claim → proof sketch → remark

每个「定理级」单元(定理/命题/主要引理)按四拍展开,先搭骨架再填公式:

1. **setup(一至三句)**:交代舞台——要分析的对象是什么、关键假设为何自然、这个结果在全文论证链里替谁服务。
2. **claim(正式陈述)**:定理本体,自洽、假设写全(见第四节)。
3. **proof sketch(三至五句)**:路线图——分几步、每步用什么工具、最关键的不等式或构造是哪个。
4. **remark(一至两句)**:界紧不紧、假设能否放宽、与前文哪条线索接上、为后文哪个实验做铺垫。

❌ **改前(公式墙)**:

> 设 $\hat f$ 为经验风险最小化解。
>
> $$R(\hat f) - \hat R(\hat f) \le \sup_{f\in\mathcal F} \lvert R(f)-\hat R(f)\rvert$$
>
> $$\sup_{f\in\mathcal F}\lvert R(f)-\hat R(f)\rvert \le 2\mathfrak{R}_n(\mathcal F) + \sqrt{\log(1/\delta)/(2n)}$$
>
> $$R(\hat f) \le \hat R(\hat f) + 2\mathfrak{R}_n(\mathcal F) + \sqrt{\log(1/\delta)/(2n)}$$

✅ **改后(四拍)**:

> 为了说明第 3 节的算法不会过拟合,我们需要控制经验风险 $\hat R$ 与真实风险 $R$ 之间的差距。差距的大小由假设类 $\mathcal F$ 的复杂度决定,我们用 Rademacher 复杂度 $\mathfrak{R}_n(\mathcal F)$ 度量它。
>
> **定理 1.** 设 $\mathcal F$ 是取值于 $[0,1]$ 的函数类,样本 $\{(x_i,y_i)\}_{i=1}^n$ 独立同分布,$\hat f$ 为 $\mathcal F$ 上的经验风险最小化解。则对任意 $\delta\in(0,1)$,以至少 $1-\delta$ 的概率,
>
> $$R(\hat f) \;\le\; \hat R(\hat f) + 2\mathfrak{R}_n(\mathcal F) + \sqrt{\tfrac{\log(1/\delta)}{2n}}.$$ {#eq:gen-bound}
>
> 证明分两步:先用一致收敛把 $R(\hat f)-\hat R(\hat f)$ 放大到整个函数类上的上确界;再对该上确界施加对称化论证与 McDiarmid 不等式,得到以 Rademacher 复杂度表达的高概率上界。完整证明见附录 A。
>
> 注意 [@eq:gen-bound] 右端第二项与模型容量同阶、第三项随样本量以 $n^{-1/2}$ 衰减——这正是第 5 节「加数据比加容量更划算」现象的来源。

🔍 **为什么更好**:读者不必自己重建三行公式之间的蕴含链;定理带全假设,可脱离上下文被引用;sketch 给了路线,想跳细节的审稿人两句话就能确认策略合理;remark 把孤立的界接回论文主线;公式打了锚,后文回指不再靠编号猜。

## 二、记号纪律:先定义后使用,句首不放符号

- **先定义后使用**:每个符号在首次出现的那半句里就地定义,不放过「顺手引入」的临时符号。
- **句首不放裸符号**:给符号加一个两字类别前缀即可——「函数 $f$」「参数 $\lambda$」「矩阵 $A$」。这既是排印惯例(句首符号与上一句句号相邻难认),也逼你想清楚符号的身份。
- **一个符号一个含义**:同一节里 $n$ 不能既是样本量又是维度;发现冲突当场改名,不留「读者可由上下文分辨」的侥幸。

❌ 「$\tau$ 控制了收敛速度,当 $\tau<1/L$ 时算法线性收敛。」($\tau$、$L$ 均未定义;句首是裸符号)

✅ 「记步长为 $\tau>0$,并设 $\nabla g$ 以 $L$ 为 Lipschitz 常数。步长 $\tau$ 控制收敛速度:当 $\tau<1/L$ 时,算法线性收敛。」

🔍 两个符号在使用前的半句内完成定义,读者零回翻;句首换成「记」「步长 $\tau$」,句子有了主语骨架;附带把 $\tau>0$ 的取值范围也交代了——定义符号时顺手写清它活在哪个集合里,是最廉价的严谨。

## 三、显式逻辑连接词:蕴含方向必须写在纸上

两行公式之间的关系可能是「等价」「蕴含」「代入」「特例」——不写出来,读者只能按最坏情况逐项验算。常用连接词与英文对应:

| 逻辑关系 | 中文 | 英文 |
|---|---|---|
| 前式推出后式 | 由 [@eq:x] 可得 / 于是 | it follows from [@eq:x] that / hence |
| 归约目标 | 故只需证 | it suffices to show |
| 代数操作 | 代入…并整理得 / 两边对…求和 | substituting … yields / summing over … |
| 合并已有结果 | 结合 [@eq:x] 与假设 A | combining [@eq:x] with Assumption A |
| 转向另一分支 | 另一方面 | on the other hand |
| 提示关键观察 | 注意到 | observe that / note that |
| 收尾 | 证毕 / 即为所证 | as desired / which completes the proof |

❌ 改前:

> $$\|x_{t+1}-x^\*\|^2 \le \|x_t-x^\*\|^2 - 2\tau\langle \nabla g(x_t), x_t-x^\*\rangle + \tau^2\|\nabla g(x_t)\|^2$$
>
> $$\langle \nabla g(x_t), x_t-x^\*\rangle \ge \mu\|x_t-x^\*\|^2$$
>
> $$\|x_{t+1}-x^\*\|^2 \le (1-2\tau\mu+\tau^2 L^2)\|x_t-x^\*\|^2$$

✅ 改后:

> 展开迭代式并利用内积恒等式,可得
> $$\|x_{t+1}-x^\*\|^2 \le \|x_t-x^\*\|^2 - 2\tau\langle \nabla g(x_t),\, x_t-x^\*\rangle + \tau^2\|\nabla g(x_t)\|^2.$$ {#eq:expand}
> 由 $g$ 的 $\mu$-强凸性,内积项满足 $\langle \nabla g(x_t), x_t-x^\*\rangle \ge \mu\|x_t-x^\*\|^2$;又由 $L$-光滑性,梯度范数项不超过 $L^2\|x_t-x^\*\|^2$。将两者代入 [@eq:expand] 并整理,得
> $$\|x_{t+1}-x^\*\|^2 \le (1-2\tau\mu+\tau^2 L^2)\,\|x_t-x^\*\|^2.$$ {#eq:contract}
> 故当 $\tau<2\mu/L^2$ 时收缩因子严格小于 1,序列线性收敛。

🔍 每一步都点名了用到的假设(强凸给内积、光滑给梯度范数),审稿人可以逐步核对而不必自己补桥;短的中间不等式内联进句子,只有承上启下的两条打锚成行间公式——公式的「行间/行内」之分本身就是叙述层级。

## 四、定理陈述自洽:假设一件不落地搬进来

定理是论文里最会被单独引用的部件——别的论文引用你时,只抄陈述不抄上下文。所以陈述内必须自带:对象的定义域与类型、正则性假设、常数的取值范围、随机性来自哪里、结论以什么模式成立(处处/高概率/期望)。

❌ 「**定理 2.** 在上述假设下,算法以速率 $O(1/t)$ 收敛。」(「上述假设」是哪三条?收敛按什么度量?常数藏在 $O$ 里依赖什么?)

✅ 「**定理 2.** 设 $g:\mathbb{R}^d\to\mathbb{R}$ 凸且 $L$-光滑,步长取 $\tau=1/L$,初始点满足 $\|x_0-x^\*\|\le D$。则算法 1 的迭代序列对任意 $t\ge 1$ 满足 $g(x_t)-g(x^\*)\le 2LD^2/t$。」

🔍 假设(凸、光滑、步长、初始化)全部进入陈述;$O(1/t)$ 换成带显式常数的不等式,读者能看出界对 $L$ 和 $D$ 的依赖——这也顺带堵住了「常数其实随维度爆炸」类的审稿质疑。写「在假设 1–3 下」也可接受,前提是假设有编号、集中列在一处、且定理里点名编号而非「上述」。

## 五、长证明:正文给 sketch 与直觉,细节后置

超过约十行、或含两个以上引理级中间步骤的证明,正文只保留三层:

1. **一句直觉**:整个证明「凭什么能成」——「核心是把误差拆成偏差与方差两项分别压制」「关键构造是把对抗样本嵌进一个更大的凸集」。
2. **分步路线**:「证明分三步:先…;再由…可得…;最后…。」每步一句,点名工具。
3. **指路牌**:「完整证明见附录 B」;技术性引理挪去附录时,正文陈述引理并一句话说它管什么用。

判断细节去留的标准:这一步删掉后,专业读者还能相信结论且知道去哪核实吗?能——后置;不能(比如全文最核心的新构造)——留正文,但仍要有文字骨架托着。

## 六、公式锚:{#eq:语义名} 与 [@eq:语义名]

- 只给**会被再次引用**的行间公式打锚;一次性的中间步骤不打,免得编号噪声淹没重点。
- 锚名用语义而非序号:`{#eq:gen-bound}`、`{#eq:contract}`,不用 `{#eq:3}`——后续增删公式时语义名不会错位。
- 回指一律 [@eq:gen-bound],禁用「上式」「由(3)」:「上式」在改稿插入新公式后立即失效,裸编号无法随文档自动重排。
- 锚写在行间公式的结束定界符之后同一行:`$$ … $$ {#eq:name}`。

## 七、中英数学写作惯例差异

中文稿直译成英文(或反向)时最容易带伤的几处:

| 场景 | 中文惯例 | 英文惯例 | 陷阱 |
|---|---|---|---|
| 定理开头 | 设…,则… | Let/Assume/Suppose …. Then … | 英文三段式里 Let 管对象、Assume 管条件,别混在一个从句里 |
| 「易证/显然」 | 期刊尚可容忍 | obviously / trivially / clearly 高危 | 改 a direct computation shows / it is straightforward to verify——且必须真的直接 |
| 引出公式 | 「有」「可得」 | we have / which gives / yielding | 逐行都写 we have 会单调,轮换使用 |
| 冠词 | 无此问题 | the solution vs a solution | 存在唯一性未证之前不用 the |
| 人称 | 「我们」 | we(单作者也用 we) | 英文避免被动式堆砌,we show 比 it is shown 好 |
| 句子边界 | 逗号可一路连接公式链 | 必须是真句子:分号、从句或句号 | 中式逗号流直译过去就是 run-on 长病句 |
| 收尾 | 证毕 | which completes the proof / as desired / □ | — |

## 八、句骨(照抄填空)

- setup:「为了控制____,我们需要对____附加____假设;这一假设在____场景下自然成立。」
- claim:「设____满足____,并记____。则对任意____,以至少____的概率,有 [@eq:____]。」
- sketch:「证明分三步:先____;再由____可得____;最后____。完整证明见附录____。」
- remark:「注意 [@eq:____] 中的____项不可去除:当____时,____。」
- 归约:「由 [@eq:____] 与假设____,只需证____。」
- 操作:「将 [@eq:____] 代入并对____求和,整理得 [@eq:____]。」
- 直觉:「粗略地说,____扮演了____的角色,因此____。」

## 九、别动/豁免清单

- **别动数学内容**:重写叙述时,不等式方向、常数、量词顺序、上下标一个字符都不许「顺手改」;拿不准某步是否等价,保留原式,只在文字层面补连接。
- **既有编号体系豁免**:若全文已统一用「定理 3.1」「式 (12)」式回指且体系自洽,不必推翻重打锚——只给新增公式用 {#eq:} 锚。
- **标准记号豁免**:$\mathbb{R}$、$O(\cdot)$、$\log$、$\mathbb{E}$ 这类领域公认记号无需定义;但同一符号在本文被重载(如 $\sigma$ 既是激活函数又是标准差)时必须显式区分。
- **短推导豁免**:两三行的代数化简不必强套四拍骨架,一句「直接计算可得」加结果即可。
- **别把句首规则执行成臃肿**:「函数 $f$」两字前缀足够,不要膨胀成「我们前文所定义的函数 $f$」。
- **纯排版不归本条**:公式内空格、标点是否入公式、行间公式的居中与断行,属常驻编辑纪律,交给通读校对处理。
