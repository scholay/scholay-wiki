# 换刊/会议适配

同一份研究,投会议和投期刊是两份不同的稿子——差的不是字数,而是读者假设、篇幅分配和叙述节奏。这条 lens 管「改投另一个 venue」时该动什么、不该动什么,以及超页数时按什么顺序砍。

## 〇、动笔前:venue 差异盘点

拿到新目标,先答四个问题,答案决定后面所有改动:

| 维度 | 要查什么 | 影响 |
|---|---|---|
| 页数/字数上限 | 含不含参考文献与附录 | 压缩优先序从哪一档启动 |
| 审稿人画像 | 窄领域同行 vs 跨领域大刊 | 术语铺垫深浅、背景段去留 |
| 引用体例 | 编号 vs 作者-年份 | 行文中引用的叙述方式 |
| 附录政策 | 允许多长、审稿人是否必读 | 图表与推导能不能外挪 |

## 一、期刊 → 会议:压缩 + 贡献前置

会议审稿人时间碎、稿量大,普遍在第一页定基调。三个动作:

### 1. 贡献前置

期刊导言可以慢热(背景→缺口→贡献),会议导言必须首页收口。

❌(期刊式慢热,贡献在导言第四段才露面):
「近年来,大规模预训练模型在自然语言处理中取得了显著进展……(两段背景综述后)……基于上述观察,本文探讨了参数高效微调的可行性。」

✅(会议式,首页收口):
「……然而,现有方法在低资源场景下仍需全量微调([@houlsby2019])。本文的贡献:(1)提出 LoRA-X,将可训练参数降至 0.3%;(2)在 GLUE 八项上匹配全量微调(差距 <0.4,见 [@tbl:glue]);(3)给出秩选择的闭式判据。」

🔍 会议审稿人在首页找「这篇做了什么、凭什么收」;贡献 bullet 是他们下评语时直接引用的素材,前置等于替他们写好。注意 ✅ 里的贡献必须与实验一一对应——前置不是升格,数字和限定词照抄原稿。

### 2. 相关工作压缩

❌(期刊式逐篇,五段 600 字):
「Houlsby 等 [@houlsby2019] 提出 Adapter,在每个 Transformer 层插入瓶颈模块……Li 与 Liang [@li2021] 提出 prefix-tuning,在输入前拼接可训练前缀……Hu 等 [@hu2021] 提出 LoRA……(每篇一段方法复述)」

✅(会议式聚类,一段 150 字):
「参数高效微调有三条路线:插入式模块([@houlsby2019]; [@pfeiffer2021])、软提示([@li2021]; [@lester2021])与低秩重参数化([@hu2021])。前两者引入推理时延;我们沿第三条路线,但把秩从超参变为可判据选择(与 [@hu2021] 的关键差异见 3.2 节)。」

🔍 聚类句保留了定位功能——读者仍知道你在哪条谱系上、差异在哪——同时砍掉方法复述。复述在会议稿里是页数头号杀手,且会议审稿人本就熟悉这些工作。压完之后一节内部怎么排,归 wl-related-work-structure。

### 3. 压缩优先序(严格按序,砍完一档再看下一档)

1. **删冗余铺垫**:重复的承接句、「众所周知」式背景、每节开头复述路线图(路标全文只保导言一处,细粒度归 wl-signposting)。
2. **合并段落**:功能相同的相邻段(两段都在说动机)合一,砍掉重复的主题句。
3. **压相关工作**:逐篇综述→主题聚类,见上例;完整版可移附录或改引一篇综述。
4. **图表挪附录**:次要消融、超参表、附加样例外挪,正文留一句「完整消融见附录 A([@fig:ablation-full])」——交叉引用键不变,挪动不断链。
5. **(最后手段)方法细节瘦身**:保住「同行能看懂做了什么」的主线,推导细节外挪。

**任何一档都绝不砍:限度声明、伦理声明、负面结果、对己方不利的基线对比。** 用砍这些换页数,审稿人视为遮掩,得不偿失。真要精简限度一节,可收敛措辞但每一条都保留;表述尺度归 wl-rl-limitations-scope。

## 二、会议 → 期刊:扩展 ≥30%

惯例(多数期刊明文或默认):journal version 需约 **≥30% 实质新内容**。算数的:新实验/新数据集/新基线、新的理论分析或证明、扩展的消融与误差分析、失败案例分析。不算数的:改写措辞、拉长导言、把附录原样搬回正文(部分期刊接受搬附录,但别指望只靠它凑数)。

两个必做:

**其一,明确声明与会议版的关系与差异。**

❌ 「本文是我们 XX 2025 会议论文的扩展版本。」
✅ 「本文扩展自会议版 [@ours2025]。新增内容包括:(1)在 X 与 Y 两个新数据集上的评测(第 5 节);(2)对 Z 性质的理论分析与证明(第 4 节);(3)完整的失败案例分析(第 6 节)。新增篇幅约占 40%。」
🔍 编辑与审稿人的第一个动作就是对照会议版找增量;❌ 逼他们自己 diff,还容易被判「增量不足」直接拒。✅ 把增量定位到节号,等于替他们完成核查。

**其二,读者假设反转。** 期刊读者更可能跨领域、且不赶时间:恢复被会议版压掉的背景铺垫,术语首次出现给一句定义,相关工作恢复成结构化的一节,图题注写成可独立读懂的完整句(图的叙事归 wl-figure-narrative)。

## 三、该动 / 绝不动

**该动**:
- 篇幅分配、导言节奏与贡献位置
- 相关工作的粒度(聚类 ↔ 逐篇)
- 术语铺垫深浅(内行读者直接用;跨领域读者先定义)
- 引用的叙述方式:编号体例下少写「[@smith2024] 表明」这种拿引用当主语的句子——渲染成「[12] 表明」不可读——改「Smith 等 [@smith2024] 表明」;作者-年份体例两种都行
- 附录边界、摘要与标题(标题摘要的具体改法归 wl-title-abstract)

**绝不动(别动清单)**:
- 实验结果数字、统计表述、图中数据——换 venue 不是重跑叙事的许可
- 结论强度:会议版写「在 X 场景下有效」,期刊版不能因为篇幅富余就升格成「普遍有效」;新结论只能来自新实验
- 限度声明与伦理声明:一条都不删、不弱化
- 作者顺序与贡献事实

## 四、camera-ready 收尾清单(录用后单独过一遍)

- [ ] **解匿**:恢复致谢、资助信息、机构名;自引从第三人称伪装恢复(「[@ours2024] 提出了……」→「我们此前的工作 [@ours2024] 提出了……」)
- [ ] **资助声明**:按资助方要求的固定句式写全,资助号别漏、别错
- [ ] **artifact/代码/数据链接**:补上正式链接,并确认链接指向的仓库本身也已解匿
- [ ] **重核页数**:camera-ready 常放宽一页,但解匿加回的致谢与链接可能把正文顶出限制;超了回到第一节的压缩优先序
- [ ] **引用条目更新**:「under review」「preprint」条目若已正式发表,在 references.bib 里换成正式出处

## 五、句骨(照抄填空)

- 扩展声明:「本文扩展自会议版 [@____]。新增:(1)____(第__节);(2)____(第__节);(3)____(第__节)。新增篇幅约占 ____%。」
- 外挪指引:「限于篇幅,____ 的完整____见附录 ____([@fig:____])。」
- 贡献前置:「本文的贡献如下:(1)我们提出 ____,首次 ____;(2)我们证明/验证了 ____(见 [@tbl:____]);(3)我们在 ____ 上 ____。」
- 相关工作聚类:「____ 方向的工作([@____]; [@____]; [@____])关注 ____;与之不同,我们 ____。」
- 致谢解匿:「本工作受 ____(资助号 ____)支持。作者感谢 ____。」

## 豁免清单

- 不换 venue、单纯要压字数或扩字数 → 归 wl-expand-compress,别套本条的 venue 逻辑
- 目标 venue 有明文例外(如强制正文含全部消融、禁止附录、结构化摘要模板)→ venue 规定优先于本条的外挪与压缩建议
- 稿子论证链本身有洞,压缩只会更暴露 → 先走 wl-argument 补链,再回来适配
- 双栏↔单栏模板切换导致的图表尺寸、断行问题不归本条——那是排版事实,不是写作决策
