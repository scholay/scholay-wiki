## 深入

**为什么图表的文字面值得单独打磨**。很多读者读论文的顺序是:摘要 → 图 → 结论,最后才回头读正文。图和题注因此要能脱离正文自成一个微型故事;正文的职责不是复述图,而是用一句话把图接到论证链上。一张没有结论的图是噪声,一句"如图所示"是断链。这条视角只管文字面——题注写什么、正文那句接图句怎么写、引用怎么打;至于图里的线画得诚不诚实(误差棒、轴截断),另有专管诚信的视角,别在这里混着改。

**figure-first:先写结论,再放图**。落图(或决定保留一张图)之前,先把这句话补全:「这张图要让读者相信 ___。」能填出一句有信息量的话(不是"展示了实验结果"),这张图才算想清楚,而且填出来的那句几乎可以直接当题注首句。反过来,填不出来的图先别急着删——问它是不是和相邻图讲同一件事,能合并就合并;真的谁的论证也不支撑,再删。

**题注三段式:结论 → 解码 → 读图脚注**。独立可读的题注 = ① 一句陈述式结论(直接说读者该带走什么,不是"X 随 Y 变化")→ ② 解码(每条线、每个 panel (a)(b)、坐标轴含义与单位)→ ③ 读图脚注(误差棒代表什么、n 是多少、`*`/`**` 对应什么)。强刊题注多以点明发现的引导句开头:先给结论,再教读图。

❌「图: 三个模型在四个数据集上的准确率。」
✅「图: 本文方法在四个数据集上均超过两个基线,长尾数据集增益最大(+6.1)。实线=本文,虚线=Baseline-A,点线=Baseline-B;纵轴为 Top-1 准确率(%),误差棒为 5 次运行的 95% CI(n=5)。」
🔍 只改一个特征:题注从「复述坐标轴的名词短语」变成「先陈述结论、再逐项解码」;所有数字与图例都来自图本身,没有引入新信息。

题注首句句骨:「___(本文方法/现象)在 ___(条件/数据集)上 ___(超过/提前达到/保持不变),___(幅度或例外)。」

**正文接图句:点名 + 模式 + 解释**。每张图/表都要在正文被点名一次,且那一句自带内容,不是空指针。句骨:「[@fig:___] 表明 ___(图里观察到的模式),说明 ___(它对论点意味着什么)。」

❌「实验结果如图所示。我们还进行了消融实验。」
✅「[@fig:conv] 中本文的曲线在前 20 个 epoch 就与基线拉开并保持,说明增益来自训练早期的特征对齐,而非后期过拟合。」
🔍 只改一个特征:从「指路牌」变成「模式 + 解释」——图没变,变的是正文替读者把图读了一遍。

**表要有人指出赢家**。表比图更容易变成数字堆,别让读者自己逐列找最优。正文先给结论句,表内把每列最优值加粗、把本文行放在便于对比的位置。

❌「各方法的详细指标见表 2。」
✅「[@tbl:main] 显示本文 F1 较最强基线提升 4.6(0.870→0.916),且召回率不降;各列最优值加粗。」
🔍 只改一个特征:把「在哪看」升级成「看到什么」,并顺手声明表内加粗约定,读者扫表时有视觉锚点。

**多线图别流水账**。一张图七八条线时,逐条复述等于没写。正文只讲读者该记住的那一个对比:哪条线明显更好、交叉点在哪、拐点意味着什么;其余元素交给题注②去解码。

❌「图中,方法 A 的准确率从 62% 升到 78%,方法 B 从 60% 升到 74%,方法 C 从 58% 升到 71%,本文方法从 65% 升到 83%。」
✅「[@fig:acc] 中四条曲线的排序全程稳定,本文方法始终领先且末段差距扩大(83% vs. 次优 78%);各方法具体数值见题注。」
🔍 只改一个特征:从「逐条念数」收敛成「一个对比 + 一个趋势」,只保留支撑该对比的两个数字。

**锚与编号:让编号自己长**。要引用的图/表打上 {#fig:x}/{#tbl:x} 锚,正文一律写 [@fig:x]/[@tbl:x](前面自带"图/表"字,如「如图 [@fig:x]」),绝不硬写"图1""表2"——增删或重排后,写死的编号会集体指错,锚引用会自动跟着长。图按正文首次引用的先后顺序排布,读者视线不用来回跳;从未被引用的图,要么补一句接图句接进论证,要么删。

**改写顺序建议**(拿到一节带图的稿子时):先扫每张图问"它的结论句是什么"→ 补/改题注首句 → 沿正文找每个 [@fig:]/[@tbl:] 落点补接图句 → 最后清查有没有无人引用的图和写死的编号。先解决"图说什么",再解决"正文怎么接",不会返工。

**速查:见到就改(仅文字面)**
- 题注是坐标轴标签的名词短语 → 换陈述式结论句。
- panel (a)(b)(c) 在题注里没解码 → 逐个说明它是什么。
- 正文"如图所示 / 见表X"后面没内容 → 补模式 + 解释。
- 表格甩数字无人指出赢家 → 正文补结论句,表内最优值加粗。
- 写死的"图1""表2" → 换成 [@fig:x]/[@tbl:x]。
- 图从未在正文被引用 → 接进论证或删。

**别动/豁免(展开)**
- **示意图/流程图/架构图**:不承载定量结论,题注写清"这张图帮读者建立什么心智模型"即可(如「图: 本文三阶段流程总览」),不必硬凑数字;但它仍要独立可读,仍要在正文被引用一次并说明它在论证中的位置。
- **诚信问题不在此改**:误差棒该不该画、选 SD 还是 CI、轴截断/双轴是否放大差异、显著性标注是否站得住——这些交给专管图表诚信的视角;这里只负责把图上已有的含义在题注里说清楚(比如误差棒已画就写明口径)。
- **数字照抄**:题注与接图句里的幅度、n、百分比一律来自图表已有数据;填不出来就留 ___ 待作者补,绝不臆造。
- **已经合格的题注别为改而改**:首句已是结论、解码齐全的,最多顺一下语序。
- **图内元素怎么画不归这里**:选色、线型、布局是画图的事;这条视角只改字。
