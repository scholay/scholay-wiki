【结论强度校准 · 让每句话的语气强度恰好等于它背后证据的强度,一分不多一分不少】逐句自查,每条判是/否,判「否」就照动作补:

反 spin(强度对齐主要结局)
- 这句依据的是主要结局吗?若靠次要/亚组/趋势/组内前后变化撑,而主结局未达显著 → 先如实报主结局「未达显著」(给 p 或含无效值的置信区间),再把亮点标为「探索性、待验证」,别让它在摘要/结论冒充胜利。
- 有没有「首次/显著突破/证明了/确立了/彻底解决/state-of-the-art(无并列基线时)」这类强词?有,且无预注册、主结局层面、直接测量的证据 → 降为「我们报告/观察到/在此设定下改进了/结果支持…的假设」。
- 摘要结论的强度=正文能兑现的吗?范围没更广、因果没更硬吧?有落差 → 把摘要往回改,以正文那句为准。

hedging(双向,别超发也别欠发)
- 一句里软化词(可能/也许/大概/在某种程度上/潜在地/倾向于)>1 个?是 → 留最贴切的一个,删其余。
- 软化落在「结果」上了吗?量到的点估计/CI/方向要直陈,别用「可能」否认自己的测量;软化只留给推论(机制/外推/因果/实践含义)。
- 探索性发现被写成定论?是 → 降到证据档位的动词。

因果(动词配得上设计)
- 观察/横断面/相关数据用了因果动词(导致/使/影响/effect of/reduces/drives)?是 → 换「与…相关/伴随/预示/predicts」,并在讨论补一句混杂或反向因果的 limitation。
- 设计够硬(随机对照/干净识别)却过度对冲成「可能也许」?是 → 该说满就说满。

铁律:一个非显著的主要结局,不能被任何次要发现的措辞救活;先认结果,再谈探索方向。校准是双向的——配得上就敢说,配不上才收。

### 这条视角管什么、不管什么
它只管**强度**:同一句主张,证据在手,但语气比证据强(夸大/因果越级)或比证据弱(把扎实结果说虚)。三个内部小节分别对付三种越级方式——反 spin、双向 hedging、因果措辞。**边界**:若症状是「这句主张在正文里根本找不到对应的结果、数字或对照」——那是有没有支撑的问题,归 wl-rl-claim-evidence;这里默认支撑存在,只校准说法的强弱。

诊断落笔时逐句过三问:① 这句依据的是主要结局,还是次要/亚组/趋势/组内变化?② 用了因果动词吗,数据是随机干预还是观察/相关?③ 主语范围有没有越出样本/设定/人群/剂量?任一命中,进对应小节修。

### 小节一 · 反 spin:非显著别用次要发现救场

Boutron 等对随机对照试验摘要的系列研究发现:当**主要结局不显著**时,相当比例的摘要仍在结论里传递「有效」的印象,靠三种手法——① 突出碰巧显著的次要/亚组/组内结果;② 用因果或强措辞包装相关证据;③ 把结果外推到未验证的人群或临床场景。只读摘要的人因此系统性高估证据。三种手法逐一拆:

**类型一:非显著主结果 → 别用次要发现救场**
- before:「我们的干预显著改善了患者预后。」(主要结局 p=0.21,只有某亚组的次要指标 p<0.05)
- after:「主要结局(全因死亡)两组无显著差异(HR 0.94, 95% CI 0.80–1.10)。在预设的高危亚组中观察到方向性获益,属探索性发现,需专门试验前瞻验证。」
- 动作:先给主要结局的真实数(带置信区间),再把亮点如实定性为探索性;摘要同样先认非显著再谈趋势。切忌只报那个碰巧 p<0.05 的组内前后对比,把它写成全局结论。

**类型二:相关/描述性 → 收回因果措辞**(详见小节三)
- before:「增加社交媒体使用会导致青少年抑郁上升。」(横断面相关)
- after:「更高的社交媒体使用与更高的抑郁量表得分相关(r=…);本设计为横断面,无法判定方向或因果。」

**类型三:过度外推 → 把结论钉在测过的边界**
- before:「这些结果证明该模型可安全用于临床决策。」(仅单中心回顾数据)
- after:「在该单中心回顾队列(N=…)上,模型区分度达 AUC=…;前瞻、多中心与临床落地验证仍属未来工作。」
- before:「我们的方法在所有任务上都优于现有方法。」(测了 3 个基准)
- after:「在所测的三个基准上,我们的方法一致优于对比基线;更广任务上的表现有待考察。」
- 动作:补一句显式 scope 通常就够——「在 …(样本/设定)成立;推广到 … 需 …」。凡出现「all / 普适 / 一定 / 必然 / 临床可用」,回头确认测试范围是否真覆盖到那么广,覆盖不到就收回数据边界内。

**强词校准表**(证据不足就替换,而不是加感叹号)

| 触发词 | 何时才配用 | 配不上就改成 |
|---|---|---|
| 首次 / 填补空白 | 确证据完整检索且无并列工作 | 我们报告 / 据我们所知 |
| 显著突破 / 彻底解决 / 无可争议 | 几乎从不 | 在此设定下改进了 / 结果支持…的假设 |
| 证明了 / 确立了 | 主结局层面、预注册、直接测量 | 我们观察到 / 结果与…一致 |
| state-of-the-art | 有同期可比基线并列且注明范围 | 在所测基准上优于对比基线 |
| significant | 统计显著(报 p/CI) | 别用它给非显著结果蹭「重要」的光环 |

### 小节二 · hedging:双向校准,别超发也别欠发

读者把你的动词强度当作证据强度的信号。写「X 导致 Y」等于向读者担保你的设计能排除混杂、能定方向——手里只是横断面相关,这句就是空头承诺。反过来,证据扎实却满篇「可能也许」,把真发现稀释没了,同样失真。目标:零超发、也零欠发。

**证据档位 → 动词/情态强度对照**

| 证据档位 | 可用动词/情态 | 该避开 |
|---|---|---|
| 单个相关/观察性研究 | suggests, is consistent with, may, 可能, 提示, 或与…相关 | 证明, 导致, causes |
| 多研究重复、跨样本稳健、meta | shows, demonstrates, 表明, 一致地支持 | 因果动词(除非每项都是因果设计) |
| 随机对照 / 干净因果识别(IV、RDD、DiD 且前提成立) | causes, 导致, 使…提高, 因果效应为 | — |

调档往「你能兑付的那一档」调,而不是往「你希望的那一档」调。

**over-hedge:堆砌稀释型**
- before:本研究的结果可能在一定程度上暗示,新方法也许有潜在的、倾向于改善性能的趋势。
- 问题:五个软化词叠一起,连「发现了效应」这个事实都被稀释没了。
- after:本研究发现新方法将准确率提高了 4.2 个百分点(95% CI [1.8, 6.6]);这一提升或源于 X。
- 动作:结果直陈(你确实量到了 4.2),只在「机制解释」处留一个「或」。

**under-hedge:把探索当定论型**
- before:数据证明,社交媒体使用导致青少年抑郁水平上升。(横断面相关)
- after:数据显示,社交媒体使用时长与抑郁量表得分呈正相关(r=0.31, p<.01);因果方向以及是否存在反向或共同成因,仍需纵向或干预研究确认。
- before:我们的模型表明特征 A 是决定结果的关键因素。
- after:在本数据集上,特征 A 的重要性排名第一;这是否反映稳定的因果贡献,取决于有无未观测混杂,需在外部数据上复核。

**结果 hedge 与推论 hedge:一条分界线**
- 结果层(直陈,别 hedge):样本内量到的一切——均值、差值、系数、CI、观测到的方向、图表里看得见的模式。这是你亲手算的。坏:两组之间可能存在约 3.2 分的差距。改:两组相差 3.2 分(95% CI [1.1, 5.3])。
- 推论层(该软化,软化是诚实):机制(「这或反映…」)、外推(「在其他人群中可能同样成立」)、因果(「这一关联可能部分由…驱动」)、实践含义(「提示临床上或可…」)。

**强/弱动词分级词库**(照这个换)
- 强(仅高档证据):证明、导致、确立、使…提高/降低、causes、establishes、demonstrates
- 中(重复或强相关):表明、显示、支持、shows、indicates、supports
- 弱(单研究/探索):提示、暗示、与…相关、可能、suggests、is consistent with、may

### 小节三 · 因果:动词配得上研究设计

因果有三层阶梯——**关联**(X 与 Y 一起变)、**干预**(动 X 会不会改 Y)、**反事实**(同一对象若 X 不同,Y 会怎样)。一句话用什么动词,等于承诺「这句可信到第几层」。观察数据只支撑第一层,而 causes / reduces / improves 承诺到第三层。让**动词强度 = 设计强度**。

**先给设计归档**:随机对照 / 干净的自然实验 / 工具变量(需外生且排他)/ 断点 / 双重差分(需平行趋势可信)属「可因果」档;横断面、观察队列、相关分析、纯回归、调查数据属「仅关联」档。

**动词梯度表(由弱到强)**

| 动词 | 承诺 | 何时配得上 |
|---|---|---|
| is associated with / correlates with / 与…相关 | 关联 | 任何观察数据 |
| predicts / is a marker of / 预示 | 时序预测,非因果 | 有前后时间、纯预测建模 |
| is linked to / is related to | 中性关联 | 观察数据的安全默认 |
| influences / affects / drives / 影响 | 弱因果 | 准实验、已控主要混杂 |
| causes / leads to / reduces / improves / 导致 | 强因果 | 随机化或强识别 + 假设已检验 |

**before → after(观察性数据被写成因果时)**
- 坏:*Higher social media use causes increased anxiety in adolescents.*
  好:*Higher social media use is associated with increased anxiety in adolescents; because exposure was not randomized, we cannot rule out reverse causation or confounding.*
- 坏:更高剂量影响了肿瘤缩小。(非随机队列)
  好:更高剂量与更大的肿瘤缩小相关联;由于剂量非随机分配,不能排除按适应证分配造成的混杂。
- 坏:*Exercise reduces depression*(基于问卷相关)。
  好:*Exercise and lower depression co-occur; a longitudinal design would be needed to separate this from depressed individuals exercising less.*
- 坏 Abstract:*We estimate the effect of the subsidy on employment.*(仅前后对比无对照)
  好:*We document an association between the subsidy and subsequent employment.*(若做了 DiD 且平行趋势成立,effect 才配留下。)

**主动交代威胁,别回避**:潜在混杂(「调整 A、B 后仍…,但未测混杂如 C 或残留」)、反向因果(「也可能 Y 驱动 X」)、选择偏倚(「样本为自选加入者,不外推到…」);讨论里留一句 limitation,比被审稿人抓强。

**阈值与例外**
- effect / effect size 的双关:统计里的「效应量」只是关联强度的度量,不自动等于因果效应。观察数据里更安全的说法是 estimated association / adjusted difference。
- 中介 / 调节:mediation 默认「中介—结局无未测混杂」,这层假设几乎从不完全成立,写「consistent with a mediating role」,而非「X 通过 M 导致 Y」。
- 预测型论文:合法地用 predicts,但别中途从 predicts 滑到 prevents / reduces——预测不含干预承诺。
- 机制实验 / 敲除:直接操纵了自变量,强因果动词到位,重点转为效应大小与边界条件。

### 摘要=正文的铁律
摘要往往是唯一被读到的部分,也是三种越级最密集处。写摘要结论时逐句对照正文讨论:强度不得更高、范围不得更广、因果不得更硬。若正文写 associated with,摘要不能写 reduces;若正文承认主要结局非显著,摘要必须同样承认。四处(Methods、Results、Discussion、Abstract)同一关系的动词强度应当一致,最容易偷偷变强的是 Abstract 和标题——定稿前专门回读这两处。

### 边界声明段模板(留占位,别编造数字)
主结局非显著时,在讨论或结论嵌一段如下(方括号处填你论文里的真实值,没有就不填、别编):

> 本研究的主要结局([主要结局名])在两组间未达统计显著([效应量与 95% CI],[p 值])。[次要指标/亚组名] 上观察到的差异属预设/事后的探索性分析,尚未经确证性检验,解读需谨慎,并有待[前瞻性/更大样本/多中心]研究验证。本设计为[横断面/观察队列/随机对照],因此对 [X] 与 [Y] 关系的表述限于[关联/因果]层面;主要威胁包括[混杂/反向因果/选择偏倚],详见局限性。

### 例外与分寸
- 不是要你把所有话都说软。证据够硬(随机、预注册、主结局、效应稳健且带 CI)时,该下的结论要敢下——过度对冲同样削弱论文。
- 机制假说、未来方向可以放开想象,但要**显式标注**为假设/展望,与已证结果分开写,别混成一句。
- 工程/方法类论文若有明确基线与指标,如实说「在该基准上提升了 X 个百分点」不是 spin;spin 是把这一步之遥的改进包装成「解决了该问题」。区别在于:动词强度和范围有没有超过你实际测到的那一格。
- 引言里复述他人已被广泛重复的定论,可用中高档动词——那是领域共识,不是你在超发。
