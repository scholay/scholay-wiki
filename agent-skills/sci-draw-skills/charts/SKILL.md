# 科研绘图 · 数据图/统计图(matplotlib 代码执行)

数据类图表**不手写 SVG、也绝不凭空生成**:你写一段 python(matplotlib),用**用户提供的真实数据**渲染,
把成品**矢量 SVG** 存到 `./out/`。数值来自数据,你只负责选图型、选列、配参数与美化 —— **绝不发明/编造任何数字**。

## 铁律(不可违反)

1. **数据必须来自用户**:用户给了数据(内联表格、CSV/xlsx 路径、或明确数值)才画。数据不足就**问**,不要编造样例数字充数。
2. **不伪造证据图**:本技能只画"从数据渲染的图表",绝不生成/伪造病理/显微/影像/blot 等原始实验证据图(那是造假)。
3. **可复现**:图完全由"数据 + 你的脚本"决定,同数据同脚本重跑结果一致。脚本也可一并留在 `./out/`(便于用户复算)。

## 环境约定(容器已装,直接用)

- python3 + matplotlib + numpy + pandas 已在镜像内。**运行期断网**(bwrap 沙箱),不要试图 pip 装包;只用这三个 + 标准库。
- **必须** headless 后端:脚本开头 `import matplotlib; matplotlib.use("Agg")`(容器无显示,否则报错)。
- **中文标签**:容器装了 Noto Sans CJK。**必须用 `matplotlib.rcParams["font.family"] = "Noto Sans CJK JP"`** —— 注意:字体文件是 `.ttc` 合集,matplotlib 只注册了默认 face 名 `Noto Sans CJK JP`(**不是** `Noto Sans CJK SC`,用 SC 名会 findfont 失败 → 中文渲染成豆腐块)。JP face 同样含简体汉字(Han 统一),中文正常显示。再设 `rcParams["axes.unicode_minus"] = False` 防负号变框。若仍不确定,英文标签最稳。
- **矢量输出**:`fig.savefig("out/<名字>.svg", bbox_inches="tight")`(SVG 首选,出版级、可编辑);需要位图再另存 `.png`(dpi=200)。

## 工作流

1. 弄清:画什么图型、哪些列/变量、给谁看。数据缺失或口径不清就问,别猜。
2. 把数据落进脚本(内联小数据直接写进 python;大数据/文件用 pandas 读用户上传到 cwd 的 CSV/xlsx)。
3. 写脚本到 `./out/<名字>.py`,用 **Bash** 跑:`python3 out/<名字>.py`。
4. **执行器修复**:若报 traceback,读错误、改脚本、再跑,直到成功产出 `./out/<名字>.svg`。别把"能跑"当"画对"——核对轴标签/图例/数据点数量与用户给的规格一致。
5. 简述你画了什么 + 可怎么改(换图型/配色/标注/坐标轴);提醒 AI 图是可编辑草稿需人工核验、投稿按目标期刊 AI 政策在图注披露。

## 常见图型速查

- **通用**:散点/折线/柱/分组柱/堆叠柱/箱线/误差棒/直方图/热图(`imshow`/`pcolormesh`)。
- **临床/统计**(医学论文最高频,全部从用户给的真实统计量渲染,**不做统计推断、不发明数字**):
  - **KM 生存曲线**:用给定的时间点与生存概率画阶梯线(`drawstyle="steps-post"`),可加删失打点、置信带(若用户提供)、risk table。
  - **森林图(meta/亚组)**:每行一个效应量点 + 95%CI 横线(`errorbar`),竖参考线(OR/RR=1 或 MD=0),右侧标注数值。
  - **ROC**:用给定的 FPR/TPR(或用户给的 (score,label) 由你用 numpy 算)画曲线 + 对角参考线,标注 AUC(若用户提供或可从点算)。
  - **漏斗图**:效应量 vs 精度(1/SE)散点 + 伪 95% 漏斗边界。

## 画法准则(与 figures 技能一致)

- 配色克制、色盲友好(别只靠红/绿区分;必要时叠形状/线型)。标签清晰、字号足够、不重叠。
- 去掉多余边框(`spines`),留白充分,图例位置不挡数据。一张图一个 `.svg` 文件,有意义命名。
- 数据点/分类的语义配色一致;误差棒、CI、单位都要标全。

## 交付约束

- 产物在 `./out/`:`.svg`(主交付)+ 可选 `.png` + 可选 `.py`(脚本,便于复现)。图片自包含,不引用外链。
