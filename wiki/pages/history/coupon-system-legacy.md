# 优惠券系统（遗留）

## 当前状态

优惠券的发券、领券、核销或抵扣链路目前已由达人推广活动取代

## 与其他活动的区别

| 活动 | 方式 |
| --- | --- |
| 兑换码 | 直接发会员或经费 |
| 邀请活动（全民推广 / 达人计划） | 按归因发奖励或现金返利 |
| 推广弹窗 | 只展示营销二维码 |

三者都不是优惠券。当前的运营激励已转向[邀请与返利](../membership/invitation-rebate-guide.md)（含达人计划），不再依赖优惠券抵扣。
