# 会员购买、升级与续费规则

## 当前是什么会员，能买什么

| 你现在是 | 可以做 |
| --- | --- |
| Free 或已过期 | 新购 Pro 或 Max（月付/年付） |
| Pro 月付 | 升级到 Max，或续费 Pro（月付/年付都可以） |
| Pro 年付 | 升级到 Max（按年费补差），或续费 Pro 年付 |
| Max 月付 | 续费 Max（月付/年付都可以） |
| Max 年付 | 只能续费 Max 年付 |

不能降级。年付会员不能通过月付把周期改回月度。页面只展示你当前可执行的选项。

## 四种计价方式

| 类型 | 怎么算钱 |
| --- | --- |
| 新购 | 购买一个完整的月或年 |
| 续费 | 在现有到期日后加一个月或一年 |
| 升级 | 对剩余有效期补差价，到期日不变 |
| 升档转年付 | 收目标档整年价，在到期日后再加一年 |

到期日按月或年叠加时，月末日期会自动对齐（比如 1 月 31 日加一个月变成 2 月 28 日）。

## 报价与支付

> 界面示意:升级补差与最终报价

结算页会列出你当前的会员、目标档位、到期日变化和应付金额。升级补差是一次性金额，不是新的月价或年价。

- 同一时间只保留一笔待支付的订阅订单。
- 超过 2 小时未支付的订单会在你新建订单时自动清理。
- 如果其他操作（比如兑换码）已经延长了到期日，原来的升级订单会失效，需要重新下单。
