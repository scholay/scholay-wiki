# 邀请有礼

## 活动状态

活动开启时，"邀请好友"页显示你的 8 位邀请码、邀请链接、二维码和奖励统计。活动关闭时入口会隐藏。

> 界面示意:活动开启且信息加载成功的邀请分享

奖励金额、每日上限和返利比例以邀请页当前显示的规则为准。

## 怎样建立邀请关系

| 规则 | 说明 |
| --- | --- |
| 邀请码 | 注册时选填，可先跳过 |
| 补录 | 没填码的新用户登录后可能看到一次补录提醒 |
| 只能绑定一次 | 邀请关系建立后不能改绑 |
| 不能邀请自己 | — |
| 有时间限制 | 需要在注册后的规定期限内完成 |
| 旧账户 | 不会自动归因，需要本人在邀请页面确认 |

> 界面示意:注册后 · 可跳过的补录提醒

绑定失败不影响注册——新账户本身不会被撤销。

## 奖励规则

- 奖励按绑定当时的活动规则计算，后续活动调整不影响已建立的关系。
- 每日奖励人数有上限，超过上限时关系仍保存但当日奖励不发。
- 好友全额退款后返利不计；部分退款时已发返利会按比例扣回。

## 隐私

你查看邀请记录时，好友的姓名和邮箱会经过脱敏处理。
