# 分享卡片、短链与海报

## 四类分享对象

| 对象 | 链接有效期 | 提取码 |
| --- | --- | --- |
| 论文 | 长期 | 无 |
| 期刊 | 长期 | 无 |
| 文献文件夹 | 永久 / 7 天 / 30 天 | 可选 |
| 公开工具 | 直接分享详情页 | 无 |

## 生成链接与二维码

点击分享后，面板提供复制链接、保存图片和二维码。分享文献文件夹时还可以复制"链接 + 提取码"口令。二维码会带上提取码，扫码者无需再输入。

> 界面示意:分享面板

支持系统分享的手机浏览器会直接打开分享菜单。不支持时复制链接并提示你粘贴到微信等应用。

## 保存海报

论文、期刊和工具会生成信息海报。文件夹海报包含整理人、篇目样本和二维码。点击"保存图片"生成 PNG 文件。

即使图片生成失败，已创建的分享链接仍然有效。

海报中的引用量、分区和摘要来自生成当时的数据快照，不保证以后始终实时更新。
