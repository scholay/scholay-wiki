# 期刊投稿资源下载

## 什么时候能看到

打开[期刊详情](journal-detail-page.md)，如果该期刊有作者指南或 LaTeX 模板，页面会显示下载卡片。没有可用资源时整个区块隐藏。

- 作者指南下载格式为 `.md`。
- LaTeX 模板下载格式为 `.zip`，有 class 名时会一并显示。

> 界面示意:期刊详情与投稿资源

## 会员限制

投稿资源下载是 **Max 专享**。

| 身份 | 看到什么 |
| --- | --- |
| Max 用户 | 直接下载 |
| 访客 / Free / Pro | 看到锁定状态，可前往定价页了解权限 |

锁图标表示资源存在但当前账户没有下载权限，与"期刊没有投稿资源"是两种状态。

## 使用边界

- 下载到的指南和模板是辅助材料，可能随期刊更新而过时。
- 投稿前仍应访问期刊官网核对最新格式、许可与要求。
- "有资源"不等于"已向期刊提交"——Scholay 不提供代投功能。
- 下载失败时页面会保留并提示稍后重试。

- [Scholay Prism](../research-ai/prism.md) — 下载 LaTeX 模板后可以在 Prism 中创建论文项目。
