# 论文详情与页面动作

## 打开方式

每篇论文都有可以单独打开和分享的详情地址。从搜索结果、暂存区、文献集或作者页点击论文，都会在浏览工作区中打开详情标签。

页面会优先显示你刚刚浏览过的论文信息，再从原数据来源补齐完整详情。如果论文来自个人文献集，还可能包含你上传的 PDF 和修改过的元数据。加载失败或论文不存在时，页面会给出说明。

## 页面内容

> 界面示意:论文详情 · 元数据与操作区

详情页从上到下包含：

| 区域 | 内容 |
| --- | --- |
| 标题与作者 | 论文标题、全部作者（可点击查看作者页） |
| 元数据 | 期刊/会议、年份、DOI、来源标识 |
| 摘要 | 论文摘要，可 AI 翻译 |
| 操作行 | 全文、收藏、引用、分享等动作按钮 |
| 参考文献 | 参考文献列表，可逐条打开 |

DOI 右侧的复制图标只复制标识符。OA 标记表示存在开放获取线索，不等于所有版本都可下载。

> 界面示意:论文详情 · 参考文献与内联引用

参考文献区的"共 N 篇"是当前取得的参考文献条数，不能与论文的被引次数混淆——前者是"这篇论文引了多少"，后者是"多少人引了这篇"。

## 可用动作

| 动作 | 说明 | 出现条件 |
| --- | --- | --- |
| 打开全文 | 打开用户上传的 PDF 或合法 OA 原文 | 有可用 PDF |
| 上游原始链接 | 跳转到出版社或数据源页面 | 有外部 URL |
| 收藏 | 加入个人文献集 | 登录 |
| 引用 | 弹出引用格式选择 | 有元数据 |
| 翻译 | AI 翻译标题和摘要 | 登录，有额度 |
| 分享 | 复制论文详情链接 | 始终可用 |

按钮会按登录状态和数据完整度出现或隐藏。例如：没有 PDF 时不显示全文按钮；来自个人文献集的自由文件没有上游来源，不显示收藏和外链。

"读者笔记与讨论"目前只是"研究论坛即将上线"占位，暂时没有功能。
