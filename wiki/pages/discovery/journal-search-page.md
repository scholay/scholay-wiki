# 期刊检索页

需要找期刊时，进入期刊搜索页。这个入口与论文搜索是分开的——论文搜索找论文，期刊搜索找期刊。

## 搜索

在搜索框中输入刊名、ISSN 或主办机构即可查找。不输入关键词时，页面按影响因子从高到低显示默认列表。

> 界面示意:期刊搜索 · 相关度排序、筛选收起

## 五组筛选

| 筛选维度 | 选项 |
| --- | --- |
| 中科院分区 | 1–4 区 |
| JCR 分区 | Q1–Q4 |
| 影响因子 | ≥5 / ≥10 / ≥20 / ≥30 |
| CCF 等级 | A / B / C |
| 出版社 | Nature Portfolio / Elsevier / IEEE / Springer / ACM |

每组单选，"不限"清除该维度。任一条件变化后自动回到第一页。

## 排序

提供相关度、影响因子和"最新"三种排序。注意：这里的"最新"实际按 OpenAlex 收录的论文数量排列，不是按创刊日期排列。

## 分页

每页固定 8 条。关键词、页码、排序和筛选保留在页面地址中，从详情返回时可以恢复。无法取得准确总数时，只显示上一页和下一页。

## 点击结果进入详情

点击期刊卡片进入[期刊详情页](journal-detail-page.md)，查看完整的标识、指标和投稿资源。

侧栏中的文件夹只是前往文献集的快捷入口，不代表期刊已经被收藏。
