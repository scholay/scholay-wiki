# PDF 阅读器

需要直接阅读论文原文、核对图表和公式时，用 PDF 阅读器。它在浏览器中翻页显示原始 PDF 页面，不改变文件内容。

## 打开方式

在论文详情或个人文献集中点击全文入口，PDF 会在阅读器中打开。阅读器和论文详情分别保留在浏览工作区的标签中，可以来回切换。

> 界面示意:PDF 阅读器 · 已载入、单页自适应

## 阅读操作

| 操作 | 说明 |
| --- | --- |
| 翻页 | 上下滚动或使用页码跳转 |
| 缩放 | 自适应、按页宽或手动缩放 |
| 布局 | 单页、连续页、双页三种布局切换 |
| 全屏 | 只改变查看空间，不改变 PDF 文件 |

阅读器内置中日韩文字所需的 CMap 资源，大多数学术 PDF 都能正常显示。

## 全文可用性

能否打开全文取决于论文是否提供合法文件：

- 论文记录中有开放获取 PDF → 可以直接打开
- 个人文献集中有你上传的 PDF → 可以打开
- 只有元数据链接 → 不能当作可下载 PDF

系统有可能存在找不到可合法访问文件的情况，请不要把元数据页面链接当作全文入口。

- [开放获取全文与翻译](open-access-and-paper-translation.md) — OA 查找流程和 Unpaywall 来源说明。

## PDF 阅读器 vs PDF 对话

阅读器是翻页阅读工具。如果你需要让 AI 帮你读论文、提取信息或比较多篇文献，应该到[智能助手](../research-ai/claw.md)中上传 PDF 并提问。二者之间没有自动同步——在阅读器中打开一个 PDF 不会让智能助手也拿到它。

- [如何与 PDF 对话](../research-ai/pdf-chat-guide.md) — 在智能助手中上传 PDF 并围绕内容连续提问。
