# 期刊详情页

从搜索结果或分享链接打开期刊详情，可以集中查看一本期刊的身份信息、质量指标和投稿资源。

## 页面内容

> 界面示意:期刊详情与投稿资源

| 区域 | 包含什么 |
| --- | --- |
| 身份信息 | ISSN、出版社、国家、期刊/会议类型 |
| 质量指标 | JCR 分区、中科院分区、CCF 等级、影响因子、OpenAlex h-index |
| 风险信号 | 预警信息（有数据时显示） |
| 开放获取 | OA 状态 |
| 年度趋势 | 影响因子年度变化（样本充足时显示） |
| 投稿资源 | 作者指南和 LaTeX 模板（有数据时显示） |

点击 ISSN 可以前往官方 ISSN Portal 核对注册信息。

## 怎么读

1. **先确认身份** — 用 ISSN 确认是同一本刊，不要只看刊名。
2. **分别记录不同体系的分区** — JCR Q1 和中科院 1 区是不同体系，不能直接等同。
3. **指标只在有数据时显示** — 字段缺失可能是来源没有返回，不能直接解释为"指标为零"。
4. **决策卡是摘要** — 多项信息的摘要，不构成投稿或录用保证。

- [期刊指标怎么看](journal-metrics-guide.md) — 逐项理解每个指标的含义、来源和正确读法。

## 当前限制

- 详情支持复制与分享，但当前没有"收藏期刊"功能。
- 空字段不会用虚构值补齐。
- 投稿资源的可用性取决于期刊是否有文件以及账户权限。

- [期刊投稿资源下载](journal-submission-resources.md) — 了解下载条件和会员限制。
