# 功能页面与元素说明

这篇帮你认识 Scholay 页面中反复出现的通用元素，避免把导航当功能、把过程指示器当最终结论。

## 汉堡菜单与浏览器页签

**汉堡菜单** — 窄屏顶栏的统一导航出口。视口小于 1200 px 时，宽屏上平铺的入口会收进这颗按钮。点击路由项进入对应页面，点击活动项打开弹层。

**浏览器页签** — 详情页面顶部的标签栏，用来并行保留多个研究对象（论文、期刊、学者、PDF）。点击标签切换，"×"关闭当前标签，"+"按题名或 DOI 快速打开论文。全部关闭后回到首页。

浏览器入口只在至少存在一个详情标签时显示。这组标签有时被口头称为"拓展区标签页"，但它不是 Claw 右侧的"扩展区"。

## 参考文献基础信息卡片

搜索结果、智能搜索和文献选择器中反复出现的论文摘要单元。它帮你判断"要不要打开这篇论文"，不是完整书目记录。

| 区域 | 说明 |
| --- | --- |
| 题名 | 点击打开论文详情 |
| 来源、作者、年份 | 期刊和作者可点击进入详情 |
| 评价标签 | JCR、中科院、CCF、影响因子、被引数——不同体系，不能互相替代 |
| 摘要 | 默认两行，缺少不等于论文没有摘要 |
| 动作区 | 暂存、收藏、原文链接、翻译各自独立 |

> 界面示意:通用元素 · 参考文献基础信息卡片

## 扩展区与文件树

**扩展区** — Claw 及部分 Agent 功能中位于对话之外的交付物工作面。桌面端通常显示为右侧分栏，窄屏改为整屏面板。收集本会话生成的文档、表格和演示文件；文件夹会打包为 ZIP。

**扩展区标签页** — 只在被预览的文件包含多个视图时出现（如 XLSX 多个工作表）。它切换同一文件内的视图，不切换会话或论文。

**文件树** — Prism 项目内的源文件导航。点击文件行载入编辑器，行尾菜单可重命名或删除非主文件。AI 正在生成待审改动时，文件操作暂时禁用。

> 界面示意:通用元素 · 扩展区、工作表标签与文件树

## 工具调用、推理过程与额度/进度

**工具调用卡片** — 显示智能体正在调用检索、读取或分析工具。展开可查看入参和结果。单次工具失败不一定等于整轮失败。

**推理过程** — 可折叠的过程提示，解释"当前在做什么"。它不是参考文献或学术证据。

**剩余额度** — 回答"这一周期还能用多少 AI 能力"。百分比和恢复时间。

**进度条** — 回答"当前任务做到哪一步"。例如智能审稿阶段 1/5。

额度和进度外观相近但含义完全不同——不要把任务完成 68% 理解成额度还剩 68%。

> 界面示意:通用元素 · 智能体过程、额度与任务进度

推理过程和工具卡用于解释执行状态，不构成学术证据。引用结论时，回到论文来源或最终报告核对。
