# 移动 Web

## 移动导航

手机网页底部有“浏览 / AI Claw / 功能 / 我的”四个入口。点击“浏览”查看论文信息流，点击“我的”进入账户、文献集和设置；下图分别展示信息流，以及已登录并包含账户资产的“我的”页。第二张图的额度条表示剩余比例，“用经费继续”处于关闭状态；这与桌面账户资产示例中的开启态是两个不同配置状态。搜索会打开独立的移动搜索页，文献集则从“我的”等入口进入。

## 能力差异

点击移动端搜索入口后，输入关键词即可查看结果，并从筛选面板调整时间、来源等条件；下方三张图依次展示期刊结果、论文结果和论文筛选面板。

移动端优先覆盖浏览、对话和账户等高频动作。Prism、完整审稿和矩阵等需要大屏的工作区目前以电脑端为主，手机上会提供对应入口或明确提示改用电脑。
