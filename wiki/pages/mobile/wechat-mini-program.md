# 微信小程序

## 四个主入口

底部 Tab Bar 提供"浏览""AI Claw""功能""我的"四个入口，对应信息流、研究对话、工具目录和账户中心。

## 页面范围

小程序还提供登录、搜索、论文、期刊、作者、新闻、工具详情、文献集、计费、资料编辑和修改密码页面。

Claw 回答中的图表和科学示意图可以点击进入独立查看页缩放检查。

> 界面示意:小程序 · 独立图表查看器

## 与 Web 的差异

微信登录、分享、剪贴板和内容安全受小程序平台约束。需要复杂编辑器、大屏对比或本地文件的流程以 Web 为主。
