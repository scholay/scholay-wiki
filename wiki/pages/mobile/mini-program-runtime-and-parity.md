# 微信小程序页面、端间差异与内容安全

## 小程序有什么

四个主要入口（浏览 Feed、AI Claw、功能广场、我的）加上登录、搜索、论文、期刊、作者、新闻、工具详情、文献集、计费、资料编辑和修改密码页面。

打开小程序不需要先登录，需要账户的操作会在使用时提示登录。

## 小程序中的 Claw

支持创建和管理会话、流式输出（包括思考过程、Markdown、表格和公式）、工具调用过程展示、停止生成、模型选择、图片和文件上传、文献库引用和交付物查看。需要在电脑上处理的交付物会提示到网页版操作。

## 目前只在网页版有的功能

| 功能 |
| --- |
| 独立智能搜索页 |
| 智能审稿（Peer Review） |
| 智能写作（Prism） |
| 幻灯片、科研绘图、统计分析 |
| 会员购买和支付 |
| 完整的学术 PDF 阅读器 |

Feed 筛选功能标注为"即将上线"，尚不可用。如果你在网页版看到的某个功能在小程序中找不到，很可能是还没有上线小程序版。
