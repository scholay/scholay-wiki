# 移动 Feed：论文、期刊与情报

## 三条信息流

| 频道 | 内容 |
| --- | --- |
| 论文 | 多来源轮换，偏向较新的论文 |
| 期刊 | 按影响因子大致排序，有"下一刊"预览条 |
| 情报 | 可切换"实时"和"热榜" |

横向滑动切换频道，上下滑动浏览卡片。下拉刷新会换一组推荐。

## 卡片上能做什么

| 对象 | 可用动作 |
| --- | --- |
| 论文卡 | 查看作者和引用、分享、收藏/取消收藏（需登录） |
| 期刊卡 | 分享 |
| 情报卡 | 浏览 |

论文卡和期刊卡目前不能直接打开详情页。收藏图标会先即时变化，最终以文献集是否保存成功为准。
