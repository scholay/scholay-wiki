# Scholay 内容维护

[打开 Excalidraw 总导航](boards/Scholay.excalidraw.md) · [文字导航](导航.md) · [全部词条](索引.md)

正文保存在 `wiki/pages/`；Excalidraw 结构节点链接这些 Markdown 文件。从画布节点打开编辑器和在 Obsidian 中编辑，操作的是同一份正文，无需双向复制或后台同步。

## 在项目内使用工作台

双击项目根目录 **`打开内容工作台.command`**，或执行：

```bash
python3 tools/workbench/launch.py
```

打开本地地址 `http://127.0.0.1:8765`。首次需要 Node.js、npm、Python 3，脚本会安装并构建界面；以后复用已运行的本地服务。服务只监听本机，不上传正文或画布。

首页展示研究路径，左侧可切换16组功能结构和8类内容分类。点击节点在右侧编辑对应词条；点击顶部主题按钮聚焦分支。「整理结构」模式可移动节点、修改连线和添加批注。停止输入约 0.65 秒后自动写入原始 Markdown，也可以按 Cmd/Ctrl+S 保存。画布布局和批注同样自动保存到项目的 `.excalidraw.md`。

Obsidian 修改文件后，工作台每 1.2 秒检查一次外部变化，更新未改动的正文和画布。浏览器与 Obsidian 操作同一份文件；这不是另建文档副本。

两端都编辑时，工作台保留本地草稿并显示冲突。正文可以查看外部版本，选择「采用外部版本」或「保留我的修改」；画布也需明确选择。编辑器不会悄悄覆盖已经检测到的外部版本。保存失败可以重试；未保存正文和画布会在浏览器保留恢复草稿。请注意状态提示，出现冲突或错误时先处理再关闭页面。

每次文件覆盖前备份到 `.local/workbench/backups/`。正文编辑保留 YAML 属性和一级标题；正式改名按下方 catalog 流程处理。画布新元素 ID 会转换成 Obsidian 支持的 8 位 ID；常见本地图片附件可以往返使用。PDF/公式等 Obsidian 专有嵌入仍保留原映射，项目工作台暂不负责渲染它们。

## 在 Obsidian 内使用画布

1. 在 Obsidian 中「打开文件夹作为仓库」，选择本项目根目录 `scholay`。
2. 在设置 → 第三方插件中安装并启用 **Excalidraw**（作者 Zsolt Viczian，插件 ID `obsidian-excalidraw-plugin`）。它是社区插件，不是 Obsidian 内置功能。本次迁移使用版本 2.27.3。
3. 打开上方「Excalidraw 总导航」，通过链接进入功能树或分类主题树。也可双击根目录 `打开Obsidian画布.command`。

Excalidraw 是开源软件，Obsidian 本体不是开源软件。画布使用插件的 `.excalidraw.md` 格式；普通 Excalidraw 网页不能提供 Obsidian 仓库内的 Markdown 编辑能力。

## 两个视图，编辑同一份正文

- **文字视图**：通过导航或文件列表打开词条，像平常一样编辑 Markdown。
- **画布视图**：节点展示词条标题，通过节点链接打开原 Markdown。分类 → 主题 → 词条以绑定实线连接；总览用箭头表达常见研究路径，用虚线表达跨阶段支持。
- **可视化整理**：拖动、缩放节点，添加连线、颜色、手写注释或新图形。图形和批注保存在画布，正文改动保存在词条文件。
- **双向跳转**：Obsidian 反向链接可找到引用当前词条的画布；画布节点可打开原词条。

总览、16组功能树和8类主题树共25张画布。主题分类覆盖全部96篇词条，每篇在所属分类中出现一次；功能树保留原导航的多层结构和快捷入口。

## Obsidian 原生 Graph View

核心关系图已开启。点击 Obsidian 左侧的关系图图标，即可看到节点和关联；滚轮缩放、拖动平移、点击节点打开文件。文章菜单中的「打开局部关系图 / Open local graph」可只看当前文章及邻居，并按深度展开。

- 默认范围是 `wiki/pages/` 与 `wiki/topics/`，排除画布文件、线上导入快照和导出副本，按8个分类着色。
- 96篇词条已接入319条有效有向关联，合并双向重复后为247条关系；另有根索引、8个分类和36个中文主题索引，方便看懂内容归属。
- 原生节点名称取文件名：现有文章显示英文 slug，主题索引显示中文。悬停或点击可进一步阅读。
- `scholay_related` / `scholay_topics` 是受维护的 YAML 链接属性；正文段落保持不变。要添加自由关系，可以在正文或其他属性中写 `[[词条路径]]`，Graph View 会自动识别。
- catalog 中21条关联指向6个尚未收录的目标，暂不生成链接或空页面；检查记录在 `.local/graph-links/report.json`。

Excalidraw 的布局和连线表达手工整理的结构，原生 Graph View 展示实际文件双链。移动节点不会改变文章分类或网站导航。

修改普通正文后直接保存即可；不要运行旧 XMind 同步器。画布布局不等于网站分类或导航顺序，自由连线也不会自动改变网站目录。

## 调整词条、分类与目录

`wiki/catalog.json` 继续管理稳定 slug、分类、文件路径和网站导航。新增词条时创建 Markdown 并登记 catalog，同时在 `wiki/structure.json` 指定语义主题；修改标题时同时更新 YAML title、H1 和 catalog title；移动分类时更新 YAML category、catalog category 和需要变更的路径。

保存并关闭相关画布标签后运行：

```bash
python3 tools/wiki/sync.py status
python3 tools/wiki/sync.py refresh
python3 tools/wiki/links.py refresh
python3 tools/wiki/export.py
python3 tools/wiki/sync.py verify
python3 tools/wiki/links.py verify
```

日常刷新维护生成节点的标题、链接及绑定关系，保留已存在节点的位置、大小、样式、用户图形与附件。新增节点按结构放置，新增连线使用实际父节点位置；布局需要重排时可显式执行 `sync.py refresh --layout`，先备份再重排生成节点，保留自由批注。移除词条时把对应生成节点标记为删除，不删除正文文件。旧分类画布保留供人工归档。

如果你修改或删除了生成节点的标题/链接，或改接了受维护连线的目标，刷新会报冲突并停止。先核对 catalog 与画布，再恢复或统一相关节点；不要删除 `customData.scholay` 标记来绕过检查。自由批注请新建文本元素。标题调整较长时可手动调整布局。

原生关系刷新会保护人工修改过的生成属性和主题索引；主题改名时，未手改的旧索引会在备份后移除，避免留下过期边。关系文件备份在 `.local/graph-links/backups/`。

刷新前将被改写的画布备份到 `.local/excalidraw/backups/`，无变化的画布保持字节不变。支持读取插件保存的普通 JSON 和 compressed-json。刷新工具需要 Python 3；读取压缩格式还需要 Node.js。正文日常编辑不需要这些工具。

## GitHub Wiki

```bash
python3 tools/wiki/export.py --github
python3 tools/wiki/prepare-github.py
```

导出正文、Home、侧栏和页脚到 `build/github-wiki/`，画布用于本地维护，不作为交互页面发布到 GitHub Wiki。准备脚本只准备独立 Wiki 仓库的 diff，不提交或推送。发布需按当次指令执行，并核对远端修改。
