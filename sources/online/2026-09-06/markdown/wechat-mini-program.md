# 微信小程序

## 四个主入口

自定义 Tab Bar 提供“浏览”“AI Claw”“功能”“我的”四个入口。它们对应信息流、研究对话、工具目录和账户中心，而不是把桌面站完整嵌入 web-view。

## 页面范围

小程序还提供登录、搜索、论文、期刊、作者、新闻、工具详情、文献集、计费、资料编辑和修改密码页面。在 Claw 回答中遇到图表或科学示意图时，点击图形可以进入独立查看页进行缩放和检查；下图展示的就是这个图形查看状态。

> 界面示意:小程序 · 独立图表查看器

## 端能力边界

微信登录、分享、剪贴板和内容安全受小程序平台能力与审核规则约束。需要复杂编辑器、大屏对比或本地文件能力的流程仍以 Web 为主。
