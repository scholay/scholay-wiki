# 文献图谱：当前状态与使用边界

## 当前没有独立文献图谱

现行前端没有文献图谱专用路由、画布或节点—边交互组件，因此不能把“查看引用量和参考文献”描述为已经上线的可视化文献图谱。本词条标记为“计划”，用于说明边界，不代表已经提供可操作入口。

传统搜索中的数据源名称“Graph”也只是来源品牌名称，不等于文献图谱功能。选择 Graph 会改变检索来源，不会打开关系网络。

## 现在可以使用的关系信息

论文详情可以显示被引用数量和参考文献数量，并按需加载参考文献列表。列表中的条目如果有站内论文标识，可以继续打开对应论文详情；只有外部 URL 时则跳到外部页面。参考文献较多时，界面分批显示，避免一次挂载全部条目。

这套能力适合从一篇种子论文逐条向后追溯，但它仍是列表导航，不提供全局网络布局、聚类、路径分析或图谱导出。

## 尚未提供的图谱能力

下面的图是设计预览，用来说明未来的文献图谱可能怎样呈现节点、连线和聚类；它不是当前可操作页面。现阶段，Scholay 不能把多篇论文自动绘制成关系网络，也不能在画布中按作者、年份、主题或共同引用聚类；图谱缩放、路径追踪和网络数据导出同样尚未开放。

论文详情中的引用计数只是元数据字段，不能据此认为你已经查看了完整的被引网络。

## 上线前如何做引用扩展

可以先打开高相关论文的参考文献列表寻找奠基工作，再在智能搜索中要求沿“参考文献、被引工作、相关论文”分别扩展，并把确认过的论文加入暂存区。这样能完成检索层面的滚雪球，但结果仍应按清单核对，不能声称已经做过图谱聚类或网络分析。

- [用追问完成滚雪球检索](https://www.scholay.com/wiki/smart-literature-search-guide#guide-the-search) — 按奠基工作、近期进展或范围收窄逐轮扩展，并只比较每轮新增结果。
