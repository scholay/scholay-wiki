# 功能广场

## 目录

进入功能广场后，你可以按分类浏览工具卡片，也可以搜索关键词，再用形式与价格条件筛选。手机端从工具首页进入目录，筛选条件会在底部面板中展开。下方四张图依次展示桌面目录、移动工具首页、移动目录和移动筛选面板。

## 访问方式

点击工具卡片后，页面会按实际字段显示使用场景、功能、价格、获取方式、替代品、教程，以及有数据时的常见问题；再按页面按钮访问网站或下载资源。下图分别展示桌面详情、移动详情，以及手机遇到仅支持电脑的工具时出现的引导页。第三张以智能审稿为例；其他仅支持电脑的工具会显示自己的名称、能力清单和可复制地址。

外部工具由各自提供者负责，Scholay 的收录不代表对其安全性、效果或持续可用性作出保证。

## 内容运营

管理员可以维护工具条目、批量导入数据，并设置内容变化通知。导入页面会依次显示等待处理、处理中、成功、部分成功或失败，便于发现需要补录的条目。

工具在产品里公开后，还要经过单独审核才会被搜索引擎收录；批量导入不会跳过这一步。工具图片统一保存，暂时没有图片时会显示默认样式。
