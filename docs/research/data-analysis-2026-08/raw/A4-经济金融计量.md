## 0. 一句话结论（先给判断，再给证据）

**这个圈子不缺"能跑回归的工具"，缺的是"把一堆脏表变成一张可以贴进论文的三线回归表"的那一整条流水线。**
他们的痛不在"我不会做固定效应"，而在：数据合不上（股票代码丢前导零）、xtset 报错、导出 Word 中文乱码、
平行趋势检验不通过、审稿人问内生性答不上来。而他们愿意为此付的钱，**低到令人意外**（竞品会员 ¥29.9/60 天）。

## 1. 群体画像：这个学科里，谁在亲手做数据分析？

### 1.1 三类人，第一类占绝对多数

| 人群 | 干什么 | 统计训练水平 | 量级 |
|---|---|---|---|
| **经管硕士生（学硕+专硕）写毕业论文** | 一篇「实证三件套」论文，2–4 个月完成 | 上过一学期《计量经济学》，会照着教程敲代码，不理解假设 | 绝对主力 |

量级：国家统计局口径 2024 年全国在学研究生 409.5 万人、全年招生 135.7 万人
（来源：国家统计局 2024 年国民经济和社会发展统计公报，经 DuckDuckGo 检索摘要转引，2026-08-04 访问）。
**经济学 + 管理学两大门类的分学科研究生人数没取到**（教育部「分学科研究生数」页面在本次抓取中 302 循环，
`www.moe.gov.cn/jyb_sjzl/moe_560/...` 未能读取）—— 标**未核实**。经验上经管是研究生规模最大的门类之一，
但本报告不给具体百分比。

### 1.2 关键特征：他们是"一次性用户"，不是"长期分析师"

硕士生做完毕业论文这辈子基本不再碰 Stata。这决定了两件事：
- **学习成本不可摊销** → 他们不会为"学会一个更好的工具"投入；只想这一次赶紧过。
- **交付物极度标准化** → 因为大家抄的是同一套模板（见 §7），所以自动化的天花板很高。

## 2. 数据长什么样

### 2.1 典型形态

- **主流：中国 A 股上市公司面板**。样本量 n ≈ 2 万–5 万（公司-年观测），
  例如 2008–2019 年、约 3000 家公司 × 12 年，剔除 ST / 金融业 / 缺失后剩 2 万上下。
- 变量数：解释变量 1–3 个 + 控制变量 8–15 个（Size、Lev、ROA、Growth、Age、Top1、Board、Dual、SOE…）
  + 行业固定效应 + 年份固定效应。
- **其他形态**：省级/城市面板（31 省 × 20 年 ≈ 600 观测，n 极小）、CFPS/CHFS 微观调查数据、
  海关数据库（千万行级，Stata 会内存告急）、问卷数据（管理学分支，n = 200–500）。

### 2.2 脏在哪 —— 全是"合并前"的问题

来源生态（高校统一采购，学生校园网内免费下）：

| 数据库 | 定位 | 高校采购价（招标公告） |
|---|---|---|
| **CSMAR 国泰安** | 学术研究标配，单一来源采购 | 深圳大学 2023 年 **49 万元/年**；上海财经大学 2025 年 **70 万元**；上海大学 2025 年 **49.8 万元**；武汉大学 **48.8 万元** |
| **Wind 万得** | 金融从业口径，实时性强 | 未核实 |
| **CNRDS** | 对标 WRDS 的"中国版"，个人账号也可买 | 未核实 |
| **中国统计年鉴 / 城市统计年鉴** | 宏观区域经济，PDF/合并单元格为主 | 免费 |

> 来源：CSMAR 采购价格经 DuckDuckGo 检索多份高校招标公告（bidding.szu.edu.cn / zhaobiao.sufe.edu.cn /
> qianlima.com / hub.zhiliaobiaoxun.com），2026-08-04 访问。置信度 medium-high（多源一致），
> 单条公告原文未逐一点开核对。

**具体脏点（每一条都有真实报错做支撑）：**

1. **股票代码前导零丢失** —— CSMAR 导出 Excel，`000001` 进 Stata 变成 `1`，两张表 merge 全部匹配不上。
   修法 `tostring Stkcd, replace` + `format %06.0f`。
   （来源：zhuanlan.zhihu.com/p/557331662；bbs.pinggu.org/thread-1517361-1-1.html，经检索摘要，2026-08-04）
2. **字符串里混了空格 / 百分号** —— 导入后变量在 Stata 里显示成红色（字符串），跑回归直接 `no observations`。
   修法要写循环 `replace \`x'=trim(subinstr(\`x',"%"," ",.))` 再 `destring`。
   （来源：bbs.pinggu.org/thread-853258-1-1.html）
3. **省份/城市名对不齐** —— "内蒙古" vs "内蒙古自治区"、带空格、繁简，merge 掉一半。
   修法 `strtrim` + 手工对照表。（来源：blog.csdn.net/Triumph19/article/details/127893129）
4. **年鉴 PDF 的合并单元格** —— "原本对齐的列被挤成一团，合并单元格被拆散成碎片"，
   宏观论文的省级面板常常是人肉一格一格粘出来的。（来源：DuckDuckGo 检索摘要，2026-08-04）
5. **面板不平衡 / 中间断年** —— 公司 2008–2019 中间几年没数据，学生第一反应是"要不要插补"。
   论坛共识是**直接删**，不要插补。（来源：bbs.pinggu.org/thread-11783128-1-1.html）
6. **缺失编码** —— CSMAR 里的空值有时是空字符串、有时是 0、有时是特殊码，`destring` 后静默变成 0。

## 4. 用什么软件，为什么

### 4.1 Stata 的统治力

- **AEA 复现包口径**：Vilhuber, Turrito & Welch (2020) 统计，自 AEA 数据公开政策实施以来，
  **73% 的作者提交的补充材料使用 Stata**。
  （来源：aeadataeditor.github.io 相关页面与 stata.com/users/epinzon/blog/aea.txt 转引，2026-08-04）
  ⚠️ 网上广泛流传的"AEA 对经济学家的问卷调查显示 73% 用 Stata、4% 用 R、2% 用 Python"这个说法
  （见 econ-jobs.com/media/python-vs-r-vs-stata-economist-jobs-2026/）**很可能是对上述复现包统计的误传**，
  73% 这个数字是"复现包占比"不是"人员占比"。**标：来源存疑，勿引用为问卷数据。**
- AEA 数据编辑办公室 2025 年 5 月的说法：Stata 的主导地位反映了**软件与程序的稳定性、以及复现既有研究的便利**。
  （来源同上，置信度 medium）

### 4.2 为什么经管圈是 Stata 而不是 SPSS

中文社区给出的四条理由高度一致（来源：知乎 question/1897050122573026100 与 question/373483847、
bbs.pinggu.org/thread-6918132-1-1.html、cloud.tencent.com/developer/article/1043243，均 2026-08-04 检索）：

1. **学科定位不同** —— "SPSS 是统计学软件，Stata 是计量经济学软件"。SPSS 服务问卷/量表，Stata 服务因果识别。
2. **面板数据是硬分水岭** —— "SPSS 对于数据的区分不够精细，在横截面数据和面板数据的区分方面缺乏简单易行的操作方式"。
   `xtset` + `xtreg` + `reghdfe` 这条链在 SPSS 里没有对等物。
3. **路径依赖是决定性的** —— "国外 top 期刊论文公布的代码基本都是 Stata 代码"；导师给的 do 文件是 Stata 的、
   师兄师姐的模板是 Stata 的、连享会/经管之家的教程是 Stata 的。**学生不是在选工具，是在继承工具。**
4. **输出格式** —— "在结果输出方面也有很好的包，可以将结果按照论文格式输出到 doc 文件或 csv 文件"
   （即 `esttab`/`outreg2`）。这条经常被低估，但它是最实际的锁定因素。

### 4.3 其他软件的位置

- **EViews**：本科时间序列教学的默认工具，点选式界面，清华社《计量经济分析方法与建模：EViews 应用及实例》
  等教材成体系。（来源：www.eviews.com.cn/、tup.tsinghua.edu.cn 书目页，2026-08-04）
  → 特征：**本科用、时间序列用、写完论文就丢**。
- **R / Python**：C 刊层面几乎不出现在经管实证的主流程里；博士生做机器学习/文本分析时才用。
- **正版率**：Stata 商业单机版价格在数千美元量级（stata.com 教育许可页面显示的是院校 site license 口径），
  学生几乎全部走**校园 site license 或破解版**。具体破解版占比**未核实**，不给数字。

## 5. 真实卡点（最重要的一节）

下面每一条都精确到"哪一步、哪句报错"，并尽量配原声。

### 卡点 1：数据合不上（merge 静默失败）

最典型：`merge 1:1 Stkcd year using ...` 之后 `_merge==3` 只有几百条。原因是股票代码类型/前导零/空格。
学生的症状是**不报错，但样本量莫名其妙从 3 万掉到 800**，而他们不会去看 `_merge` 分布。

### 卡点 2：`xtset` 三连报错

- `string variable not allowed` → 需要 `encode`
  > 原声（violet6，经管之家 Stata 专版）：
  > **"tsset state year 提示 varlist: state: string variable not allowed 错误，state 是字符串变量只能是数字变量，
  > 知道原因了，那么怎么办呢"**
  > （https://bbs.pinggu.org/thread-7261727-1-1.html ，2026-08-04 访问）
- `repeated time values within panel` → 同一 id-year 有重复行，需 `duplicates report id year`。
  Stata 官方 FAQ 措辞是"绝对规则，不允许例外"。
  （https://www.stata.com/support/faqs/data-management/repeated-time-values/ ）
- `variable not found` 但数据里明明有 —— 实际是缺失值或滞后项没生成。
  > 原声（accumulation，经管之家）：
  > **"运行 stata 动态面板模型 一直显示 variable not found 但数据确实有，求助！"**
  > 报错具体是 `variable rd not found`，跑的是 `xtabond2 rd l.rd rd2 abse cgi...`。
  > （https://bbs.pinggu.org/thread-6352850-1-1.html ）

### 卡点 3：回归跑出来 `no observations`

Excel 导入后数值列里混了 `%`、逗号、空格，变量实际是字符串。
> 原声（solor1211，经管之家）：
> **"学习 stata 做数据分析，从 EXCEL 导入 STATA，做了图表后，一个数据的显示颜色是红色和绿色，
> 在进行回归效应模型和滞后项时，显示 'no observations'"**
> 回帖给的解法是 `foreach x of varlist ... { replace \`x'=trim(subinstr(\`x',"%"," ",.)) ; destring \`x',replace }`
> （https://bbs.pinggu.org/thread-853258-1-1.html ）

**这是一个纯工程问题被当成统计问题的典型。** 学生不知道"红色 = 字符串"这个 Stata UI 约定。

### 卡点 4：结果不显著，然后开始"调"

论坛与教程的公开共识是"不显著才是常态"，但实际操作里学生做的是：删变量、换样本区间、
换控制变量、取对数、缩尾、换固定效应粒度，直到星号出现。
**代做服务甚至把这条写进了服务范围：淘宝/闲鱼商单描述中明确出现「显著性调整」。**
（来源：DuckDuckGo 聚合的淘宝商品与百度知道结果，2026-08-04 访问，置信度 medium）

### 卡点 5：平行趋势检验事后不通过

> 原声（帖子标题即诉求，经管之家 Stata 专版）：
> **"平行趋势检验还有什么方法可以调啊，缩尾，换控制变量，取对数都做了，事后不通过？"**
> （https://bbs.pinggu.org/thread-11588892-1-1.html ）

注意这句话暴露的心智模型：他们把平行趋势当成一个**需要"调"到通过的关卡**，而不是一个识别假设。
学术界给的正确解法（Rambachan & Roth 2023 的 honest DID 敏感性分析、ΔRM/ΔSD 约束）
在香樟经济学术圈有推文（作者：陈梁，华中科技大学博士生），
但**这个解法要求承认"违背了但可控"，与学生"要星号"的目标是冲突的**。
（来源：https://cec.blog.caixin.com/archives/278331 ，财新博客·香樟经济学术圈，2026-08-04 访问）

### 卡点 6：内生性 —— 找不到工具变量

> 原声（qinhanqing，经管之家，2013-09-13）：
> **"目前在做的是一篇关于工业污染的文章。因为污染是重要的解释变量，同时又是因变量的重要影响因素。
> 所以怎么解决内生性问题呢？得到的结果就是如果没有工具变量，那自己就说不了什么。"**
> 回帖（jose.liupei）："滞后项和控制变量为主要对付内生性"，后续提到 Arellano-Bond GMM。
> （https://bbs.pinggu.org/thread-2629260-1-1.html ）

这条帖子 2013 年发的，2026 年问题一模一样 —— **十三年没被解决的结构性痛点**。
现实中的"解法"是抄同行：滞后一期、同省同行业均值、地理/历史工具变量（河流坡度、明清书院数量…）。

### 卡点 7：Hausman chi2 出负数

`hausman fe re` 输出 chi2 为负，学生不知道这意味着模型设定有问题。
社区解法：`hausman fe, sigmaless`、`rhausman`、`xtoverid`。
（来源：blog.csdn.net/weixin_46189461/article/details/134762158、bbs.pinggu.org/thread-10385740-1-1.html）

### 卡点 8：导出 Word 那一步崩掉（**被严重低估的高频痛点**）

- **中文乱码**：> "outreg2, asdoc, esttab… 导出 rtf 文件里的中文会变成乱码。这是由于它们用了 UTF-8 编码导出"，
  而 Windows Word 默认 GBK。
- **格式错乱**：> "表格格式错乱问题，如列宽不一、文字换行异常、边框缺失或变量名与系数错位"。
- 论坛给的"解法"里赫然包括 **"手动复制粘贴结果到 Word 而不是直接导出"**。
（来源：知乎与 CSDN 相关问答的 DuckDuckGo 聚合摘要，2026-08-04 访问，置信度 medium-high —— 多源一致）

## 6. 他们真正想拿到的东西（交付物排序）

按"愿意为之付出/付费"排序：

1. **一张可以直接 Ctrl-V 进 Word 的三线基准回归表**
   —— 列 = 模型 (1)(2)(3)…；行 = 变量名；系数下方括号里是**聚类稳健标准误**（或 t 值，需可切换）；
   星号 `*** p<0.01, ** p<0.05, * p<0.1`；表底 = 控制变量 Yes、个体固定效应 Yes、年份固定效应 Yes、
   N、R²/within R²。**这是这个圈子最刚需的单一交付物。**
   给谁看：**审稿人和导师**。这张表的格式对不对，直接决定第一印象。
2. **描述性统计表**（变量、N、Mean、SD、Min、P25、Median、P75、Max）—— 论文固定第一张表。
3. **稳健性 / 异质性表**（同上格式，只是换样本换变量）—— 数量上占一篇论文表格的一半以上。
4. **平行趋势检验图 / 事件研究图**（横轴 pre-4…post-4，点估计 + 95% CI 竖线，0 处虚线）
   —— DID 论文的门面图，**必须是这个样子**，画偏了审稿人一眼看出来。
5. **一份能复现的 do 文件** —— 越来越硬的要求，见 §7。
6. **一段能抄进论文的中文结果描述**（"核心解释变量 X 的系数为 0.032，在 1% 水平上显著为正，
   表明……"）—— 学生真实的时间黑洞之一。
7. **数据清洗/合并后的干净数据集**（.dta）—— 想要但不敢要，因为怕出错说不清。

**不在清单里的**：交互式仪表盘、炫酷可视化、机器学习模型解释。这个圈子的审美是**黑白三线表**，
花哨图表在 C 刊里反而扣分。

## 7. 该学科特有的规范与审稿人要求

### 7.1 论文结构 = 高度固化的模板

"实证三件套"的实际展开顺序几乎不变：
**理论假设 → 研究设计（变量定义表 + 数据来源 + 模型设定式）→ 描述性统计 → 基准回归 →
内生性处理（IV/PSM/DID）→ 稳健性检验 → 异质性分析 → 机制检验 → 结论**。
（来源：多份中文教程一致，如 zhuanlan.zhihu.com/p/378376294、
blog.csdn.net/wzk4869/article/details/128881238 等，2026-08-04 检索聚合）

### 7.2 数据与代码公开正在成为硬要求

- **《中国工业经济》自 2016 年第 11 期起，在官网公开所刊发论文的原始数据和程序**（ciejournal.ajcass.com）。
- 检索显示约 **19–23 家中文经济学期刊**已要求或鼓励作者提交数据与代码；
  《经济研究》《世界经济》《数量经济技术经济研究》均在列，《世界经济》近期升级了可复现性指南。
（来源：DuckDuckGo 聚合各刊官网信息，2026-08-04；置信度 medium —— 期刊官网原文未逐一读取）

**产品含义：生成的代码必须是"能被别人重跑"的 do 文件，不能是一串黑箱结果。**

### 7.3 方法论正在被"重新审判"，而学生还在用旧套路

- **中介效应逐步法（Baron-Kenny / 温忠麟三步法）已被点名批评**。
  江艇（2022，《中国工业经济》）明确指出："目前中介效应分析的主要问题是对嫁接自心理学的
  中介效应逐步法检验的滥用"，建议**停止用逐步法、不再估计间接效应大小与其显著性**，
  把重心放回"更干净的因果识别"。而同期该刊 56.3% 的因果推断论文仍在做中介效应分析。
- **多期/交错 DID 的双向固定效应估计量有偏**：Goodman-Bacon (2021) 分解显示 TWFE 是所有 2×2 比较的加权平均，
  权重可能为负；"在异质性处理效应下，多时点 DID 估计系数有偏，严重时估计系数符号会与真实系数符号相反"。
  解法：加总法、两步回归法、堆叠 DID，以及 Callaway & Sant'Anna (2021)、Sun & Abraham (2021)、
  de Chaisemartin & D'Haultfœuille (2020) 等新估计量。
  （来源：王鹏超、韩立彬《多时点双重差分法的潜在问题与解决措施》，《东北财经大学学报》2023 年第 2 期，
  https://zzs.dufe.edu.cn/file/a87e9613-ddb7-11ed-acb6-005056a49984/003_...pdf ；
  以及 sijichun.pro 慧航 2024 年 4 月讲义 Slides13_DID.pdf，2026-08-04 访问）

→ **审稿人现在会问："你的 DID 是交错处理吗？做没做 Bacon 分解 / 换 CS 估计量？"**
学生完全答不上来。这是当下最新鲜、最有区分度的卡点。

### 7.4 常见拒稿/大修理由（按经管圈实际）

1. 内生性处理不干净（工具变量的排他性说不通）
2. 交错 DID 用了 TWFE 没做稳健性
3. 机制检验用逐步法，被指"不是因果"
4. 标准误没聚类到正确层级
5. 稳健性检验太单薄 / 全是同质重复

## 10. 对本产品的启示

### 10.1 应该做什么（按 ROI 降序）

1. **把「回归结果表」做成一等公民的产物面板。**
   不是"输出一段 markdown 表格"，而是：
   - 多模型并列的三线表，系数 + 括号标准误（可切 t 值）+ 星号，表底 Yes/No 行、N、R²
   - **一键导出 Word（.docx，GBK 中文不乱码）**——直接吃掉 §5 卡点 8 的全部痛
   - 变量名支持中文标签映射（`label var`）
   这是唯一一个"用户会为之惊呼"的交付物，也是竞品做得还不够好的地方（HTML/Word 导出但中文与三线表细节未知）。

2. **把「脏数据 → 干净面板」做成显式的、可审计的步骤。**
   自动检测并报告：股票代码前导零、数值列里的 `%`/逗号/空格、id-year 重复、面板断年、
   缺失编码、merge 后 `_merge` 分布。**输出一张"数据清洗报告"**，学生可以直接写进论文的"数据处理"一节。
   这比多支持三个模型有用十倍。

3. **产出可复现的 `.do` 文件，而不只是结果。**
   §7.2 说了 19–23 家中文经济学期刊要数据+代码。产出物必须包含一份注释齐全、能在 Stata 里原样重跑的 do 文件。
   这同时解决了信任问题（学生敢用）和合规问题（答辩能交代）。

4. **把方法论争议做成"体检"而不是"答案"。**
   自动识别：这是交错 DID 吗？→ 提示 TWFE 有偏、建议做 Bacon 分解 / CS 估计量；
   做了中介效应逐步法？→ 提示江艇(2022)的批评并给两步法替代。
   **这是差异化最强的一块** —— 竞品 STATAU 只是"能跑"，不会告诉你"你这么跑要被审稿人打"。

5. **事件研究图 / 平行趋势图作为标准图形模板**（点估计 + 95% CI + 0 处虚线 + 基期剔除）。
   格式必须是圈内那个样子，不要发挥。

### 10.2 明确不该做的部分（砍需求）

| 不做 | 理由 |
|---|---|
| **不做"更快更强的回归引擎"** | Stata 已经足够快，而且用户不是因为算不动才来的。竞品 ¥30/两月就在做同样的事，做这个只是低价内卷。 |
| **不做交互式仪表盘 / 炫酷可视化** | 这个圈子的交付物是**黑白三线表**，花哨图在 C 刊里扣分。做了没人用。 |
| **不做"帮你调到显著"** | 代做市场明码标价的「显著性调整」是学术不端的灰产。碰这个既毁产品声誉，又是审稿人最警惕的。**明确拒绝这类请求，并把它转化为"帮你正确解释不显著"。** |
| **不做数据库/数据源集成（CSMAR/Wind 抓取）** | ① 学校已花 49–70 万/年买了，学生校园网免费下；② 版权与合规红线；③ 真痛点在下载**之后**的合并，不在下载。 |
| **不做 SPSS/AMOS/SmartPLS 的问卷 SEM 路线** | 那是管理学问卷分支，工具链、审美、期刊要求全不同，SPSSAU 已占位。**在这张卡片里做会把定位搅浑。** 若要做，另开一张卡。 |
| **不做通用统计教学 / 计量课程内容** | 连享会、经管之家、B 站已经饱和到过剩，做不出增量。 |
| **不做 EViews / 时间序列的深水区（VAR、协整、GARCH）** | 用户量小、场景集中在本科论文、且 EViews 点选式已够用。优先级排在面板之后很远。 |
| **不做"我帮你写完整篇论文"** | 越界，且与本仓库 Prism（智能写作）职责重叠。数据分析卡片的边界应止于「表 + 图 + do 文件 + 一段结果描述」。 |

### 10.3 形态建议（针对"能力卡片"）

- 空态卡片文案不要写"数据分析"，写**用户语言**：如「跑回归 · 出三线表」或「面板数据实证」。
  这个群体不搜"数据分析"，他们搜"stata 面板 固定效应"。
- 独立产物面板的三个 tab：**表（可导出 Word）· 图（可导出 EMF/PDF）· 代码（.do）**。
- 首屏必须有"上传 Excel/dta"，因为他们手里就是这两种文件。
- **风险提示要 in-band**：不显著、平行趋势不过、交错 DID 有偏，这些要在结果旁边说，不要藏在文档里。
