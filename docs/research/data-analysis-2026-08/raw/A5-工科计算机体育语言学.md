## 1. 群体画像：这个学科里，谁在亲手做数据分析？

这五个学科的共同特征是：**做分析的人，统计训练远低于他们要用的方法的复杂度**，
而且这个落差在工科和 CS 比在医学更大——因为医学至少有「医学统计学」必修课和统计室，工科/CS 没有。

### 1.1 工科（机械 / 土木 / 化工 / 材料 / 食品 / 农业工程）

- **主力：硕士研究生（学硕+专硕），做一到两年实验，毕业前三个月集中处理数据。**
- 统计训练水平：本科阶段通常只有《概率论与数理统计》（数学系口径，讲分布与极限，不讲 ANOVA 前提检验），
  研究生阶段的《试验设计与数据处理》是选修或不开。**方差齐性、球形检验、多重比较校正基本没系统学过。**
- 一个可验证的侧写：经管之家 SPSS 论坛 2009 年就有工科用户问「SPSS 正交试验分析」，
  回帖的第一句是**「SPSS菜单中没有专门的正交试验分析工具，但可以用单因素或多因素方差分析来进行。」**
  （handuan，2009-12-22 11:16:44，[bbs.pinggu.org/thread-658993](https://bbs.pinggu.org/thread-658993-1-1.html)）
  ——十七年过去，SPSS 依然没有正交试验菜单，这个错配一直没被填平。
- 人数量级：**未核实**。可参考的间接信号是「正交试验」在百度贴吧有独立贴吧、
  B 站有大量「正交实验设计、数据处理与分析简单教程」类视频（如 BV1mGChY7EE1），
  以及 Design-Expert 破解版在 3h3.com / ddooo.com / newasp.net 等下载站有 10/11/12/13 多个版本长期挂载
  —— 这是一个**盗版流通量足以支撑多个下载站做 SEO** 的规模。置信度：中。

### 1.2 计算机 / 人工智能

- **主力：硕博研究生 + 青年教师，投 CVPR/NeurIPS/ACL/AAAI 与中文核心。**
- 特殊性：他们**编程能力极强、统计能力极弱**。能手写一个 Transformer，但不知道
  「我的方法比 baseline 高 0.3 个点」需要什么证据才叫赢。
- 这个落差有官方证据：NeurIPS 论文 checklist 有一条专门的
  **"Experiment Statistical Significance"**，问题原文是
  > "Does the paper report error bars suitably and correctly defined or other appropriate information about the statistical significance of the experiments?"
  （NeurIPS 2026 Paper Checklist，[neurips.cc/public/guides/PaperChecklist](https://neurips.cc/public/guides/PaperChecklist)）
  指引里还要求作者说明「误差棒代表标准差还是标准误差」「变异性来自训练/测试划分还是初始化」
  ——**要专门写进 checklist 逐条追问，说明常态是不写。**
- 审稿人侧一手观察见 §8 原声 6。

### 1.3 体育科学

- **主力：体育院校硕士（体育教育训练学 / 运动人体科学 / 运动心理学 / 运动康复与运动医学四个二级学科）+ 一线教练读在职硕士。**
- 统计训练：**有《体育统计学》必修课，但停在 t 检验和单因素 ANOVA**，
  重复测量、效应量、功效分析属于「听过没做过」。
- 这个判断有硬数据支撑。彭凡、张力为、周财亮《体育科学实验研究如何确定适宜的样本量》
  （《上海体育学院学报》2023, 47(2): 26-36，DOI 10.16099/j.sus.2022.03.16.0008）
  对《体育科学》《上海体育学院学报》《北京体育大学学报》《中国体育科技》四本中文核心
  2020—2021 年的 **105 篇实验研究论文（共 111 项实验）**逐篇核算，结论：
  - 样本量达标率：**干预研究 49%，非干预研究仅 17%**
  - 样本量过小（不及所需样本量 1/2）的实验 **51 项，占 46%**
  - **仅 1 项干预研究和 2 项非干预研究**报告了使用功效计算软件估算样本量
  - 对照：*Journal of Sports Sciences* 编辑部 2020 年统计自己 3 年内收到的 120 篇实验论文，
    **样本量中位数仅 19**，只有 12 篇（10%）交代了研究前的样本量估算，其中 4 篇还没说清效果量依据
- 换句话说：**这个学科 90% 的人从没算过 power，46% 的研究样本量不到应有的一半。**

### 1.4 语言学与外语

- **主力：外语类院校的语言学硕博 + 二语习得 / 语料库方向的青年教师。**
  这批人**文科背景，数学基础是五个学科里最弱的**，但被推着用最难的模型（混合效应模型）。
- 学科内部有明显断层：
  - **传统语料库派**：用 AntConc / WordSmith / BFSU 系列工具跑词频、搭配、关键词，
    统计只到卡方和对数似然比。
  - **心理语言学 / 实验语言学派**：必须用 R + lme4 跑混合效应模型（被试和词项双随机效应），
    因为「参与者是从总体抽样的，语言刺激材料也是从所有词的总体中抽样的」这个论证已成学科共识
    （见 arXiv:1506.04967 *Parsimonious Mixed Models*、arXiv:1701.04858 *Mixed Effects Models are Sometimes Terrible*）。
- 结果就是：**一群不会写 for 循环的人，被期刊要求交 lmer() 的输出。** 这是本次调研发现的最尖锐的错配。

### 1.5 地理 / 测绘 / 遥感

- **主力：地理学、城乡规划、生态、经济地理的硕博。**统计训练中等，但**空间统计是自学的**。
- 特点：他们的分析和「地图」不可分——Moran's I 出来的不只是一个数，是一张 LISA 聚类图；
  GWR 出来的不是一组系数，是一张系数空间分布图。**脱离地图的空间统计结果没有发表价值。**

### 1.6 心理生理交叉（眼动 / EEG-ERP / fMRI）

- **主力：认知神经、心理、体育运动心理、语言学的博士生。**
- 这批人被两段完全不同的技能夹住：**前半段是信号处理**（EEGLAB/ERPLAB/SPM/FieldTrip，MATLAB 生态，
  滤波、ICA 去眼电、坏导插值、分段叠加），**后半段是统计**（混合效应模型 / 重复测量 ANOVA）。
- 前半段有大量中文教程（CSDN 上「无需代码，图文并茂详解 EEGLAB 中的 ERPs 数据分析方法」等），
  且有明确的批处理陷阱：**「在进行批处理之前，必须对第一个数据进行完整且适当的分析，因为后续所有被试的分析都基于第一个被试的分析」**
  （CSDN blog.csdn.net/psybrain/article/details/121529950）。
- fMRI 的样本量问题被点名：体育科学那篇综述引用称
  **「现阶段 fMRI 普遍只选取 20~30 名样本；依据该检验报告，无论采取何种数据分析方法，这样的小样本量都很难得到可重复性高的研究结果」**
  （彭凡等 2023，同上）。

## 2. 数据长什么样

**这一节是产品设计的地基。五个学科的统计方法可以合并，数据形态不能合并。**

| 学科 | 典型 n | 变量数 | 文件形态 | 脏在哪（具体） |
|---|---|---|---|---|
| 工科 DOE | **9~30 行**（L9/L18 正交表；BBD 三因素 17 次、CCD 三因素 20 次） | 3~7 因素 + 1~3 响应 | Excel，常带合并单元格的表头 | 因素列存的是**真实值**（如 60℃/70℃），分析要的是**编码值**（-1/0/+1）；平行试验三次没求均值就直接丢进去；中心点重复次数被删了导致失拟项算不出来 |
| CS/ML | 数据集 n 很大，但**评估层只有 3~10 个 seed × 5~10 个 baseline** | — | `.csv` / `.json` / TensorBoard 导出 / 直接是 python 里的 numpy 数组 | **根本没存多次运行的结果**（只跑了一遍，无从算误差棒）；y_true/y_score 存在不同文件里对不齐；同一个 baseline 在不同论文里数字不一样 |
| 体育 | **每组 8~20 人**，2~4 组，2~5 个时间点 | 5~30 个指标（生理+体能+量表） | Excel 多 sheet，一个时间点一个 sheet | 宽表（pre/mid/post 三列）要转长表；中途退出的被试留空行；同一被试 ID 在不同 sheet 拼写不一致；量表反向计分没做 |
| 语言学 语料 | 语料 10 万~1 亿词，**导出的频次表几百到几万行** | 2~4 列（词/频次/语料库大小） | AntConc/WordSmith 导出的 `.txt` 制表符分隔，带 BOM | 两个语料库总词数不同必须归一化；期望频数 <5 时卡方失效；**不同工具算出的卡方/对数似然比数值对不上**（见 §5.4） |
| 语言学 实验 | 被试 20~60 人 × 项目 20~80 个 = **数千行长表** | 5~15 列 | R 里的 data.frame / `.csv` | 反应时异常值裁剪标准（±2.5SD？绝对阈值？）没定；正确率 <80% 的被试要不要剔；**长表已经是对的，但用户以为要转宽表** |
| 地学 | 面要素 100~3000 个（区县/格网） | 5~20 个解释变量 | `.shp`+`.dbf`+`.prj`（四五个文件必须同时在）/ GeoTIFF | 坐标系没定义或是地理坐标系（度）导致距离阈值单位错；属性表字段名 10 字符截断；缺失值填的是 -9999 或 0 |
| 眼动/EEG | 被试 20~40 人 × 条件 2~6 × 电极 32~128 | — | `.bdf/.cnt/.set/.edf`，**几百 MB~几十 GB** | 触发码（trigger）标错；坏导；眼电伪迹；**预处理后导出的「被试×条件×电极×时间窗平均振幅」表才是几百行的 csv** |

**跨学科的四个共性脏法**（这四条 100% 命中，是通用能力的最大公约数）：
1. **宽表 ↔ 长表**：体育的重复测量、语言学的实验数据、工科的平行试验，全都卡在这一步。
2. **中文列名 + 合并单元格表头**：Excel 是中文科研界的事实标准，第一行往往是合并的大标题，第二行才是真列名。
3. **缺失值编码**：空白 / `NA` / `999` / `-9999` / `0` 混用，且用户自己常常不记得当初用的是哪个。
4. **多 sheet / 多文件需要按 ID 合并**：ID 拼写不一致（大小写、前导零、全半角）是合并失败的头号原因。

## 3. 高频分析清单（按真实频次降序）

频次证据来自：中文核心期刊的方法学文献计量、在线统计平台的功能目录、
教程/视频的选题分布、论坛提问的分布。每条标注**用户自己会不会做**。

### 3.1 全学科通用底座（频次最高，价值也最高）

| # | 方法 | 典型场景 | 会不会 | 频次证据 |
|---|---|---|---|---|
| 1 | **数据清洗：宽转长、多表合并、缺失值处理、异常值判定** | 所有学科的第一步 | **完全不会 / 半会** | 五个学科的数据形态表里全部命中；论坛求助帖里「怎么把数据整理成 R 要的格式」是 lme4 提问的前置卡点 |
| 2 | 描述统计 + 正态性检验 + 方差齐性检验 | 论文表 1 | 半会 | 《临床肝胆病杂志》2017-07-05 的常见误用清单第 1、4 条就是「正态性判断错误」「方差不齐处理不当」，说明是高频且高错率 |
| 3 | 两组比较：t / Welch t / Mann-Whitney | 实验组 vs 对照 | **半会——不知道何时该换** | 同上，误用清单点名「不符合方差齐性时应用校正 t 检验或秩和检验」 |
| 4 | 单因素 / 双因素 ANOVA + 事后多重比较 | 多水平因素 | 半会 | 误用清单第 5 条：组间两两比较「不能直接采用 t 检验」，需选 LSD、Tukey 等 |
| 5 | **效应量 + 95% CI + 功效** | 期刊硬要求 | **完全不会** | 彭凡等 2023：105 篇论文里仅 3 篇报告了功效计算软件结果 |
| 6 | 相关 / 多元线性回归 / logistic 回归 | 影响因素分析 | 半会 | SPSSPRO/SPSSAU 功能目录里位置最靠前的几项 |

### 3.2 工科专属

| # | 方法 | 场景 | 会不会 | 证据 |
|---|---|---|---|---|
| 7 | **正交试验极差分析（R 值 + K 均值）** | 筛主次因素、定最优组合 | **半会——极差会算，方差分析不会** | SPSSAU 与 SPSSPRO 均把「极差分析」做成独立功能页；博客园 spssau 有《正交实验与极差分析》《正交实验进行方差分析》两篇分开写 |
| 8 | 正交试验方差分析（判显著性） | 审稿人问「你怎么知道这个因素显著」 | **完全不会** | 「极差分析简单易懂，但不考虑各因素对试验结果的影响是否显著」是所有教程的共同措辞 |
| 9 | **响应面 RSM（BBD / CCD）二次回归 + 3D 曲面 + 优化求解** | 工艺参数优化、配方开发 | **完全不会（靠 Design-Expert 点按钮）** | SPSSAU 响应面功能输出 **7 张表 3 类图**：模型参数、方差分析、回归系数、拟合优度、标准化效应 Pareto、优化解、诊断数据；图为效应图、等高线图、残差诊断图（[spssau.com/helps/quality/responseface.html](https://spssau.com/helps/quality/responseface.html)） |
| 10 | 失拟项（Lack of Fit）判断、VIF 共线性 | 审稿人必查 | 完全不会 | SPSSAU 教程明确提示「失拟项检验（p 值 >0.05 为理想）」「VIF 值大于 10 表示多重共线性问题」（CSDN，2026-07-31） |

### 3.3 计算机 / AI 专属

| # | 方法 | 场景 | 会不会 | 证据 |
|---|---|---|---|---|
| 11 | **多次运行的均值 ± 标准差 / 误差棒** | 结果表的每一格 | **半会——知道要做，但没存数据** | NeurIPS checklist 逐条追问，说明常态是缺失 |
| 12 | **两模型比较的显著性检验** | 审稿人质疑「差 0.3 个点算赢吗」 | **完全不会** | 学界共识是配对 t 检验违反 i.i.d.（交叉验证产生依赖样本，导致乐观估计与 I 类错误膨胀），应改用 McNemar、5×2 cv 配对 t、10×10 重复 cv t 检验（见 MATLAB `testckfold` 文档、academia.edu《Statistical Tests for Comparing Machine Learning Algorithms》） |
| 13 | **AUC 的 95% CI + DeLong 检验** | 医工交叉、生物信息 | 完全不会（复制别人的 pROC 代码） | 大量医学 AI 论文的标准写法：R 的 `pROC` 包 + DeLong 法 + Benjamini-Hochberg FDR 校正 |
| 14 | 多模型多数据集比较：Friedman + Nemenyi + CD 图 | 综述型/benchmark 论文 | 完全不会 | 属方法学共识但普及率低，**未核实具体使用比例** |

### 3.4 体育科学专属

| # | 方法 | 场景 | 会不会 | 证据 |

## 5. 真实卡点（本节最重要）

不写「不懂统计」。以下每一条都精确到**具体的那一步、那个按钮、那句报错**。

### 5.1 工科：卡在「极差算完了，然后呢」

- **卡点 A：SPSS 里根本找不到正交试验的入口。** 用户在菜单里翻遍了，
  然后被告知要去 `Analyze → General Linear Model → Univariate` 手动把因素填进去。
  十七年前的帖子和今天的教程说的是同一件事。（原声 1）
- **卡点 B：极差分析（R 值 / K 均值）自己会用 Excel 手算，但方差分析不会。**
  于是论文里只有一句「由极差分析可知，因素影响主次顺序为 A>C>B」，
  **没有任何显著性证据**，审稿人一问就崩。
- **卡点 C：响应面的「编码值」。** 用户把 60℃、70℃、80℃ 直接填进去，
  软件跑出来的回归系数没法解释交互项，也没法和文献比。
  SPSSAU 的帮助页专门有一句提示「此处的系数是基于编码后的数据」——**要专门提示，说明常错。**
- **卡点 D：失拟项显著了不知道怎么办。** 教程只说「p>0.05 为理想」，
  不说 p<0.05 时该加中心点、该降阶还是该换设计。
- **卡点 E：优化解出来了，但没做验证试验。** 审稿人必问：「你预测的最优点实测了吗？」

### 5.2 计算机：卡在「差 0.3 个点，怎么证明我赢了」

- **卡点 A：只跑了一遍，没有多次运行的结果。** 想补也补不了——
  「我的实验很贵，不可能重跑」（原声 6）。
- **卡点 B：知道要做检验，但不知道做哪个。** 直觉上想用配对 t 检验，
  但学界共识是交叉验证的折间结果不独立，配对 t 会**低估方差、放大 I 类错误**，
  应改用 McNemar / 5×2cv 配对 t / Nadeau-Bengio 校正 t。**这个知识在 CS 课程里根本不教。**
- **卡点 C：误差棒到底是 SD 还是 SE。** NeurIPS checklist 专门要求澄清，
  说明大量论文自己也说不清。
- **卡点 D：审稿意见来了，只剩一周 rebuttal。** 这是**付费意愿最高的时刻**——
  有明确的截止时间、明确的意见文本、明确的失败代价。（原声 6）

### 5.3 语言学 / 交叉：卡在 lme4 的三行报错

这是本次调研中**证据最密集**的卡点。三条不同年份、不同学科的一手报错：

- `boundary (singular) fit` —— 随机效应方差被估成 0
- `Model failed to converge with 1 negative eigenvalue: -4.1e-08`（原声 3）
- `Model failed to converge: degenerate Hessian with 1 negative eigenvalues`
  + `unable to evaluate scaled gradient`（原声 5）

**卡点的本质不是报错本身，而是「报错之后要做一个学术决策」**：
删哪个随机斜率？删相关项还是删斜率？删完还算不算「理论上正确的模型」？
学界对此本身就有争论（"parsimonious convergence hypothesis"，arXiv:1506.04967），
**没有唯一正确答案**——所以任何自动化工具都不能默默替用户删。

更前置的卡点是**「模型公式怎么写」**：
- 原声 2（眼动/瞳孔）：`(1 | participants) + (1 | motion_coef)` ——
  把一个**连续型自变量**（运动量系数）当成了随机效应分组变量，这是概念性错误，
  但提问者自己完全不知道，只说「I am a bit lost about the model's writing」。
- 原声 4：想把被试内因素直接写进模型，而不是先 `lm()` 再 `aov()` 分两步做，
  **连「重复测量该在哪一层表达」都还没建立心理模型。**

### 5.4 语言学语料：卡在「三个软件三个数」

corpus4u 论坛的长期讨论指出：**WordSmith、AntConc、BNCweb 算出的卡方值和对数似然比常常不同，
差别来自不同的计算公式**（[corpus4u.org/threads/4659](https://www.corpus4u.org/threads/4659/page-3)，
注：该站证书配置异常，本次经搜索摘要取证，**原帖原文未直接核实**，置信度：中低）。
用户的实际处境是：**三个数不一样，不知道哪个能写进论文，也不知道怎么向审稿人解释。**

### 5.5 地学：卡在空间权重矩阵那个下拉框

ArcGIS 的 Moran's I 工具第一个必填参数是「空间关系的概念化」，
选项决定了后面要不要填距离阈值、要不要提供权重矩阵文件：
- 反距离法 → 距离范围可选
- `FIXED_DISTANCE_BAND` / `ZONE_OF_INDIFFERENCE` → **必须输入距离范围**
- `CONTIGUITY_EDGES_ONLY` / `CORNERS` → 不需要距离
- `GET_SPATIAL_WEIGHTS_FROM_FILE` → 需要权重矩阵文件

**官方文档自己承认这里有坑**：「如果将距离范围或距离阈值参数留空，系统将计算距离阈值，
但这可能不是分析所需的最适当距离」（ArcMap 官方文档）。
另一个可观测的错误信号：**未行标准化时指数值会落在 [-1, 1] 之外，这直接说明参数设错了**
（tuyuangis.com，2021-11-04）——但用户看到 1.37 这样的值时，往往直接抄进论文。

### 5.6 体育：卡在球形检验不通过之后

- **卡点 A：Mauchly 球形检验 p<0.05，然后呢？** 中文教程给出的一致答案是看
  Greenhouse-Geisser 校正行——但**用户不知道 SPSS 输出的四行（Sphericity Assumed / G-G / H-F / Lower-bound）该抄哪一行**，
  也不知道校正后自由度变成小数要不要写进论文。
- **卡点 B：交互作用显著了，简单效应分析在 SPSS 菜单里做不了**，必须改 GLM 语法。
  B 站教程标题直接写着「球形度校正版，VEGF 案例实操……GLM 代码修改」（BV1KrnnzBELG）
  ——**要教改代码，说明菜单路径走不通**。
- **卡点 C：效应量 SPSS 不默认输出**，要在 Options 里勾 Estimates of effect size，
  而且勾出来的是偏 η²，期刊要的可能是 Cohen's d，换算关系用户不会。
- **卡点 D：投稿被问「你的样本量依据是什么」**——105 篇里 102 篇答不上来。

### 5.7 五个学科的共同终点卡：「输出的一堆表，哪个数进论文」

无论用什么软件，最后一步都一样：**软件吐出 5~10 张表，论文只需要其中 3~6 个数字，
外加一句符合本学科惯例的句式。** 这一步没有任何软件负责，
也正是代做服务真正在卖的东西（「专业绘图、过程推导、智能分析**支撑结论**」）。

| 学科 | 硬规范 | 常见拒稿/返修理由 |

| **CS/AI** | **NeurIPS Paper Checklist "Experiment Statistical Significance"**（原文见 §1.2）；要求说明误差棒的变异来源、计算方法、是 SD 还是 SE、非对称分布不得画对称误差棒 | 「表里的差异在噪声范围内，需要误差棒和显著性检验」；baseline 复现不一致；只跑一个 seed |
| **体育科学** | APA《出版手册》第 7 版建议报告统计功效；*Psychology of Sport and Exercise* 已将假设检验类论文的 Power 标准写进投稿指南并**提高到 0.90**；*Cortex* 把 α 提到 0.02 并要求先验功效计算用 0.90；*Journal of Sports Sciences* 2020 社论倡导投稿时详述样本量估算过程（均引自彭凡等 2023） | 样本量无依据；只报 p 不报效应量；重复测量误用配对 t；球形检验未处理 |
| **语言学（实验类）** | 混合效应模型已成默认；被试 + 项目双随机效应是共识；随机效应结构必须报告并说明简化过程 | 「只放了随机截距，没放随机斜率」；不报告收敛问题的处理；用按被试平均（F1）代替混合模型 |
| **语言学（语料类）** | 频次必须归一化（每百万词）；期望频数 <5 用对数似然比而非卡方；近年要求同时报效应量（LogRatio / %DIFF） | 只报 p 不报效应量（大语料下什么都显著）；两库规模不同直接比绝对频次 |
| **地学** | 报告空间权重矩阵的构造方式；Moran's I 必须报 z 值和 p 值；GWR 必须报带宽选择准则（AICc/CV）与局部共线性诊断 | 「你的权重矩阵怎么定的」；GWR 未做 OLS 残差空间自相关检验就直接上；样本要素过少 |
| **工科 DOE** | 响应面必须报失拟项（p>0.05）、R²/调整 R²/预测 R²、VIF；最优解必须做验证试验 | 失拟项显著仍下结论；只有极差分析没有显著性；没做验证试验 |
| **交叉（EEG/fMRI）** | 预处理参数必须完整报告（滤波带通、ICA 成分数、伪迹阈值、分段窗口、基线）；多重比较必须校正（cluster-based permutation / FDR） | 样本量 20~30 被质疑功效不足；多重比较未校正；电极/时间窗是看了数据才选的（double dipping） |

## 9. 对本产品的启示 + 明确不该做的部分

### 9.1 一个通用卡片能覆盖什么（判断，不是罗列）

**能覆盖，且必须做（跨五学科的最大公约数）：**

1. **脏 Excel → 干净长表**。宽转长、多 sheet 按 ID 合并、中文列名保留、合并单元格表头识别、
   缺失编码（空/NA/999/-9999）统一。**这是所有学科的第一步，也是耗时最长的一步，且没有任何统计软件负责。**
   这一项的通用性是 100%，应该是卡片的第一个动作，而不是「顺便做的预处理」。
2. **前提检验驱动的方法分流**，且**把分流依据一起交付**。
   不是「我帮你选了 Welch」，而是「Levene F=6.3, p=.014 → 方差不齐 → 改用 Welch't」。
   理由见 §7：审稿人问的是依据，不是结论。
3. **效应量 + 95% CI + 事后功效**，全学科补齐。这是当前普及率最低（体育：105 篇里 3 篇）
   而期刊要求上升最快的一项，是最容易做出「比用户自己做得好」的差距。
4. **把输出翻译成本学科句式的 Results / Methods 段落**。这是排序第 1 的交付物，
   也是 20 元代做卖不动、150 万用户的在线平台也没真正做好的一段。
5. **三线表（Word 可编辑）+ 期刊规格静态图**。不是 dashboard，不是交互图表。
6. **窄口但高价值的三个专项**（做起来便宜、卡点极痛、竞品覆盖差）：
   - **模型比较统计**：给 `y_true / y_pred / y_score`，出 AUC+DeLong CI、McNemar、
     多 seed 的均值±SD、Nadeau-Bengio 校正 t、多模型 Friedman+Nemenyi。**纯数值输入，无需碰模型训练。**
   - **重复测量全链路**：球形检验 → G-G/H-F 校正 → 简单效应 → 偏 η² → 直接给出该抄哪一行。
   - **词频表对比**：两列频次 + 两个语料库总词数 → 对数似然比 + LogRatio 效应量 +
     期望频数<5 的自动提示。**输入只是一张两列的表。**

**必须承认覆盖不了（且应主动说「这个我做不了」）：**

| 覆盖不了的 | 为什么 |
|---|---|
| **DOE 的「设计」那一半** | 用户来的时候试验还没做，要的是排布表（L9/BBD/CCD），这是**生成实验计划**不是分析数据；而且响应面的最终价值形态（编码系数表、Pareto、3D 曲面、优化解+验证试验）是审稿人认得的**固定视觉产物**，仿不像等于没做。可做的是「已有 DOE 数据 → 方差分析 + 失拟项 + 系数表」这一半 |
| **EEG / ERP / fMRI / 眼动的预处理** | 数据是 .bdf/.cnt/.set/.nii，几百 MB~几十 GB，pipeline 绑死 MATLAB + EEGLAB/SPM/FieldTrip。**接入点应该是预处理之后那张「被试×条件×电极×时间窗平均振幅」的几百行 csv**，不是原始信号 |
| **空间统计（Moran's I / GWR）** | 需要 shapefile（.shp/.dbf/.prj 一组文件）+ 空间权重矩阵 + 结果必须落回地图。三样都是重投入，且 ArcGIS/GeoDa 路径依赖极强 |
| **语料库检索本身** | 在千万词语料上跑索引/搭配是 AntConc/CQPweb 的活。只接它们**导出的频次表** |
| **模型训练 / 调参 / 特征工程** | CS 用户自己比我们强得多。只接**评估层** |
| **完整 SEM / 路径图** | AMOS/Mplus 路径依赖 + 需要画图。Bootstrap 中介效应可做，完整 SEM 不做 |

### 9.2 交付物的学科分叉（一个卡片，三种输出模板）

统计计算可以共用一套引擎，**但最后一公里必须分叉**，否则交付物一律不可用：

- **体育 / 心理**：APA 第 7 版句式，`F(dfn, dfd) = x.xx, p = .xxx, ηp² = .xx`，
  必须带效应量；图要误差棒图 + 显著性标记。
- **工科**：方差分析表 + 编码回归方程 + 失拟项 + R²/调整R²/预测R² + 3D 响应曲面 + 等高线。
- **CS**：均值±SD 表 + 显著性标记 + 检验名说明 + ROC/CD 图；语言是英文。
- **语言学**：归一化频次（每百万词）+ LL 值 + LogRatio；混合模型报告随机效应结构与简化过程。
- **地学**：Moran's I + z + p + 权重矩阵构造说明（即使不出图也要出这段文字）。

### 9.3 入口设计的一个非显然结论

**「审稿意见」应该是一等入口，和「上传数据」并列。**

理由：§5.2 卡点 D 与原声 6 显示，付费意愿的峰值不在「我要开始分析」，
而在「审稿人提了一条统计意见，我有一周时间，我不知道怎么办」。
这个时刻有明确的文本输入（意见原文）、明确的成功标准（意见被消解）、明确的截止时间。
**这是 20 元代做覆盖不了的场景**，也是唯一能支撑溢价的场景。

建议卡片空态提供两条路：
- 「我有数据要分析」→ 走清洗 → 分流 → 交付流水线
- **「审稿人提了统计意见」→ 粘贴意见原文 + 上传数据/原稿 → 直接产出针对性回应 + 补做的分析**

### 9.4 明确不该做的（砍需求）

1. **不做「一键自动选统计方法」的黑箱。** 选错的代价是拒稿，而且用户被追问时答不上依据。
   要做的是：**给候选 + 前提检验证据 + 让用户确认**。这不是妥协，这是交付物本身的一部分（§6 排序 2）。
2. **不做实验设计生成器（正交表 / BBD / CCD 排布）作为第一版。**
   它是另一个时点、另一种心智（试验还没做），且输出必须兼容 Design-Expert 的格式惯例才有用。
   列入 v2 候选，不进 v1。
3. **不做 EEG/fMRI/眼动的原始数据预处理。** 文件太大、生态绑死 MATLAB、
   出错的责任边界不清（预处理参数错会污染全部下游结论）。
4. **不做 GIS 空间统计。** shapefile 多文件依赖 + 坐标系 + 必须出地图，投入产出比在这批学科里最差。
5. **不做模型训练。** 只接 `y_true/y_pred/y_score`。
6. **不做交互式 dashboard / BI 看板。** 这批用户的终点是 Word 和 PDF，不是网页。
   静态三线表 + 300dpi 图 > 任何交互图表。
7. **不做「图表美化」当卖点。** 期刊要的是黑白可辨、坐标轴带单位、符合本刊模板的图，
   不是好看的图。**把「符合规范」做对，比把「好看」做满更值钱。**
8. **不做按次收费的「跑一次分析」。** 市场出清价 20 元（§4.4），正面竞争必输。
   价值锚点应该是「陪你走完一轮返修」。
9. **不做 Excel 插件 / 桌面客户端。** 与 claw 的形态不符，且盗版软件生态里这类分发没有优势。
10. **不承诺「统计结论正确」。** 这批学科的规范争议（如 lme4 随机效应该简化到什么程度）
    学界本身没有定论。产品应该输出**决策依据和候选方案**，把最终判断留给用户，
    并在交付物里如实写明做了哪些简化——这反而是审稿人想看到的。

### 9.5 与已有两张卡片（制作PPT / 科研绘图）的关系

- **上游关系**：数据分析的产物（表 + 图）天然是「制作PPT」的输入。
  组会汇报「我这批数据跑出来了」是极高频场景，两张卡片应能串起来。
- **重叠风险**：「科研绘图」已经覆盖了出图。
  **数据分析卡片不应该重做绘图引擎**，应该在需要图时调用已有的绘图能力，
  自己只负责「该出哪张图 + 图上要标什么显著性标记」。这条边界要在实现前钉死，否则会重复建设。

### ChatSRS（chatsrs.com）

`/blog/ai-spss-three-line-table`。**其博客里直接暴露了实现约束**，这对我们极有参考价值：

> - 重复测量 ANOVA：**"当前代码只用 GG ε 生成校正 ANOVA 行"**（即：不给 H-F，直接替用户做了决定）

> - 缺失值：完整案例删除，**"某个时间点缺失会让同一对象在所有时间点都退出本次 ANOVA"**

> （[chatsrs.com/blog/ai-repeated-measures-anova](https://chatsrs.com/blog/ai-repeated-measures-anova)，2026-08-04 抓取）

**三条判断**：

1. **它们把「三线表」当成第一卖点**，不是「方法多」。这与第一轮 §6 的交付物排序一致，

2. **"完整案例删除"那条是反面教材**：用户根本不知道自己的被试被静默剔掉了。

3. **"待核验草稿"的措辞值得抄**：它把责任边界写在交付物里，

### ① 学科级方法占比的硬数据（体育学，样本 70,275 篇）

1978—2023 年体育学 **11 种 CSSCI 来源期刊共 70,275 篇**论文（人工核查剔除非学术类后的有效样本），
方法使用占比前十：

其后为信息科技类 4.53%、医学生物类 2.54%、社科类 1.91%、测试法 1.69%、比较法 1.68%。
（[sohu.com/a/975276850_121124683](https://www.sohu.com/a/975276850_121124683) 转载《体育学刊》郑嘉昕、黄汉升，福建师范大学体育科学学院；

**注意口径**：这是**学科级方法**占比，不是具体统计方法频次，不能直接当"t 检验占 X%"用。
它确立的是量级：**统计法是体育学第三大方法**。

### ② 体育科学的样本量硬阈值（可直接做成产品提示）

- α=0.05、power=0.8、中等效应量 d=0.5 时，**独立样本 t 检验每组需 64 人**
- 精度法：置信区间宽度 5 → 每组 54 人；宽度 2.5 → 每组 **211 人**
- **要重复一个原始 p=0.05 的结果并达到 80% 检验力，样本量需是原始研究的 16 倍**
（[sohu.com/a/693268708_121124683](https://www.sohu.com/a/693268708_121124683)，2026-08-04 抓取）

对照第一轮已记的「样本量中位数 19」——**用户的真实样本量与达标线差 3 倍**。
**产品含义**：卡片若老老实实做事后功效分析，会对绝大多数体育用户输出"你的研究检验力不足"。
这是**真话，但是坏交付物**。正确形态是：给出效应量 + 95% CI + 一句可写进 Limitations 的规范表述，
而不是一个刺眼的红色警告。

### 卡点：**三线表转换**（第一轮列为交付物 #3，但没有量化痛感与生态证据）

## II-6. 两条会改动产品结论的新证据（**读第 9 节前必看**）

### 🔴 证据 A：伪重复不可自动检测 —— 「一键分析」在这个集群是危险的

原声 9 那位工科研究生的 30 行数据里，**机器无法从表格结构判断**
这 30 行是 30 个独立实验单元，还是 3 个生物学重复 × 10 个技术复孔。
两种解读给出的标准差差一个量级，p 值差一个数量级，**而且两种情况下程序都跑得通、图都画得出来、没有任何警告**。
体育科学侧 46% 的研究栽在同一件事上（II-1）。

**结论**：卡片必须有一个**不可跳过的结构确认步骤**——
"你这张表里，一行代表什么？哪一列标识独立实验单元（被试/批次/地块）？"
跳过这一步的产品，产出的是**精致的错误**，而这类错误比"不会做"更难被发现、后果更严重。

这条**加强并具体化**了第一轮 §9.4 第 1 条（不做一键黑箱）：
第一轮的理由是"选错方法会拒稿"，本轮给出的理由更硬——
**不是方法选错，是数据结构理解错，而这个错误在任何输出上都不可见。**

### 🔴 证据 B：MBI 是体育科学的雷区，不能自动推荐

**Magnitude-Based Inference（MBI）** 在运动科学里曾被广泛使用，
但受到统计学界的方法学批评，已有系统综述专门审视其使用状况与问题
（[pmc.ncbi.nlm.nih.gov/articles/PMC7319293/](https://pmc.ncbi.nlm.nih.gov/articles/PMC7319293/)、
[PLOS ONE 10.1371/journal.pone.0235318](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0235318)，2026-08-04 抓取）。
同时 BJSM 在推"p 值 ≠ 实际意义"的立场
（[bjsm.bmj.com/.../bjsports-2024-109357.full.pdf](https://bjsm.bmj.com/content/bjsports/early/2025/10/05/bjsports-2024-109357.full.pdf)，2026-08-04）。

**结论**：卡片在体育科学场景下若"贴心地"推荐 MBI（它在中文体育文献里确实出现过），
会把用户送进拒稿。**方法推荐必须带学科时效性，不能只按统计正确性来选。**
这是一个第一轮完全没有覆盖的风险面：**过时但曾经流行的方法，比错误的方法更危险，因为它有文献先例可循。**

## II-7. 对第一轮 §9「砍需求清单」的四条修订

### ① 【加强】不做一键黑箱 → 升级为「不可跳过的数据结构确认」

见 II-6 证据 A。这不是一个可以用 UX 优雅度换掉的步骤。
**建议实现形态**：读入表格后先出一张"我理解的数据结构"卡片（行 = ？分组列 = ？重复测量列 = ？独立单元 = ？），
用户点确认才继续。这一步同时也是 §6 交付物 #2（Methods 段落）的原料。

### ② 【新增】必须硬拒"把不显著变显著"，且要做成显式产品行为

见 II-5 最后一条。**理由不是道德洁癖**：一旦本平台的卡片被发现能干这个，学术信誉一次性归零，
而且会污染 Scholay 的其他能力（审稿、写作）。

**但不要静默拒绝**——静默拒绝只会把用户推去代做。正确做法是**给替代路径**：
报告效应量与置信区间、说明检验力不足、把"未发现显著差异"写成一段合格的、审稿人能接受的表述
（"本研究未发现 X 与 Y 的显著关联（p = .18, d = 0.21, 95% CI [-0.10, 0.52]），
考虑到本研究样本量 n=24 仅能检出 d ≥ 0.83 的效应，该结果不足以支持无效结论"）。
**这段话本身就是一个有价值的交付物，而且没有任何竞品在做。**

### ③ 【明确】不做谱图类信号处理（XRD / 拉曼 / 红外分峰）

见 II-4 第 ③ 条。它长得像"数据分析"（也确实要拟合、要算参数），
但本质是**信号处理**：基线扣除算法、峰形函数选择（Gaussian/Lorentzian/Voigt）、
仪器参数相关的 Scherrer 常数——每一项都是领域知识，且已有 Origin/Jade 和专门的 AI 工具（xrd-ai.cn）占位。
**做半截的分峰比不做更糟**，因为峰面积错了整篇论文的定量结论就错了。

### ④ 【拆分】眼动 ≠ EEG，眼动的导出后表格应当覆盖

见 II-5 第三条。第一轮把两者并列为"覆盖不了"，应改为：
- **EEG/ERP/fMRI**：不做（原始信号 + MATLAB 生态）
- **眼动**：**接 Tobii Pro Lab 导出后的 AOI 指标表**（普通宽/长表），
  该表的下游分析（混合效应模型 / 重复测量 ANOVA）与语言学、体育完全同构，**零边际成本**

### ⑤ 【补充】不要试图在"方法覆盖数"上竞争，也不要在"能不能免费跑"上竞争

新增理由（II-3）：SPSSAU 免费版限前 100 行，
而本集群五个学科的真实样本量（工科 9~30 行、体育每组 8~20 人、语言学被试 20~60 人）
**几乎全部落在 100 行以内** —— 也就是说竞品的免费版就能覆盖大多数用户的主分析。
叠加 SPSSPRO **根本不卖会员**（用它换小红书/知乎种草内容）这一事实，
**"跑分析"这件事在中文学术市场上已经是免费商品。**

**价值只能建立在跑分析之外**：结构确认 → 依据链 → 学科句式的 Results/Methods 段落 →
三线表 + 字母标记 → **陪走返修**。第一轮 §9.3（把"审稿意见"做成一等入口）的判断，
在本轮拿到了更多支撑：小木虫上"如何回复审稿人的统计意见"是一整片帖子
（《编辑提出关于数据统计分析，如何应答?》[t-10960799](https://muchong.com/t-10960799-1)、
《怎样回复审稿人意见：文章中没有数据的统计学处理》[201304/5716899](https://muchong.com/html/201304/5716899.html)、
《审稿人提出"实验重复的统计信息应该被提供"如何回答?》[201408/7839306](https://muchong.com/html/201408/7839306.html)，

**四个独立帖子问的是同一件事，而没有任何软件负责这件事。**

## II-8. 关于「一张通用卡片能覆盖多少」的量化判断（本轮的收敛结论）

把第一轮和本轮的证据合起来，给一个可执行的边界：

**能覆盖（应做）**——判据：数据是 **n < 200 的表格**，且分析目标是**假设检验/建模 + 论文交付物**

| 学科 | 覆盖的部分 | 覆盖不了的部分 |
|---|---|---|
| 工科 | 正交表的极差 + 方差分析；已有 DOE 数据的响应面回归/失拟项/系数表；显著性字母标记 | DOE 试验排布表生成（时点不同）；XRD/拉曼分峰（信号处理） |
| CS | 多次运行结果聚合 → 均值±SD → **LaTeX booktabs 表**；给 `y_true/y_pred/y_score` 出 AUC+DeLong / McNemar / Friedman+Nemenyi | 训练、调参、日志目录扫描 |
| 体育 | 重复测量 ANOVA 全链路（球形检验 → G-G → 简单效应 → 偏 η²）；ICC / SEM / MDC；效应量与 CI | 无（本集群里覆盖度最高的学科） |
| 语言学 | 频次表 → 归一化 + 对数似然比 + LogRatio + 期望频数<5 提示；反应时长表的清洗与混合效应模型 | 语料库检索/分词/索引 |
| 地学 | 混淆矩阵 + Kappa + 生产者/用户精度 | Moran's I / GWR（需 shapefile + 空间权重矩阵 + 落图） |
| 交叉 | **眼动 AOI 指标表**的下游分析 | EEG/ERP/fMRI 全部 |

**粗估覆盖率 55~65%**（按"用户的分析需求条数"计，非严格测量，**未核实**）。
**剩下的 35~45% 不是"以后再做"，是"永远不做"** ——
它们要么依赖学科专有二进制格式，要么依赖必须落回地图/图像的输出，
要么在时点上根本不属于"拿到数据之后"。

**交付物介质必须分叉**（第一轮 §9.2 已有，本轮补一条实现要点）：
中文期刊/学位论文走 **Word 可编辑三线表**；CS 顶会走 **LaTeX booktabs**。
只出 Markdown 表的实现，**两边都不可用**——这一条要在实现前钉死。
