# A6 · 交付物与报告规范

> 横切主题：科研用户做完数据分析后，**真正想拿到手的信息与文件**是什么形态。
> 调研日期：2026-08-04 ｜ 面向：智能助手（claw）第三张能力卡片「数据分析」的需求与形态定义
> 所有事实结论后标注来源（URL + 站点 + 时间）；核实不了的显式标「未核实」。

---

## 〇、一句话结论

**用户不要「分析报告」，用户要「能直接粘进投稿文件的那几块东西」。**

按「愿意为之付钱 / 实际卡住的时长」排序，交付物的真实优先级是：

1. **合规格式的成品表格**（Table 1 基线表 + 主分析结果表），可直接落 Word 且线型/星号/小数位符合目标期刊惯例；
2. **Methods 里的统计方法段**（含软件与版本号、检验前提、缺失处理、多重比较），因为这段是审稿人第一个挑刺的地方，且各大规范都有硬清单；
3. **Results 段的成句文字**（p 值写法正确、效应量与置信区间齐全），中英双语；
4. **「审稿人会问什么」的预答清单**；
5. 可复现脚本 / 原始输出对照 —— **是信任凭证，不是交付主体**。

最容易被误判为高价值、实际应当克制的是：「这个结果能不能发」的结论性判断、以及仿造 SPSS 原始输出界面。理由见第八节。

## 二、交付物清单与优先级

下面每一条都给：**为什么认为用户要这个**（证据）、**谁在为它付钱**（证据）、**我们该做到什么程度**。

### P0-1 合规格式的成品表格（Table 1 + 主结果表）

**为什么要：** 这是「手工做最费时、且格式对错可被客观判定」的唯一一类产物。整个 R 生态里最被广泛使用的一批包，存在的唯一理由就是把统计结果变成能投稿的表：`gtsummary` 的自述是「creates publication-ready analytical and summary tables」，明确支持导出 **Word (.docx) / RTF / LaTeX / HTML / PNG**，并会自动识别变量类型、自动带上缺失量、对 logistic 回归自动填「Odds Ratio」表头（CRAN gtsummary README，https://cran.r-project.org/web/packages/gtsummary/readme/README.html，2026-08-04 取）。`stargazer` 被描述为「the classic LaTeX-first package. It shaped what a 'regression table in R' looks like for a decade and is still the default in many economics workflows」，且目前「is in maintenance mode. The maintainer has publicly paused feature development」（r-statistics.co / Tilburg Science Hub 汇总，2026-08-04 检索）——**一个已停止开发的包仍是经济学默认，说明这个需求刚性到用户宁可用停更工具也不肯手工排版。**

在中文侧，SPSS 官方内置的表格外观模板里**直接有一个叫「Academic」的样式**，用户设置一次之后「此后输出的表格均为三线表样式」（spss.mairuan.com/jiqiao/spss-wjzxr.html，IBM SPSS 中文站，2026-08-04 取）。而所有中文教程都在教同一件事——把 SPSS 默认输出改成三线表（CSDN，blog.csdn.net/m0_51211389/article/details/119274688，2021-08-01；另有多篇同题材文章）。这类教程的存在量本身就是需求量。

**谁付钱：** SPSSAU 把「表格格式默认就已经是三线表」作为核心卖点写在营销页，其会员定价为 **¥9.8/24小时、¥69.8/周、¥258/月、¥2588/年**（spssau.com/addmoney.html 官网价格页，2026-08-04 实测）。英国的论文服务商 Premier Dissertations 把「converting raw SPSS output into APA-style dissertation tables」单列为售卖项（premierdissertations.com/write-spss-results-in-dissertation/，2026-08-04 取）。

**做到什么程度：** 必须做到「不用再手工碰一下」——线型、小数位、星号脚注、缺失标记、行序，全部在导出时就是对的。做成 90% 对、还要用户进 Word 补线，价值归零（这是三线表教程里所有痛点的共同来源）。

### P0-2 Methods 的统计方法段

**为什么要：** 这是唯一一段「有权威硬清单、可以逐条打钩」的文字。SAMPL 指南在**每一种分析类型下都重复了同一句**：「Name the statistical package or program used in the analysis.」——相关分析下、回归分析下、方差分析下、生存分析下、贝叶斯分析下各出现一次（Lang T, Altman D. *SAMPL Guidelines*，EQUATOR Network PDF，2013 版，本地逐页读取 p.5–p.7）。重复五次说明作者认为这是最容易被漏、且最不可原谅的一项。

SAMPL 转引 ICMJE 的原话是整个交付物设计的基准线：

> "Describe statistical methods with enough detail to enable a knowledgeable reader with access to the original data to verify the reported results. ... Avoid relying solely on statistical hypothesis testing, such as P values, which fail to convey important information about effect size."
> —— SAMPL Guidelines p.3 逐字引 ICMJE Uniform Requirements

**谁付钱：** LetPub 明确把「数据统计分析服务」列为独立收费项，并说明「如果是常规的统计分析服务，我们会在您提交服务需求后，当天给出报价；对于部分较复杂项目，我们会请美国数据统计专家先评估，再根据项目的难度和工作量报价」（letpub.com.cn 价格页，2026-08-04 取）。**注意这条是「报价制」而非明码标价** —— 报价制意味着交付内容不标准化，也意味着这块存在被标准化产品吃掉的空间。

### P0-3 Results 段成句文字（中英）

**为什么要：** 用户卡住的位置不是「跑不出来」，是「跑出来了不知道往论文里写哪几个数」。中文侧最直白的三句用户困惑被产品方原样引用：

> 「Sig.值小于0.05说明什么？」「这个系数是正的好还是负的好？」「我该在论文里报告哪些数字？」
> —— turingpub.com《SPSS分析结果不会解释？》，2026-08-04 取

这三句刚好对应三个不同层级的需求（读数 / 方向判断 / 取舍），详见第五节。

**做到什么程度：** **模板填空，不是自由生成。** 已有公开的成熟模板句式可以直接对标，例如：

> "An independent-samples *t*-test indicated that [DV] was significantly [higher/lower] for [Group 1] (*M* = [value], *SD* = [value]) than [Group 2]"（含 *t*、*p*、*d*、95% CI）
> "A one-way ANOVA revealed a significant effect of [IV] on [DV], *F*([df_between], [df_within]) = [value], *p* = [value], η² = [value]."
> "A chi-square test of independence indicated a significant association between [V1] and [V2], χ²([df], *N* = [value]) = [value], *p* = [value], Cramér's *V* = [value]."
> —— statisticsforresearch.com/cheat-sheets/apa-reporting/，2026-08-04 取

中文侧同样存在成熟模板：「独立样本T检验结果显示，实验组（M=85.6, SD=4.2）与对照组（M=78.3, SD=5.1）的后测成绩存在显著差异，t(58) = 5.32, p < .001。」（turingpub，同上）。

### P1-1 「审稿人会问什么」预答清单

**为什么要：** 统计问题是高频退修意见，而中文用户对「回复审稿人」这件事的需求量大到形成了内容品类——搜索「审稿意见回复模板」可见知乎多篇长文、CSDN、EA-ISET、Unionpub、埃米编辑等平台各有一套模板，且共同强调「所有问题必须逐条回答」「先用斜体粘贴审稿人原文，再点对点回答」（多站汇总，2026-08-04 检索）。

**旁证（重要）：** 一篇 2025 年发表在 PMC 的 SAMPL 实施评论指出，**141 家 WAME 会员期刊中只有约 5% 主动引用 SAMPL 指南**，同时列出最常缺失的是「inadequate reporting of effect sizes」「unclear descriptions of statistical test purposes」「poor analysis of assumptions」「limited consideration of outliers」（pmc.ncbi.nlm.nih.gov/articles/PMC12036030/，2026-08-04 取；该文为评论性文章，未给具体百分比，除 5% 一项外为定性描述）。

**这条数据的产品含义极强**：期刊自己不写明规则（只有 5% 引用），但审稿人照着这套隐性规范挑刺。**用户面对的是一套「没人告诉你、但你必须做对」的规范** —— 把隐性规范显性化，正是这张卡片的核心价值主张。

### P1-2 期刊级图（分辨率 / 字体 / 配色 / 显著性标注）

**为什么要：** 规格是硬的、可校验的。Nature 的作者指南要求：图像 **RGB、300 dpi 起**（彩色 300 dpi、灰度 600 dpi、线稿 1000 dpi），字体统一用 **Arial 或 Helvetica、5–7 pt**，多面板图的分面板标签用 **8 pt bold、正体（非斜体）的 a, b, c**，并明确「avoid the use of red and green for contrast」（nature.com/nature/for-authors 初投稿与终投稿页，经多源汇总，2026-08-04 检索；未逐字读取原页，置信度中高）。

**但要注意与本仓库既有能力的边界**：「科研绘图」已经是**独立的第二张卡片**（`sci_draw`）。数据分析卡片里的图应当是**统计图**（森林图、K-M 曲线、效应量图、诊断图），且**产物应可交给绘图卡片做最终美化**，而不是在数据分析里重造一套期刊配色系统。

### P1-3 可复现脚本 / 数据与代码可得性声明

**为什么要：** 这是**规范强制项**，不是加分项。

- Nature Portfolio 的 Reporting Summary 有独立的 **Software and code** 段，要求分别填写「Data collection」与「Data analysis」所用软件，并写明「We strongly encourage code deposition in a community repository (e.g. GitHub)」（nature.com/documents/nr-reporting-summary-flat.pdf，April 2023 版，本地逐页读取 p.1）。
- PRISMA 2020 第 27 条逐字要求：「Report which of the following are publicly available and where they can be found: template data collection forms; data extracted from included studies; **data used for all analyses; analytic code**; any other materials used in the review.」（PRISMA_2020_checklist.pdf，本地逐页读取 p.2）

**做到什么程度：** 用户真正要的不是一个 GitHub 仓库，而是**（a）Methods 里那句软件与版本号的话**、**（b）一份能存档、能应付「请提供分析代码」这条审稿意见的脚本**。脚本要与产出的表**逐格对应**（表里每个数字都能追到脚本哪一行），否则脚本反而变成风险。

### P2 原始软件输出对照（.spv 之类）

**这一项被高估了，但不是零。** 证据两面：

支持侧：CRAN 上真实存在一个包 **`r2spss`（v0.3.2，2022-05-25）**，功能是「creates plots and LaTeX tables that look like SPSS output for use in teaching materials」（cran 镜像页，2026-08-04 取）。一个包专门为了「长得像 SPSS 输出」而存在，说明这个外观在**教学与导师验收**场景里有独立价值。

反对侧：用户在 SPSS 原生输出上的实际体验是持续挫败。SPSS 教程作者的建议原文是「we recommend you **only use the pivot table editor when all other methods have failed**」，理由是「you cannot copy and re-run any operations done in the pivot table editor」，并直言「SPSS users tend to spend considerable time and effort manually adjusting output items」（mlln.cn/quarto/SPSS-tutorials/spss-output/，2026-08-04 取）。

**结论：** 交付「中间量对照表」（各组 n、df、检验统计量、精确 p、效应量、CI），用于导师/审稿人复核；**不要**仿造 SPSS 界面截图。详见第八节。

### P2/慎做 「这个结果到底能不能发 / 该怎么说」

需求真实存在且强烈（见第五节），但这是本次调研中**风险最高的一项**。处理方式必须从「结论断言」改为「决策辅助」，见第八节。

## 三、格式即价值：学科惯例差异对照

这是用户自己做最费时、最容易做错、且**做对了没人夸、做错了直接被退**的部分。关键发现是：**不存在统一惯例，惯例按「目标期刊所属体系」分裂。产品必须做「体系选择器」，不能设一个全局默认。**

### 3.1 p 值报告：四套互不兼容的规则

| 维度 | APA 7（心理/教育/社科） | AMA / NEJM（医学） | SAMPL（生物医学通则） | 经济/管理（Stata 生态） |
|---|---|---|---|---|
| 前导零 | **无**（`p = .034`）——「Do not use a zero before a decimal when the statistic cannot be greater than 1 (proportion, correlation, level of statistical significance)」 | **无**（AMA：「a zero should be placed before the decimal point for numbers less than 1, **except** when expressing the 3 values related to probability: P, α, and β」） | 未强制 | **通常有**（`p = 0.034`） |
| 大小写 / 斜体 | 斜体小写 *p* | 大写 P（GraphPad/NEJM 写作 "P value"） | 大写 P | 小写 p |
| 小数位 | >.01 两位；.01–.001 三位 | NEJM 逐字：「P values larger than 0.01 should be reported to two decimal places, those between 0.01 and 0.001 to three decimal places」 | **一到两位**：「P values should be reported as equalities when possible and to one or two decimal places (e.g., P = 0.03 or 0.22 not as inequalities: e.g., P < 0.05)」 | 常直接用星号替代 |
| 最小可报值 | `p < .001` | 「P values smaller than 0.001 should be reported as P<0.001」 | 「The smallest P value that need be reported is P <0.001, **save in studies of genetic associations**」 | 同 |
| 「不显著」 | 报精确值 | 报精确值 | **「Do NOT report "NS"; give the actual P value.」** | 常留空或不标星 |

来源：APA Style *Numbers and Statistics Guide* 7th ed.（apastyle.apa.org/instructional-aids/numbers-statistics-guide.pdf，© 2024，Last Updated September 11, 2024，本地逐页读取 p.2）；SAMPL Guidelines（EQUATOR PDF，2013，本地逐页读取 p.5）；GraphPad FAQ 1885「How to report P values in journals」（graphpad.com/support/faq/how-to-report-p-values-in-journals/，2026-08-04 取，含 NEJM 逐字规则）；AMA 规则来自 Wiley 托管的 AMA guidelines 摘要（onlinelibrary.wiley.com/pb-assets/.../Decimal%20places...AMA%20guidelines-1666156207.pdf）+ 搜索摘要，**未逐字读取 AMA 手册原文，置信度中**。

### 3.2 `p = .000` —— 那个经典错误

APA 官方指引逐字：「In tables and figures, report exact *p* values (e.g., *p* = .015), unless *p* is < .001 (instead write as "<.001").」（APA Numbers and Statistics Guide p.2）。

而 SPSS 默认只显示三位小数，任何小于 .0005 的值被显示为 `.000`，用户直接抄进论文即成错误。Statology 的表述最直白：「**Never write p = .000** (although some statistical software report this) because it's not possible. Instead, write p < .001.」（statology.org/how-to-report-p-value/，2026-08-04 取）。

**产品含义（很具体）：** 数据分析卡片输出任何 p 值时，必须走一个**统一的格式化函数**，禁止把引擎原始浮点直接串进文字。这个函数需要吃两个参数：`目标体系（APA/AMA/SAMPL/econ）` 与 `原始 p`。这是一条可以直接写进实现约束的规则。

### 3.3 括号里放什么 —— 学科分裂最严重的一处

- **SAMPL（生物医学）明确禁止用 SE**，两处逐字：
  「**Do NOT use the standard error of the mean (SE) to indicate the variability of a data set.** Use standard deviations, inter-percentile ranges, or ranges instead.」
  「**Do NOT use the standard error of the mean (SE) to indicate the precision of an estimate. The SE is essentially a 68% confidence coefficient: use the 95% confidence coefficient instead.**」（SAMPL p.4、p.5）
- **经济学回归表的默认恰恰是标准误在括号里**（"standard errors appear in parentheses below the coefficient estimate"，多源一致，2026-08-04 检索）。
- AJE 中文站给中国作者的建议与 SAMPL 一致：「应采用标准差(SD)而非标准误差(SE)描述数据变异性」（aje.cn/arc/statistical-methods-and-results，2026-08-04 取）。

**同一个括号，医学里放 SE 是错，经济学里放 SE 是默认。** 这条差异如果做错，产物在半个学科里是废的。

### 3.4 `mean ± SD` 与 `mean (SD)` —— 中英规范正面冲突

SAMPL 逐字：「Summarize data that are approximately normally distributed with means and standard deviations (SD). **Use the form: mean (SD), not mean ± SD.**」（SAMPL p.4）

而中文医学期刊长期通行 `x̄±s` 写法。《中华流行病学杂志》统计报告规范的中文转述是：连续变量「符合正态分布时采用均数（标准差）描述，否则采用中位数（四分位间距）描述」；分类变量「采用频数（百分比）描述」（医咖会 mediecogroup.com/zhuanlan/lessons/408/，2026-08-04 取）——**注意这里用的是括号式，与 SAMPL 一致**，说明中文顶刊的规范侧已经在向国际靠拢，但基层作者的肌肉记忆仍是 `±`。

**产品含义：** 「中文期刊 vs 英文期刊」不是简单翻译，连描述统计的**符号形态**都要换。这是双语需求刚性的直接证据（见第六节）。

### 3.5 星号阈值：心理学 vs 经济学差一档

- 通行三档（APA/NEJM/Prism 一致）：`* P<0.05`、`** P<0.01`、`*** P<0.001`；GraphPad Prism 5.04/d 起加了第四档 `**** P<0.0001`（GraphPad FAQ 1885，逐字对照表，2026-08-04 取）。
- **经济学惯例整体宽一档**：`* p<0.1`、`** p<0.05`、`*** p<0.01`。Statalist 上有专帖讨论「Why do many economists put an asterisk next to *p<.10?」（statalist.org/forums/.../1754832，帖子本身 403 未取到正文，标题可见）；统计学家 Andrew Gelman 的博客 2026-06-22 有一篇专门吐槽经济学星号惯例的文章（statmodeling.stat.columbia.edu/2026/06/22/...，未逐字读取，**置信度中**）。

### 3.6 表格线型（三线表）

中文期刊侧：三线表由**顶线、底线（粗）+ 栏目线（细）**三条线构成，无竖线。搜索到的中文教程普遍引用「顶线和底线（1.5磅）、栏目线（0.75磅）」的具体磅值，但**该磅值在我实际抓到的 CSDN 原文里是「评论区引用的另一篇文章」而非作者主张**（blog.csdn.net/m0_51211389/article/details/119274688，2026-08-04 取，作者本人明确未给磅值）——**因此 1.5pt/0.75pt 这组数字标为「广泛流传但未在权威源逐字核实」，置信度低-中。**

APA 表格「只有横线、无竖线」的规则符合我的常识与所有二手资料，但**本次未从 APA 官方 PDF 逐字取到表格线条条款**（我读到的 Numbers and Statistics Guide 只覆盖数字与统计符号，不含表格章节）——**标未逐字核实，置信度中**。

## 四、报告规范硬清单与「最低必报项」

### 4.1 Nature Portfolio Reporting Summary —— 逐字十条（最可操作的一份）

这是最适合直接做成产品内 checklist 的清单，因为它是**投稿时必须逐条打钩提交的表单**，不是建议。逐字（nature.com/documents/nr-reporting-summary-flat.pdf，April 2023 版，本地读取 p.1，Statistics 段）：

> "For all statistical analyses, confirm that the following items are present in the figure legend, table legend, main text, or Methods section."
>
> 1. The exact sample size (*n*) for each experimental group/condition, given as a discrete number and unit of measurement
> 2. A statement on whether measurements were taken from distinct samples or whether the same sample was measured repeatedly
> 3. The statistical test(s) used AND whether they are one- or two-sided（附注：*Only common tests should be described solely by name; describe more complex techniques in the Methods section.*）
> 4. A description of all covariates tested
> 5. A description of any assumptions or corrections, such as tests of normality and adjustment for multiple comparisons
> 6. A full description of the statistical parameters including central tendency (e.g. means) or other basic estimates (e.g. regression coefficient) AND variation (e.g. standard deviation) or associated estimates of uncertainty (e.g. confidence intervals)
> 7. For null hypothesis testing, the test statistic (e.g. *F*, *t*, *r*) with confidence intervals, effect sizes, degrees of freedom and *P* value noted（附注：*Give P values as exact values whenever suitable.*）
> 8. For Bayesian analysis, information on the choice of priors and Markov chain Monte Carlo settings
> 9. For hierarchical and complex designs, identification of the appropriate level for tests and full reporting of outcomes
> 10. Estimates of effect sizes (e.g. Cohen's *d*, Pearson's *r*), indicating how they were calculated

同一份表单还强制 **Life sciences study design** 五项：Sample size / Data exclusions / Replication / Randomization / Blinding，并注明「All studies must disclose on these points **even when the disclosure is negative**」（同上 p.2）。

### 4.2 SAMPL —— 最全的「方法段该写什么」

SAMPL 的 General Principles for Reporting Statistical Methods 逐字要点（SAMPL p.3–p.4）：

- Preliminary analyses：「Identify any statistical procedures used to modify raw data before analysis.（举例：数学变换使分布接近正态、构造比值或衍生变量、把连续数据折成分类数据或合并类别）」
- Primary analyses：「Describe the purpose of the analysis.」「Make clear which method was used for each analysis, **rather than just listing in one place all the statistical methods used**.」「Verify that data conformed to assumptions of the test used to analyze them.」「Indicate whether and how any allowance or adjustments were made for multiple comparisons.」「If relevant, report how any outlying data were treated in the analysis.」「Say whether tests were one- or two-tailed and justify the use of one-tailed tests.」「Report the alpha level (e.g., 0.05).」「Name the statistical package or program used.」
- Supplementary analyses：「Describe methods used for any ancillary analyses, such as sensitivity analyses, imputation of missing values, or testing of assumptions.」「**Identify post-hoc analyses, including unplanned subgroup analyses, as exploratory.**」

回归分析专项（SAMPL p.6）：「Report how any missing data were treated in the analyses.」「Report the regression coefficients (beta weights) of each explanatory variable and **the associated confidence intervals and P values, preferably in a table**.」「Provide a measure of the model's "goodness-of-fit"（r²/R²）.」「Specify whether and how the model was validated.」「report whether the variables were assessed for a) colinearity and b) interaction」。

**「preferably in a table」这一句直接背书了 P0-1：规范本身就说结果该以表格形态交付。**

### 4.3 PRISMA 2020（系统综述/Meta）

与统计交付相关的逐字条目（PRISMA_2020_checklist.pdf，本地读取）：

- 12 Effect measures：「Specify for each outcome the effect measure(s) (e.g. risk ratio, mean difference) used in the synthesis or presentation of results.」
- 13b：「Describe any methods required to prepare the data for presentation or synthesis, such as handling of **missing summary statistics**, or data conversions.」
- 13d：「...If meta-analysis was performed, describe the model(s), method(s) to identify the presence and extent of **statistical heterogeneity**, and software package(s) used.」
- 13e / 13f：亚组分析与元回归的方法；**敏感性分析**方法。
- 19：「For all outcomes, present, for each study: (a) summary statistics for each group (where appropriate) and (b) **an effect estimate and its precision (e.g. confidence/credible interval)**, ideally using structured tables or plots.」
- 20b：「Present results of all statistical syntheses conducted. If meta-analysis was done, present for each the summary estimate and its precision (e.g. confidence/credible interval) and measures of statistical heterogeneity. **If comparing groups, describe the direction of the effect.**」
- 27：数据与**分析代码**的可得性（见 P1-3）。

### 4.4 ARRIVE（动物实验）

第 10b 条逐字：「If applicable, the effect size with a confidence interval.」解释部分逐字：「statistical significance is heavily influenced by sample size and variation in the data」；效应量是「a quantitative measure that estimates the magnitude of differences between groups, or strength of relationships between variables」；建议逐字：「**Report all analyses performed, even those providing non-statistically significant results.** Report the effect size to indicate the size of the difference between groups in the study, with a confidence interval to indicate the precision of the effect size estimate.」（arriveguidelines.org/arrive-guidelines/results/10b/explanation，2026-08-04 取）

### 4.5 CONSORT / STROBE

CONSORT 2010 与统计交付最相关的一条：「For each primary and secondary outcome, results for each group, and the estimated effect size and its precision (such as 95% confidence interval).」STROBE 覆盖队列/病例对照/横断面研究的 setting、participants、variables、statistical methods 与 results（多源汇总，2026-08-04 检索；**未逐字读取 CONSORT/STROBE 官方 PDF，置信度中高**）。SAMPL 自述与这些方法学指南是互补关系而非重复：「These guidelines for reporting methodologies all include items on reporting statistics, but the guidelines presented here are more specific and complement, not duplicate, those in the methodology guidelines.」（SAMPL p.2 逐字）

### 4.6 「最低必报项」—— 跨规范交集（这就是产品的验收清单）

把 Nature Reporting Summary、SAMPL、ARRIVE、PRISMA、ICMJE 求交集，得到**任何一个学科都不会错的六项**：

1. **精确样本量 n**（每组、每分析；含分母 —— SAMPL：「Report numerators and denominators for all percentages.」）
2. **效应量**（并说明怎么算的 —— Nature 第 10 条）
3. **95% 置信区间**（不是 SE）
4. **精确 p 值**（不写 NS、不写 p<0.05、不写 p=.000）
5. **检验前提是否满足 + 多重比较是否校正**（Nature 第 5 条 / SAMPL 明列）
6. **缺失数据如何处理 + 统计软件与版本**

**产品含义：** 这六项应做成「交付前自检」的硬闸——生成的结果里少任何一项就在产物面板显式标红，而不是静默交付一个看起来很完整的报告。这与本仓库「宁可吵也不要假绿灯」的既有工程价值观一致。

## 五、用户对「解释」的需求：三层，只有前两层该做

用户嘴上说要「解释」，但「解释」实际是三件完全不同的事，混在一起做会出大事。

**第一层：读数（这个数字是什么）。** 「Sig.值小于0.05说明什么？」「这个系数是正的好还是负的好？」（turingpub 引用的用户原话，2026-08-04 取）。这一层是确定性的、可模板化的，**必做**。

**第二层：措辞（能不能这么说）。** 这是需求密度最高的一层，也是最被低估的。证据：

- ICMJE / SAMPL 的规范核心就是措辞约束：不能只报 p 值、不能把相关说成「low/moderate/high」除非定义了区间（SAMPL p.5 逐字：「Do not describe the association as low, moderate, or high unless the ranges for these categories have been defined.」）、post-hoc 分析**必须**标为 exploratory。
- 从业者反复强调的也是措辞而非计算：「It's crucial to not only report statistical significance but also consider the practical significance through effect size and confidence intervals.」（Animesh Gandhi，LinkedIn 专业问答，linkedin.com/advice/0/how-do-you-interpret-report-results-spss-analysis，2026-08-04 取）
- 付费服务商对自己客户的诊断是**最直接的证据**：「**Most students are not marked down because their statistics are wrong. They lose marks because the write-up is confusing**」——太多输出、解释不足、缺效应量、与研究问题连接薄弱（premierdissertations.com，2026-08-04 取）。

**这句话应该被贴在这张卡片的需求文档第一行。用户的失败模式不是算错，是写错。**

**第三层：判断（这个结果能不能发 / 意味着什么）。** 需求真实（「不会写 discussion」在中文内容生态里是一个成熟品类，搜索可见知乎/博客园/丁香通/清新电源等多平台长文，2026-08-04 检索），但这一层**输出的是学术主张**，一旦模型说「你这个结果支持 XX 结论」而实际不支持，责任在我们。

**结论：第一、二层做实，第三层降级为「审稿人会问什么」的问题清单**——用提问代替断言。「审稿人可能会问：你的 post-hoc 分析是否预先注册？」是安全的；「你这个结果可以发 SCI 二区」是不安全的。

## 六、双语需求：比想象的刚性，但不是「翻译」

**结论：中文用户投英文期刊时，需要的不是翻译，是「换一套规范体系重新生成」。**

证据链：

1. **中文用户读中文指南、写英文论文。** AJE（American Journal Experts）专门运营中文站，并用中文写「如何描述统计方法和结果」的指南（aje.cn/arc/statistical-methods-and-results，2026-08-04 取），逐字给出「以精确值而不是范围（如 p=0.049 而不是 p<0.05）来报告 p 值」「应采用标准差(SD)而非标准误差(SE)」「必须说明所用统计软件及版本号（如 "SPSS v.21.0"）」。**一个英文编辑公司花力气写中文统计规范指南，说明这个错配是它的主要客源。**

2. **翻译是真金白银的支出。** 意得辑（Editage）中译英学术翻译明码标价 **「¥0.65/字 起」**，实际折后 **1–2000 字 ¥0.88/字（3 个工作日）、2001–4000 字 ¥0.76/字（4 个工作日）**，并把「期刊格式排版」作为附加权益（editage.cn/services/translation/professional，2026-08-04 官网实测）。**一篇 5000 字的稿子按此价大约 ¥3800–4400。** 这是「双语」这件事的真实标价。

3. **规范体系本身不同，不是词汇不同。** 见 3.4：中文肌肉记忆是 `x̄±s`，SAMPL 明令 `mean (SD)`；中文习惯 `P<0.05`，SAMPL 明令报等式且不许写 NS。**直译过去仍然是不合规的。**

4. **中文统计工具已经在往英文交付走**：SPSSAU 上线「国际版，全英文数据分析界面」（CSDN 官方账号文章，blog.csdn.net/m0_37228052/article/details/144432095，2024-12 发布，2026-08-04 检索到）——**间接证据，置信度中**。

**产品含义：** 双语开关不能是「点一下翻译成英文」，必须是「切换目标体系」——同一份分析，选「中文核心期刊」和选「Nature Portfolio」，产出的表格线型、p 值写法、离散度符号、必报项清单**全都不同**。这是本调研得出的最强的产品形态结论。

## 八、我们不该做什么（砍需求）

**1. 不做「一键出完整分析报告 PDF」。**
用户要的是**可粘贴的碎片**（一张表、一段话、一句 Methods），不是一份自成体系的报告。报告形态的东西无法粘进 Word 模板，会被用户拆开重排——所有格式工作等于白做。证据：全部付费服务商卖的都是「表格 + Results 段 + Chapter 4 打磨」这种**按稿件部位切分**的产品（premierdissertations.com），没有一家卖「分析报告」。

**2. 不做 SPSS 原始输出界面的仿制（.spv 外观复刻）。**
`r2spss` 的定位说得很清楚：「for use in **teaching materials**」（CRAN，v0.3.2）。仿 SPSS 外观的价值场景是教学，不是投稿。我们复刻它只会得到一个**既不能投稿、又比 SPSS 本身更不可信**的中间产物。真正该给的是**中间量对照表**（n / df / 检验统计量 / 精确 p / 效应量 / CI），用于导师和审稿人复核。

**3. 不做「这个结果能不能发 / 能发几区」的结论性判断。**
需求真实，但输出的是学术主张，错了责任在我们，且用户会拿它去做投稿决策。**改做「审稿人会问什么」的提问清单**——用提问代替断言，价值几乎一样大，责任面小一个量级。旁证：SAMPL 实施评论指出只有约 5% 的 WAME 会员期刊明文引用统计报告指南（PMC12036030），意味着「能不能发」在客观上没有稳定判据可依。

**4. 不设「全局默认格式」。**
第三节已证明：p 值前导零、小数位、括号里放 SD 还是 SE、星号阈值、离散度符号，**在医学 / 心理 / 经济三个体系里两两冲突**。设一个全局默认等于在两个学科里默认输出错的东西。必须做「目标体系选择器」，且**选择器要在生成之前问，不能在生成之后改**（改一遍等于重跑）。

**5. 不做统计方法的自动挑选与自动跑（「你上传数据我告诉你该用什么检验」）。**
这是 SPSSAU 被批评的地方：有评论指出它「对变量的限制不足…优先保证跑得出来，可能导致结果错误，例如直接把分类变量随便赋数值码丢进回归」（知乎问答 663758208 的搜索摘要转述，**原页 403 未逐字核实，置信度中**）。跑得出来 ≠ 跑得对，而错误的统计选择在交付物层面**看起来和正确的一模一样**——这是本卡片最大的隐蔽风险。方法选择应当**显式呈现依据并要求用户确认**，不做静默决策。

**6. 不在数据分析卡片里重建期刊配色/绘图规范系统。**
「科研绘图」已经是独立卡片（`sci_draw`）。数据分析产出统计图的**数据与语义**，最终美化交给绘图卡片。重建 = 两份规范、两处会漂移（本仓库在「fold 有四份」上已经吃过这个亏）。

**7. 不把 p 值格式化交给模型自由发挥。**
必须是确定性函数。理由见 3.2：`p = .000`、`p < .05`、`NS` 这三种写法都是**模型极容易生成、且在目标体系下明确错误**的输出。

**8. 不做「数据代传」式的隐私姿态。**
百度知道那条原声（「会不会把数据发过去然后把数据盗走」）说明**数据交出去这件事本身就是转化漏斗上的一个洞**。产品文案与交互必须正面处理数据去留，而不是回避。

## 九、对卡片形态的直接结论（可作为需求输入）

1. **进入即问目标体系**，不是进入即传数据。第一屏问：目标期刊/体系（中文核心 / APA 心理教育 / 医学 AMA-NEJM / 生物医学 SAMPL / 经济管理 / Nature Portfolio）+ 研究设计（RCT / 观察性 / 系统综述 / 动物实验 / 问卷）。这两项决定后续**全部**格式与必报项清单。
2. **产物面板按「稿件部位」分栏，不按「分析步骤」分栏**：`Methods 统计段` / `Table 1` / `主结果表` / `Results 段（中/英）` / `图` / `脚本与软件版本` / `审稿人预答` / `自检清单`。
3. **自检清单是硬闸不是装饰**：第 4.6 节六项缺任一项，产物面板显式标红并说明缺什么，不静默交付。
4. **表格必须是可编辑的原生表**（Word/LaTeX），不是图片。经管之家那条 2010 年的帖子在 2026 年仍是首位搜索结果——「粘过去变成图片」是这个品类十六年未解的第一痛点。
5. **中英不是翻译按钮，是体系切换**：切换后表格线型、p 值写法、离散度符号、必报项同步变。

## 十、存疑与未核实（务必不要当成结论用）

1. **淘宝/闲鱼「数据分析代做」的具体成交价与商单描述没拿到一手证据。** 搜索配额耗尽前只取到「有人推荐去闲鱼找独立分析师而非淘宝店」的二手建议，**没有价格数字**。这是本主题最大的证据缺口——因为它最直接回答「用户最后掏钱买了什么」。建议下一轮专门补。
2. **中华医学会系列杂志稿约通则原文未取到**（302 跳登录页）。中文医学期刊对统计学符号、`x̄±s`、P 值书写、三线表的官方条款，本文用的是二手转述。
3. **三线表 1.5pt/0.75pt 磅值**：广泛流传，但在我抓到的原文里属「评论区引用」，未在权威源逐字核实。
4. **APA 表格「无竖线」条款**未从 APA 官方 PDF 逐字取到（官方 Numbers and Statistics Guide 不含表格章节）。
5. **AMA Manual of Style 的 P 值小数位规则**来自 Wiley 托管摘要与二手汇总，未逐字读取手册原文。
6. **CONSORT 2010 / STROBE 官方 checklist PDF 未逐字读取**，相关条目为二手汇总。
7. **Reddit 全站不可抓**（爬虫被阻），英文一线研究者原声缺失；**知乎 403**，中文高质量长文原声缺失。本文原声样本偏向论坛老帖、官方社区与服务商自述。
