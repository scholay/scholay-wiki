## §0 · 五条结论先行

1. **这张卡片的核心不是"会统计"，是"按目标体系产出合规交付物"——但"合规交付物"这个空位必须收窄着说。** 跑分析在中文学术市场已经是**免费商品**：SPSSAU 免费版限前 100 行（官网帮助页原文），而工科 DOE 9–30 行、体育每组 8–20 人、语言学被试 20–60 人——A5 五个学科的真实样本量**几乎全部落在 100 行以内**；SPSSPRO 干脆**不设会员购买通道**，用会员换用户去小红书/知乎发种草文（bbs.spsspro.com/news/272）；问卷星的信效度分析**不单独收费**。在"能不能算"这一维上，连一个免费的天花板都打不穿。

   🔴 **修订（2026-08-04）：原稿把结论写成"交付物翻译整体是空位"，被自家 raw 直接反驳。** B2 §四1-4.2 记录 **JASP / jamovi 完全免费、能直接打开 `.sav`**，JASP 官网首要卖点逐字是 "Support for APA format (**copy graphs and tables directly into Word**)"，用户原声是 "opened up my SPSS file and literally ran my first analysis and had a table done **within five minutes**" 与 "**Copy. Paste. DONE**"（r/labrats），jamovi 侧是 "absolutely everything in APA tables you can literally copy and paste into a Word document"（r/IOPsychology）。**"表能直接粘进 Word"这一格已经有免费玩家做完了，而且做得很好。**

   **正确的结论（收窄版）**：空位不是"交付物翻译"整体，而是**「中文三线表 + 目标体系切换 + Methods 统计段」这三格**——JASP/jamovi 只出 **APA 英文表**、**单一口径**、**不产 Methods 段**，且它们的 GUI 骨架在结构上装不下脏表清洗与结构化问诊。逐格对照见 [产品形态 §7.1](./SYNTHESIS-产品形态.md#71-逐条对比) 的六列竞品表（JASP/jamovi 是本次修订补进去的一列）。**不这样收窄，第一条结论会在第一次竞品评审上被打穿。**

2. **如果只能解决一个环节，解决"结果 → 目标体系合规交付物"（三线表 + Methods 段 + Results 成句）。** 不是数据清洗——清洗频次更高（100% 命中）但它是**中间品**，用户不为中间品付钱，且清洗做对而交付不对时价值归零。完整论证见 §3.3，七条独立证据链。

3. **做 21 个方法，分两批（12 + 9）。** 方法条数覆盖 ~85%，但真正该看的指标是**链路覆盖率**（能独立走完全套交付的用户比例）——因为 11/12 的用户和 0/12 的用户一样交不出论文。N>28 之后边际每项 <0.5%，且分别落在互不相交的小众链路。见 §1.2。
   🔴 **两处本次修订**：① 原稿写"20 个（12+8）"，但它自己定义的问卷链里有一步（共同方法偏差 Harman）**两批都没排**，靠数链才发现 ⇒ 补入后是 **21（12+9）**；② 原稿称第一批"闭合医学 Table 1 链、生科多组比较链"，按"链上每步都覆盖"的严格定义**第一批闭合 0 条链**（医学缺多因素 Logistic、生科缺字母标记）——第一批的正确定位是**五条链的公共前缀**。⚠️ 本条排的是**需求优先级，不是 P0 范围**；P0 见产品形态 §6.1。

4. **价值锚点是"一次代做"（¥100–500）而不是"一份 license"，溢价唯一来源是"陪走一轮返修"。** 台湾 EBOSS 的价格阶梯把这条讲得最白：单项分析 1,000 元 → 预试套餐 8,000/10,000/15,000 元 → 正式分析套餐 18,000 元，**贵的那几档卖的全是「修正次數不限制」**，且「若數據更改則增加額外收費」。**返修次数是价格阶梯的自变量**——这是整份调研里最可操作的一条商业情报。见 §5。
   🔴 **本次修订更正一句话**：原稿写"**我们的边际返修成本≈0（脚本可重跑）**"，与自家成本表（产品形态 §8.4-$2：单会话 input 8–20 万 token）**直接冲突**。**必须拆成两类**：**A 类（换格式/换体系/改表样）= 只重跑 report verb，零 LLM 调用，边际确实≈0**；**B 类（补一轮分析）= 新一轮完整 turn，与首轮同量级，只省下 20–30%**。正确的对外表述是「**改格式不限次 + 补分析按轮**」，这仍强于人力代做（对方连 A 类都要重排），但它经得起成本表核对。拆分表见产品形态 §7.3-4。⚠️ 另有硬边界：**返修窗口上限 = 会话工作目录的 30 天 GC**（产品形态 §8.1-T11 实读）。

5. **模型能力不是瓶颈，流程约束才是。** StatQA：GPT-4o 选方法 64.83% > 有统计背景研究生开卷 53.45% > 无统计背景 34.48%（arXiv:2406.07815；⚠️人类基线仅 n=6，只能作弱证据）。但 BLADE 显示模型**概念变量选择精度 60–70%（最强）、统计模型选择 <35%（最弱）**；端到端真实分析基准**无一超过 50%**（DABstep hard 45.24% / DSBench 34.12% / DiscoveryBench 25% / ScienceAgentBench 32.4%）。工程投入应压在"前提检验夺权给确定性代码 + 数字锁死在执行产物 + 不可跳过的结构确认"，不是"让模型更懂统计"。

### 3.2 一条被反复低估的卡点：**"跑出来了，但不知道能不能用"**

IBM SPSS 官方社区一位用户的原话把它说全了：
> 「How do I resolve these error messages and **are the output results valid if the error messages show?**」

同帖三个人给了三种猜测，**没有定论**。用户拿着一份"可能有效也可能无效"的输出去写论文。这一条在现有任何产品里都无人负责，而它的实现成本极低（把警告映射成"影响/不影响结论"的确定性判定表）。

### 3.3 **如果只能解决一个环节：解决第 2 个（结果 → 目标体系合规交付物）**

> 🔴 **先钉一条边界（本次修订新增，否则下面七条证据会被误读）**：这七条证明的是**"结果→交付物"这个环节值钱**，**不是**"这个环节没人做"。**"表直出 Word"那一格已有免费玩家**——JASP/jamovi（B2 §四）。**真正空着的是三格**：**中文三线表口径**（它们只出 APA 英文表）、**目标体系切换**（它们单一口径）、**Methods 统计段**（它们只有 annotated output，不产方法学段落）。下面第 3 条与第 6 条的证据强度不受影响，但结论必须按这个收窄口径引用。

不和稀泥，直接给结论和七条证据：

1. **三家国际大厂在 2025Q4–2026Q1 同时押注同一件事。** IBM SPSS AI Output Assistant、Minitab AI、JMP Assistant——三家独立公司、同一时间窗、全部押在"把已跑出的结果翻译成人话"，而不是"帮你跑"。三家独立收敛到同一结论，是本次调研里最强的单一需求信号。
2. **两家形态与我们几乎完全一样的中文 AI 竞品，把"三线表"当第一卖点。** ChatSPSS 首屏原文「上传 CSV/Excel/SPSS(.sav)/Stata(.dta) 数据或直接描述研究问题，**自动生成三线表与专业解读**」；ChatSRS 按方法拆 SEO 内容页，`/blog/ai-spss-three-line-table` 是其主力页。**它们用真金白银的 SEO 投入选出了同一个卖点，不是"方法多"。**
3. **一个统计能力远弱于 SPSS 的在线工具，靠"三线表直出 + 指标解读"拿到了学术渗透。** SPSSAU 把"默认三线表格结果、一键复制导出"写进八大卖点；OpenAlex 全文检索命中 **1,145 篇**（厂商自称 CNKI 12,384，约 10 倍口径差，取小的那个）。
4. **代做供给侧自己把这一段拆成独立价位。** 台湾新菊统计的价目原文：「上述費用**僅提供輸出結果，不含資料檔及結果報表說明**」——想要解读请另外买。**从结果到可用文字，是供给侧公认的独立生意。**
5. **服务商对客户失败模式的诊断。** Premier Dissertations：「**Most students are not marked down because their statistics are wrong. They lose marks because the write-up is confusing.**」——用户的失败模式不是算错，是写错。
6. **十六年没被解决。** 经管之家 2010-12-07 的帖子「SPSS 输出的表格复制到 word 上变成图片了？」，2026 年仍是该关键词的首位搜索结果。**一个纯格式问题养出一整条教程内容链 + 可下载的 SPSS 样式文件 + B 站视频 + 两家 AI 创业公司的首要卖点——这就是真痛的定义。**
7. **这是唯一"需求与 LLM 能力同时对齐"的环节。** B4 §四明确列出：解释统计输出给非统计背景的人听是 LLM 原生强项，Elsevier 政策原文允许"generating data visualizations directly derived from underlying datasets"且明确「This policy does not prevent the use of AI tools in formal research design or research methods」；而端到端分析基准无一超 50%。**在这一环，我们做的是模型擅长的事；在"全自动分析"那一环，我们做的是模型最不擅长的事。**

**为什么不是第 1 个（数据清洗）**——尽管它频次更高：
- 清洗是**中间品**。用户拿到一份干净数据后仍然要去 SPSSAU（¥9.8）跑、仍然要手工排三线表。价值不闭合。
- 反过来成立：只做交付物翻译，用户**至少能从已有结果拿到完整价值**——而且有一条零门槛入口：`.spv` / 已跑好的输出 → Results 段。这条路**零隐私顾虑、零学习成本、天然绕开人遗条例与 PIPL 的全部锋利边界**（A7 §0 结论 3）。这是可以独立验证需求、且转化漏斗上没有"交数据"这个洞的唯一入口。
- 排序结论：**交付物翻译做第一优先，清洗做紧随其后的第二优先**——两者最终都必须有，但如果只能有一个，交付物翻译的价值是闭合的。

**一条锋利的旁证支持这个定位。** Julius AI 已经真的进了已发表论文的方法学段落（Europe PMC 全文检索命中 53 篇，含 PLoS Medicine 2025-12-05, PMC12680241），但那篇的原文是：
> 「All the analyses ... were performed using **Stata software, version 17/SE** ... **Data visualizations were performed using Julius AI**」

**在高分刊里，统计仍然交给 Stata/SPSS，AI 只被允许做"数据可视化"。天花板不在"能不能进论文"，而在"被允许进论文的哪一段"——而"合规交付物"恰好是最容易被允许、也最没人做的那一段。**

### 5.2 判断

**① 锚点是"一次代做"（¥100–500），不是"一份 license"。**
国际正版价格对中国学生**客观上不存在**——我们不是在跟任何一个正版标价竞争，是在跟 **0 元 + 一个下午的安装折腾**竞争。三个真实心理锚点是 `¥0（破解/免费额度）`、`¥9.8–258（SPSSAU 档）`、`¥100–500（代做）`，**锚在中间偏上那档**。

**② 计费形态必须是按次/按天/按产物，不能按年订阅。**
需求是脉冲式的（开题/中期/盲审前/投稿返修）。SPSSAU 敢卖 ¥9.8/24 小时说明市场天然接受这个形态；L2 垂直云平台（微生信微币充值、Chiplot 按单工具标价）全部是**按产物计价**而非按时间订阅——因为用户的心理账户是"我要出这一张图"，不是"我要用这个软件一个月"。这与本仓已有的**经费/算力点按量付费**模型天然兼容。

**③ 溢价的唯一来源是"返修"，而这恰好是我们成本结构上的优势。**
把 §5.1 的价格带竖着读一遍：从 ¥1,000（EBOSS 单项）到 ¥18,000（不限次修改套餐），**中间隔的不是方法数量，是返修次数**。EBOSS 的两句条款是全份调研里最硬的定价情报：
> 「**修正次數不受限制**」（预试套餐）
> 「在**問卷資料保持不變**的條件下，修改次數無限制；**若數據更改則另外收費**」（正式分析套餐）

而 zuoyedaixie 的 $299–599 档对应的是**有界的两轮免费修改**——返修次数就是价格阶梯的自变量。

**人力代做的返修边际成本是线性的（每一轮都要人重做一遍），我们的更低（脚本可重跑 + 会话有状态）。这是唯一一处我们的成本曲线优于代做市场的地方，也就是唯一的溢价空间。**

| 返修类型 | 实际发生什么 | 我们的边际成本 | 能不能承诺"不限次" |

**④ 推荐的三段式定价结构：**
- **免费引流**：数据体检 + 结构确认卡 + `.spv`/已有输出翻译（零隐私门槛、30 秒可见价值、独此一家）

### 7.2 上线后的验证指标（第一周就该有）

**A. 直接校准 §1.2 的覆盖率（最高优先）**
- `方法请求分布的累积曲线`：实际被请求的方法 Top-N 累积占比 → 直接给出真实的 N。**如果真实曲线的 knee 落在 12 之前，第二批可以推迟；落在 28 之后，说明我选的 20 项选错了品种**
- `链路完成率`：进入卡片的会话中，走完「进数据 → 分析 → 至少下载/复制一个交付物」的比例。**这是覆盖率的唯一真实测量**
- `断链位置分布`：没走完的会话卡在哪一步（读文件失败 / 结构确认放弃 / 方法不支持 / 交付物不满意）

**B. 验证 §3.3「交付物翻译是第一优先」**
- `产物复制/下载率`，按类型分：Table 1 / 主结果表 / Methods 段 / Results 段 / 图 / 脚本 / 自检清单。**如果 Methods+Results 段的复制率显著低于表，§3.3 的判断被证伪**
- `.spv / 已有输出入口的独立转化率` vs `上传原始数据入口` —— 验证"零隐私门槛入口"假设（不确定性 #7 的产品面）

**C. 验证 §5「溢价来自返修」（最弱的一环）**
- `7 天 / 30 天内同一份数据的二次会话率` —— 溢价假设的核心指标。**低于 15% 则"陪走返修"的定价结构不成立，需要回到按次交付**
  ⚠️ **口径必须钉死（本次修订）**：① **"同一份数据"= `project.json.source_files[].sha256` 相同**，不是"同一个会话"——用户新开会话重传同一份表也算二次返修（产品形态 §4.1 的 `consult` verb 与字段表就是为这个指标存在的）；② **30 天那一档踩在悬崖边**：会话工作目录的 GC 默认 30 天（产品形态 §8.1-T11），第 31 天回来的用户**数据已被删**，会被记成"没有二次会话"而实际是"我们把它删了"——**这两种情况必须在埋点上可区分**，否则这个核心指标从第一天起就是脏的
- `A 类返修（换格式/换体系）与 B 类返修（补分析）的次数比` —— 直接决定 §5.2③ 那个定价结构的可行性（A 类才是我们边际≈0 的那一类）
- `审稿意见入口的使用量与付费转化` vs `常规分析入口`
- `付费档位分布` + `从免费体检到付费的转化漏斗`

**D. 验证工程与合规假设**
- `上传格式分布` + `行数/列数/文件大小的 P50/P90/P99` + `30MB 撞墙率` → 校准不确定性 #8
- `目标体系选择分布`（中文核心 / APA / AMA-NEJM / SAMPL / 经济管理 / Nature Portfolio）→ 校准 P0-1 的实现优先级。⚠️ **P0 只实现中文核心 + APA 两套**（产品形态 §4.1.3），但**选择器里要把另外四项也列出来并记录点击**——"想选却选不到"的数据正是 P1 补包排序的唯一依据；点了未实现项时明确告知"这套体系在做，先按最接近的出，你可以自己改"
- `前提检验不满足的触发率` 与 `分流后用户是否回退`
- `9/99/999 未登记为 user-missing 的出现率` → 决定要不要默认主动询问
- `结构确认卡的放弃率` —— 如果 >30%，说明 P0-6 的形态需要重做（但**不能取消这一步**，理由见 §4 P0-6）

**E. 风险监控**
- `L3 硬拒请求命中率` + `拒绝后是否继续会话` —— 验证"给替代路径 vs 静默拒绝"的效果（产品形态 §九-21 / §2.7）
- `数字硬拦触发率`（文字中出现但不在执行产物 JSON 里的数字）—— 这是 F7 防线是否真的在工作的唯一证据
