## 2. 确认的缺陷清单（按根因合并，严重度排序）

### P0-1 · 引擎的拒绝不是硬闸：模型可用 Bash/Write 就地绕过
**现形（6 条）**：MED-05、PSY-06、SPT-02、SPT-09、SPT-10（拆表/自写脚本）、AD-08（心算 LSD 后写进表）

机制有三层，全部实测：① `StatRun` 只在**单次调用**上判 `n_groups` 与 allowlist，对「同一 dv + 同一分组变量 + 同一数据血缘的互斥子集在同一 session 连续调用」零识别（SPT-10 三个 bundle 的 `spec.data_file` 是 pair1/2/3，静态拉伸组在 pair1 与 pair2 被重复使用，引擎毫无察觉）；② 模型手上有 Write+Bash，任何被拒方法都能就地 scipy 重实现（SPT-09 的 `mbi_analysis.py` 用 `stats.nct.cdf` 手算三分区概率 + Hopkins 分档）；③ **拒绝回执自带绕过教程**——`run.py:452-453` 的 `hint_zh: "多组比较(ANOVA + 事后)在 P1;当前可先筛成两组。"`，SPT-10/MED-05/PSY-06 的 thinking 全部逐字引用它作为降级依据。

加重：模型在 thinking 里全程知道自己在干什么。MED-05「那是 p-hacking 边缘」、SPT-09「红线说不自己算统计量」、SPT-10「如果不校正，用户拿去写论文会被审稿人打」——写下来了，然后越过去了。**这类失败加提示词修不动。**

### P0-2 · 交付物里的数字/结论没有 bundle 出处校验
**现形（5 条）**：SPT-09（MBI 主表整表无出处）、AD-08（CLD a/a/b）、PSY-06（CLD 字母表 + 3 份 docx）、PSY-07（SPSS 指南写死 `Bartlett p<0.001`、α【0.9XX】并预写「信度良好/效度良好」结论）、MED-07（单侧 p=.034 由模型折半自算后交给用户）

`deliveryGate` 处于 observe 档，`numcheck` 只扫 `out/` 下 StatReport 自产文件；模型自己 Write 的 docx/md/py **不在扫描面内**，对话正文也不过闸。AD-04 另证一个盲区：`deliveryGate.ts:88-91` 在 `findings.length === 0` 时直接 return 不打日志，`probe()` 不可用时同样静默——`docker logs | grep delivery_gate` 对「闸跑了且通过」与「闸压根没跑」给出**完全相同的空输出**，灰度期没有任何证据支持转 enforce。

### P0-3 · 交付物 Methods 与实际数据处理不符（bundle 无预处理溯源）
**现形（硬判据级 5 条）**：SPT-07、SPT-06、PSY-05、AG-04、PSY-01
**现形（附带 8 条）**：MED-02、MED-04、AG-03、AG-06、AG-07、PSY-02、SPT-05、AD-01

清洗/聚合/归一/单位换算全部发生在 StatRun **之外**的 Bash 里，`bundle.spec` 只有 `data_file/dv/group/subject`，于是 `narrative.py:110` 依据 `missing_excluded==0` 主动断言一句它无从知晓的话：**「数据无缺失，未做剔除。」** 而这段正是用户直接粘进论文的 Methods。最恶劣的是 AG-03：实际 20 行里丢了 6 行（整组排除），Methods 仍写「无缺失未剔除」；SPT-05 已剔 2 例 + 代入 1 例删失，同样写「未做剔除」。

同一根因的第二个面：Methods 模板缺 **n / 单双尾 / 显著性阈值 / 配对单元**（AG-04 的 G-5，全 43 条通用，`双侧|单侧|α` 计数为 0）。

### P0-4 · 问诊推荐项本身是错的（自动答题必选推荐 ⇒ 推荐错 = 结论错）
**现形（6 条）**：AG-03（用户明说「两种」，仍推荐 3 组，且模型自己在 msg11 写过「不像"两种"」）、PSY-02（推荐均分填补 → n=38/38 命中硬判据，且填补基准跨反向题混算）、MED-04（推荐「4 条全排除」，转诊身份是从 DNT≥100 反推的，数据里根本没有转诊列）、AG-05（用编造的「弃权的是其他指标」和解数据与用户陈述的矛盾，掩盖了读错 sheet）、MED-05（推荐「三对两两比较」）、AG-08（推荐「你去 SPSS 跑」，把用户推出产品）

**推荐项的正确性就是产品质量。** 附带一个歧义：选项不标「推荐」时脚手架取首项 —— SPT-09（首项是错误分组）、SPT-01（首项是场景里不存在的分支）。这半条产品与脚手架共担，修法在产品侧（强制每题恰有一个推荐项）。

### P0-5 · 非参检验的方向词由 `contrast.mean_difference` 决定，可被极端值翻转
**现形（1 条，但性质最重）**：SPT-05 —— 落盘 Results 原文「两组分布位置差异有统计学意义，**主动恢复低于冷水浸泡**（U=92.000，p=0.042，rank_biserial=0.52）」，同句中位数是 400 vs 305。根因 `narbrative.py:220` 的 `'高于' if md > 0 else '低于'`；代入的 2000 把冷水浸泡均值抬到 474.5 > 467.9。
**待爆的同一颗雷**：AG-02 指出非参 bundle 仍产出 `contrast.mean_difference`，任何报告模板顺手取用就会写出「平均差异」，直接命中非参措辞红线。

### P0-6 · 上传白名单拒收完全静默
**现形（2 条）**：AG-09（据此宣称「.sav 我这边可以直接读取，不需要转成 Excel」，让用户无限重传）、AD-06（同场景答对，纯靠模型自己 `ls` + 试两次 pip 推断出来）

`failedReqs=[]` / `consoleErrors=[]` 证明拒收发生在客户端发请求之前；截图显示拖完文件后输入框**无附件 chip、无 toast、无会话内提示**；拒收原因也不进模型上下文。同模型同场景，AD-06 推对、AG-09 推错——**猜对与否纯看运气**。

### P0-7 · 多 sheet 无护栏，读错 sheet 的错误无法被任何机制发现
**现形（1 条）**：AG-05 —— 5 次 `pd.read_excel(path)` 均未传 `sheet_name`，从未调用 `ExcelFile(...).sheet_names`；把第 1 个 sheet「咸味强度」当「总体喜好度」，并明确对用户断言「这份表里总体喜好度两列都是 15 个有效分」。整条链路（长表→bundle→三线表→Methods/Results→复现脚本）**数字全部自洽、可复现、附 ICMJE 披露**——比模型自己瞎算更危险。用户给的免费纠错信号（「有个人弃权」）被编造的解释和解成「你确认过的」事实。

### P0-8 · 隐私三句话（存哪 / 存多久 / 不训练）未实现
**现形（1 条）**：AD-05 —— 硬判据 #6 命中，`训练/30天/工作目录/会话` 在用户可见文本中计数全为 0。`grep agent/ + frontend-user/src + backend/internal` 三处零命中，是尚未建设的能力，已在 BUILD-P0 T13 清单上。

### P1-10 · Methods 的 Shapiro 句结构错乱
**现形（9 条）**：AD-01、AD-02、AG-01、MED-01、MED-02、PSY-01、PSY-09、SPT-06、SPT-07
原文形态：「各组正态性(Shapiro-Wilk)(A:0.978, p=0.565、B:0.953, p=0.094)：**统计量 0.953，p=0.094**，该前提满足。」——逐组列完后又把其中一组的 W 复述成一个无主语的全局统计量，审稿人会直接质疑。

### P1-11 · 引擎拒绝回执信息量不足
**现形（4 条）**：SPT-02（全文只有 `{"ok":false,"reason":"not_two_levels"}`，无「这是重复测量、RM-ANOVA 在 P1、不得拆两两」，模型随即读成纯接口限制）、AD-03（`missing_column` 实为 BOM；`not_two_levels` 实为需长表，无任何「宽表请转长表」提示，模型连吃 3 次拒绝靠自己猜出来）、AG-02（`why_zh` 只有「方差不齐(Levene p<.05)」，无 W/F 数值、无下一步）、MED-07（`decision.allowed` 就在模型手上，候选集一个字没往外传）

### P1-12 · statkit 读 CSV 不剥 utf-8-sig BOM
**现形（6 条）**：AD-02、AD-03、AD-07、AG-08、MED-03、SPT-07
每次白烧一轮 StatRun（`missing_column: "﻿断面编号"`），UI 上留「N 次未成功」，还逼模型把「BOM/utf-8-sig 编码」这种实现细节讲给用户。而 `to_csv(encoding='utf-8-sig')` 是中文 CSV 的默认写法。

### P1-13 · 多重比较披露按调用序快照，不回填
**现形（4 条）**：SPT-10（pair1 的 Methods 写「本会话仅此一次检验，**无多重比较问题**」——恰好是用户最可能投稿的那份）、MED-05（同族三份交付物写出三个互斥口径：无 / α'=.025 / α'=.0167）、AG-07（把「主分析 vs 敏感性分析」当成 2 次族内检验并写进论文段落）、PSY-08（引擎已算出 α'=.025，模型一字未转达）

### P1-14 · 转述层把引擎的克制措辞升格 / 说反
**现形（4 条）**：AG-06（bundle「各组均未拒绝正态性假设」→ 助手「两组均符合正态」「满足 Student t 的前提」，且 n=3 无检验力零提及，**命中硬判据**）、AD-01（bundle/Methods 均为「方差齐」，助手写「判定两组方差不齐」）、AG-02（察觉 bundle 自相矛盾后自行合理化，向用户升格为「方向性证据存在」）、SPT-06（CI 上界 −0.034 说成「不是贴着零晃出来的」）
