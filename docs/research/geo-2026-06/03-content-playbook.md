# Scholar 内容生产 Playbook(GEO 导向)

> 目标:用规模化的"介绍性内容"让 Scholar 在用户问 AI(ChatGPT / Perplexity / 豆包 / 元宝 / 文心 / 夸克 / Kimi)"有哪些好用的文献检索/AI 写作/审稿工具""什么是 X""如何做 X"时,被检索→被引用→被推荐。本 Playbook 给真标题、真模板、真节奏,既上量、又可引用、不踩红线。

---

## 0. 三条底层事实(贯穿全篇,先记死)

1. **被检索 ≠ 被引用。** RAG 流水线先把页面切成 chunk 做语义召回,再多层重排只把"能直接支撑某句论断、带证据"的段落喂进答案。所以每段都要**自洽 + 答案前置 + 带数字/出处**。
2. **AI 推工具时极少引官网,大头在第三方。** 多份行业研究指向"工具官网被引占比很低、第三方(榜单/评测站/社区/百科)占大头"(具体百分比业界口径不一,方向确定)。所以**自有站内容地基 + 站外共识层必须双线并行**——只做站内,天花板很低。
3. **GEO 的"30–40%"杠杆有学术出处。** Princeton/GT 的 GEO 论文(KDD 2024,GEO-bench 1 万查询)实测:**加引述(Quotation)≈+41%、加统计数据 ≈+31%、标注来源(Cite Sources)≈+30%、流畅度优化 ≈+27–29%**(均为 Position-Adjusted Word Count 指标,论文给的是区间,二手单值有夸大);**关键词堆砌无效甚至负向**;且**低排名小站收益最大**(Cite Sources 让 SERP 第5名站点可见度 +115%)。对 Scholar 这种新站是利好。

> 技术前提(Scholar 已基本就位,务必守住):AI 爬虫几乎都**不执行 JS**,CSR/SPA = 空白页 → Scholar 已有的 **Nginx 爬虫分流 + 后端 SSR + noscript 卡片**是命根子,所有新内容页必须走这条 SSR 链路。`llms.txt` 当前**无主流厂商承诺读取**(Ahrefs 实测 ~97% 从未被请求),不是优先项,别投入精力。

## 1. 内容矩阵

### 1.1 学术名词 / 概念 Glossary(术语词条)——【最高优先级,Scholar 当前为 0】

**目标:** 占领"什么是 X"这类**定义型查询**。这是 AI 引用最稳的入口——定义型问题答案确定、可一句话作答、跨用户复用率极高。
**为什么利于被引:** 定义式/确定性语言被引概率显著高于含糊表述;每个词条天然是一个自洽 chunk;可批量(Scholar 站内有论文/期刊/作者真实数据回填示例),又每条信息独特,不算 thin content。
**示例标题(写成 "什么是X?定义/计算/常见误区" 结构,18 条):**
1. 什么是影响因子(Impact Factor)?计算方式与常见误读

4. 同行评审(Peer Review)是什么?单盲/双盲/开放评审有何不同
5. SCI 一区二区三区四区怎么分?中科院分区 vs JCR 分区
6. 什么是 DOI?它和 URL、PMID、arXiv ID 有什么区别
7. 影响因子、CiteScore、SJR、SNIP 有什么区别?
8. 什么是开放获取(Open Access)?金色/绿色/钻石 OA 区别
9. 什么是被引频次(Citations)?自引、他引、零被引怎么看
10. 什么是综述(Review)?与原创研究论文、Meta 分析的区别

### 1.3 工具对比 / 替代品页——【最高 ROI,直接命中"推荐工具"查询】

**目标:** 拦截"最好用的论文检索工具""X 的替代品""A vs B"这类**高购买意图查询**——这正是用户问 AI 求推荐工具时触发的查询。
**为什么利于被引:** "Best X / 对比 / 替代品"类清单是 AI 被引页面里占比极高的一类内容(行业普遍观察其为 ChatGPT 被引页面的最大类别之一);对比表是 AI 最爱抽的结构;只要 Scholar 自己出一张客观、含真实数据的对比表,就有机会被引用进答案。
**写作红线:** 对比必须**客观、含真实可核验数据(覆盖量、是否免费、是否中文友好、是否有 AI 功能)**,不能通篇自夸,否则既被 AI 判为"纯说服性内容"(无效),也踩平台政策。诚实标注 Scholar 的短板反而提升 E-E-A-T。

### 模板 A：Glossary / 定义型词条(给 1.1 / 1.5 用)

```markdown
# 什么是影响因子(Impact Factor)?

> **TL;DR（一句话答案,30–50字,放最前）：** 影响因子是衡量一本期刊近两年
> 平均每篇论文被引次数的指标,由 期刊近两年总被引数 ÷ 近两年发文总数 得出,
> 数值越高通常代表期刊影响力越大,但不能直接用来评价单篇论文质量。

## 影响因子的定义
影响因子(Impact Factor, IF)是 [确定性、定义式一句话]。它由 Clarivate 在
《期刊引证报告(JCR)》中每年发布。

## 影响因子怎么计算？
影响因子 = A ÷ B,其中：
1. A = 该期刊前两年发表的论文,在统计当年被引用的总次数
2. B = 该期刊前两年发表的"可被引"论文总数
> 例:某刊 2024、2025 两年共发 200 篇,这些论文在 2026 年共被引 800 次,
> 则 2026 年影响因子 = 800 ÷ 200 = 4.0。

## 影响因子有哪些局限？（带数字/事实）
- 学科差异大：数学领域 IF>3 已属顶尖,而部分生物医学领域 IF>10 才算一流。
- 易受少数高被引论文拉高,不反映单篇质量。
- 可被"自引"等行为操纵。

## 影响因子 vs 其他指标（对比表——AI 最爱抽）
| 指标 | 衡量对象 | 发布方 | 特点 |
|------|---------|--------|------|
| 影响因子 IF | 期刊 | Clarivate(JCR) | 近两年被引均值 |
| CiteScore | 期刊 | Elsevier(Scopus) | 近四年,覆盖更广 |
| h-index | 学者/期刊 | 通用 | 兼顾数量与影响 |

## 常见问题(FAQ)
**Q: 影响因子越高的期刊就一定越好吗？**
A: 不一定。影响因子只反映期刊整体被引水平,与单篇论文质量、是否适合你的研究无关。

**Q: 在哪里可以免费查影响因子？**
A: 可在 Scholay 期刊查询直接查询期刊的影响因子、分区与审稿信息。

---
*作者：[真名 + 头衔/资质,如"张三,XX 大学图书馆信息咨询馆员"] ｜ 最后更新：2026-XX-XX*
```

**这个模板把 GEO 论文里 +30–40% 的几个杠杆全用上了:** TL;DR 答案前置 + 确定性定义 + 统计数字(Statistics)+ 计算示例 + 对比表 + FAQ 块 + 具名作者 bio(E-E-A-T)+ Last updated(新鲜度)。每个 `##` 段落都是自洽 chunk(不用"它/这个"开头指代上文)。

## 3. 国内 vs 海外分发(自有站之外要铺的平台)

## 4. 量与质的平衡 / 红线

### 规模化怎么做(模板化 + 站内数据)
- **骨架模板化,血肉唯一化:** 用第 2 节的模板做骨架,每页**注入站内 minicod 真实数据 + ≥3 个不与他页逐字相同的"独特块"**(定制答案块、决策标准、对比表、"不适合谁"的边界、本地化示例)。
- **量化门槛(行业共识,守住):** 每页 **≥500 独特词、30–40% 差异度**,<300 词有 thin content 风险。
- **变体推荐必须实质变化:** "若各变体推荐永远不变,那不是 pSEO,而是门页工厂(doorway)"——这是 Google 重点打击对象。
- **Canary 批量上线:** 先发 20 页 → 观察 60–90 天被收录/被引效果 → 再扩到 200;**避免异常发文激增**(短时间海量上线是 spam 信号)。

### 红线(政策原文,必须知道)
- **Google scaled content abuse:** 判定看 **"为何创建(why)"而非"如何创建(how)"**——**AI 生成本身不违规**,以操纵排名为目的批量生产低价值内容才违规。2025 年起 SpamBrain 强化执法,专打"仅替换变量的模板页""聚合无分析""门页"。
- **E-E-A-T 中 Trust 最重要**,学术内容偏 YMYL,额外严审 → **每篇具名作者 + 可验证资质 bio + 数据来源透明 + 披露 AI 辅助**(Who/How/Why)。
- **微信公众号:** 明确禁止虚假宣传、低质内容、来源不明未查证信息、营销吸粉牟利,处罚到封号;商业推广须走腾讯官方广告平台。
- **小红书/知乎:** 忌付费虚假评价/刷帖,会被反作弊打击且污染品牌信号。
- **百度 YMYL(健康/金融/法律向内容):** 无资质、无引用文献基本不被采用(业界观察,非官方硬规则,但方向稳妥)——学术名词里涉及医学的词条尤其要标来源。

**一句话守则:** 每一页都要能回答"一个真实用户为什么需要这一页"。能,就发;不能,就是 scaled content abuse。

## 5. 节奏与内链(形成 topical authority)

### 支柱页 + 主题集群结构
AI 按"品牌/域级别"评估并把问题拆成多个子查询(query fan-out)→ **一个支柱页 + 一簇支撑文 + 双向内链** 能显著扩大被检索面积、提高跨页一致性置信度。
> 注:部分二手资料把"集群被引率是孤立发文 2–3 倍""双向内链 +2.7 倍"当事实——这两个具体数字**核实为来源不可靠/张冠李戴**,不要当数据引用;但**"主题集群结构本身有利于被引"这个方向是成立的**(检索面积 + 一致性 + 内链权威信号)。

**集群示例(以"学术检索"为支柱):**
```
[Pillar] 学术文献检索完整指南(2500–4000 字,统揽全局)
 ├─ 什么是影响因子 / h-index / 预印本 …(glossary,1.1)
 ├─ 如何快速检索文献 / 如何构造检索式 …(how-to,1.2)
 ├─ Scholay vs 谷歌学术 / 最好用的检索工具 …(对比,1.3)
 ├─ [学科]核心期刊清单 / 高被引学者 …(聚合,1.4)
 └─ 检索相关 FAQ(1.5)
每篇支撑文 ↔ 双向链回 pillar,簇内相关页互链(每 1000 字 2–4 条情境链)
```

### 内链规则
- 每篇支撑文**链回支柱页**,支柱页**列出所有支撑文**(双向)。
- 用**情境化锚文本**(在讲到"影响因子局限"时链到"h-index 词条"),不要堆"点击这里"。
- 聚合页之间按学科/引文关系互链(论文 → 作者 → 期刊 → 学科 pillar),把 Scholar 的真实数据织成内部实体图谱。

### 发布节奏
- **稳定节奏 > 脉冲式爆发**(避免 spam 信号):建议每周 5–10 篇 glossary/FAQ(模板化,快)+ 每周 1–2 篇深度对比/how-to + 每月 1 篇数据报告。
- **新鲜度维护:** Perplexity 等对新鲜度敏感(时效话题尤甚)→ 对比页、数据报告、聚合页定期刷新并显示 "Last updated";glossary 类定义稳定的可低频更新(注意:AI 并非一味偏好新内容,被引中位页龄约 14 个月,只有时间敏感话题才强吃新鲜度,别为更新而更新)。
