## UI样式说明

### 提示条样式（类似Google/百度）

- **背景色：** 深色主题，半透明白色边框
- **文字颜色：** 
  - 普通文字：`rgba(255, 255, 255, 0.6)`
  - 强调文字（查询关键词）：`rgba(255, 255, 255, 0.9)`
- **按钮样式：**
  - 颜色：`#8ab4f8`（浅蓝色，类似Google链接色）
  - hover效果：背景半透明 + 下划线
  - 无边框，扁平设计

### CSS类名

```css
.search-translation-hint         /* 提示条容器 */
.hint-text                        /* 提示文字 */
.hint-action-btn                  /* 操作按钮 */
```

## 交互逻辑

### 1. 显示条件

提示条仅在以下条件**同时满足**时显示：
- ✅ `translationEnabled === true`（启用了翻译）
- ✅ `translatedQuery` 不为空（有翻译结果）
- ✅ `translatedQuery !== originalQuery`（翻译结果与原文不同）

### 2. 用户操作流程

```
用户输入中文 → 点击搜索
    ↓
后端AI翻译 → 组合查询（原文 + 译文）
    ↓
显示提示 → "已为你找到 'xxx' 的结果"
    ↓
用户可选择：
    ├─ 继续使用当前结果（组合查询）
    └─ 点击 "仅按原始查询查找" 
         ↓
      禁用翻译重新搜索 (enableTranslation: false)
         ↓
      仅用原始查询，不显示提示
```

### 3. 参数控制

| 参数 | 值 | 说明 |
|------|-----|------|
| `enableTranslation` | `true` | 首次搜索，启用AI翻译 |
| `enableTranslation` | `false` | 用户点击"仅按原始查询"，禁用翻译 |

```json
{
  "code": 0,
```

## 用户体验优势

1. **✅ 透明度**：用户清楚知道系统做了什么
2. **✅ 可控性**：用户可以选择是否使用翻译
3. **✅ 熟悉感**：类似Google/百度的设计，降低学习成本
4. **✅ 智能化**：自动翻译提升检索准确性
5. **✅ 灵活性**：支持中英文混合检索
